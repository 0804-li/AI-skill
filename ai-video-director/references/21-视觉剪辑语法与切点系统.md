# 21 视觉剪辑语法与切点系统

> 定位：05号解决“怎么转场、怎么保持连续”，本库解决**“为什么此时切、切什么、切前与切后如何形成新的意义”**。核心是剪辑逻辑、镜头顺序、Cut Point、节奏和视觉/声音信息的接力。
>
> 核心原则：**剪辑不是把好镜头拼起来，而是在两个镜头之间制造新的信息关系。**

## 一、剪辑决策四问

每一次切镜头前先问：

1. 为什么现在结束当前镜头？
2. 为什么下一个镜头必须在此时出现？
3. 切换后观众新增了什么信息？
4. 两个镜头之间产生了什么关系？

## 二、镜头的三种时间

### 画面时间
主体实际动作发生时间。

### 观看时间
观众需要多少时间理解画面。

### 叙事时间
故事世界中过去了多少时间。

三者可以一致，也可以故意错开。

## 三、Cut Point切点类型

| 切点 | 使用逻辑 |
|---|---|
| Action Start Cut | 动作开始前/开始时切，制造预期 |
| Action Peak Cut | 动作高潮时切，强化冲击 |
| Action Completion Cut | 动作完成后切，强调结果 |
| Reaction Cut | 先看反应，再解释原因 |
| Eyeline Cut | 按视线切到目标 |
| Information Cut | 切到关键道具/信息 |
| Emotional Cut | 情绪峰值后切 |
| Rhythm Cut | 按音乐/动作节拍切 |
| Contrast Cut | 从A直接切到视觉相反的B |

## 四、Continuity Editing连续性剪辑

维持：

- 时间连续
- 空间连续
- 运动方向连续
- 视线连续
- 动作连续
- 光色连续
- 角色状态连续

## 五、Discontinuity不连续剪辑

故意破坏连续性，用于：

- 心理断裂
- 时间跳跃
- 记忆
- 荒诞
- 恐怖
- 梦境
- 主观认知

规则不是“绝对不能跳”，而是：

> **跳跃必须有叙事理由。**

## 六、Match Cut

### Action Match
同一动作跨镜衔接。

### Graphic Match
形状/构图相似跨镜连接。

### Movement Match
相同方向的运动衔接。

### Color Match
色块或色调相似。

### Concept Match
视觉物体不同，但意义相同。

## 七、Shot Reverse Shot

经典对话结构：

```text
Master / Two Shot
→ A
→ B
→ A Reaction
→ B Reaction
→ Insert / Shared Space
```

不能把每个单句机械切一次。切点应服从：

> 信息、权力、情绪、潜台词变化。

## 八、Reaction Shot

反应镜头经常比“说话镜头”更有叙事价值。

三种用途：

- 显示人物真实情绪
- 暂时隐藏说话对象的信息
- 通过反应改变观众理解

## 九、信息领先与延迟

### Information First
先给观众看事实，再看人物反应。

### Reaction First
先看人物反应，再揭示原因。

### Sound First
先听到信息，再看到来源。

### Image First
先看到目标，再补充声音。

这些结构可形成不同悬念强度。

## 十、J-Cut / L-Cut

### J-Cut
下一镜声音先进入。

作用：

- 连续空间
- 提前预告
- 情绪延续

### L-Cut
上一镜声音延续到下一镜。

作用：

- 人物余韵
- 记忆
- 情感过渡
- 时间空间柔化

## 十一、Cross Cutting

在两条行动线之间交替剪辑。

适合：

- 营救倒计时
- 两地对照
- 追逐
- 同时发生事件
- 互相不知道的行动

## 十二、Parallel Editing

两个场景不是同一事件，也可以通过并置产生：

- 对照
- 隐喻
- 主题关系
- 命运呼应

## 十三、蒙太奇五层

### Metric
按镜头时长形成节奏。

### Rhythmic
按主体运动切换。

### Tonal
按情绪切换。

### Overtonal
运动+节奏+情绪综合作用。

### Intellectual
通过两个画面并置产生第三层思想意义。

## 十四、Shot Duration心理

不是越快越刺激，越慢越高级。

### 极短镜头
信息冲击、混乱、危险、快速决策。

### 中等长度
正常叙事、动作、对话。

### 长镜头
观察、沉浸、压迫、真实时间、表演。

### 极长镜头
时间感、等待、尴尬、仪式、孤独、审视。

## 十五、节奏曲线

一个Sequence建议建立：

```text
建立 → 累积 → 加速 → 峰值 → 停顿 → 余韵
```

“停顿”不是浪费，它是让峰值具有重量的必要部分。

## 十六、Cutting Rhythm与动作

动作场景中常用：

> Wide建立空间 → Medium跟随 → Close强调接触 → Reaction显示冲击 → Wide重新建立空间。

不要连续使用大量Close-up，否则观众容易失去空间方向。

## 十七、视觉剪辑与注意力联动

每次剪辑都应完成一次：

> 注意力A → Cut → 注意力B。

如果两边的视觉焦点相互竞争，剪辑会混乱。

## 十八、剪辑切点卡

```text
SHOT A
起始状态：
结束状态：
主信息：
视觉焦点：
动作节拍：
情绪状态：
声音状态：

CUT
切点原因：
观众新增信息：

SHOT B
起始状态：
视觉焦点：
动作/情绪承接：
声音承接：

连续性检查：
空间 / 方向 / 光色 / 人物 / 道具 / 状态
```

## 十九、AI多镜头生成规则

1. 每镜先定义Start State和End State。
2. 下一镜默认继承上一镜End State。
3. 一个Cut最好完成一个主要信息变化。
4. 转场效果不能取代叙事切点。
5. 动作镜头优先保证空间连续，再追求剪辑花样。
6. 对话戏优先保证视线、轴线和情绪连续。

## 二十、AI Prompt转译

不要写：

> 节奏紧凑，电影剪辑感强。

改写为：

> 前镜头保持2–3秒建立人物位置，人物突然抬头时在动作峰值附近切入近景；下一镜直接接他的视线目标；随后在目标出现的瞬间切回人物反应；上一镜环境声持续进入下一镜，形成J-Cut。

## 二十一、最终检查

1. 每次切镜是否有明确原因？
2. 切后是否新增信息？
3. 是否保持或有意改变空间方向？
4. 镜头时长是否符合理解难度？
5. 动作峰值是否被浪费？
6. 反应镜头是否比重复信息更有价值？
7. 声音有没有成为镜头之间的桥？
8. 节奏有没有峰值与呼吸？

## 二十二、核心公式

> **剪辑 = 镜头选择 + 镜头顺序 + Cut Point + 信息关系 + 时间压缩/扩展 + 声音连接 + 节奏曲线。**
