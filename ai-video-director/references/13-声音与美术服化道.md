# 13 声音与美术服化道词库

声音把不可见的心理变成听觉体验；美术服化道把历史和身份留在空间与身体上。本词库包含：声音五层结构、声音透视、声音剪辑技法、音乐动机系统、美术世界观圣经、场景叙事五层、空间连续性、服装系统、化妆发型、道具系统。

**核心原则：声音的距离就是叙事，空间的材质就是人物。**

## 声音五层结构（写声音Prompt时逐层填充）

| 层级 | 内容 | 专业用途 | AI/后期提示 |
|---|---|---|---|
| 对白 | 对白、呼吸、口腔细节 | 叙事与人物关系 | 近讲、低声、耳语、远距离喊话 |
| 同期环境 | 房间、街道、自然、机械 | 建立真实空间 | 室内残响、城市底噪、风、雨、空调 |
| 动作音效 | 脚步、衣物、门、武器、触碰 | 增强动作重量 | 材质具体化（皮革/金属/木门/布料） |
| 设计声音 | 低频轰鸣、反向音、纹理声 | 心理化、主观化 | 非现实、延迟、失真、拉伸 |
| 音乐 | 主题、节奏、和声、音色 | 情绪与意义组织 | 动机、变奏、留白、反讽 |

## 声音透视（距离就是叙事）

| 距离 | 声音表现 | 叙事含义 |
|---|---|---|
| 贴近 | 口腔、呼吸、衣物细节明显 | 主观、亲密、压迫 |
| 近场 | 环境清晰、细节丰富 | 现实感 |
| 中远 | 混响增加、细节衰减 | 观察、疏离 |
| 远景 | 人声与空间融合 | 孤独、宏大 |
| 隔墙/门后 | 高频损失、遮蔽 | 秘密、未知、阻隔 |

## 声音剪辑与心理技法

| 技法 | 定义 | 效果 | Prompt写法 |
|---|---|---|---|
| 先声后画 | 声音提前进入下一镜 | 预期与连续性 | 下一场景声音提前0.8秒进入 |
| 画先声后 | 画面先出现才听到 | 主观迟滞、震撼 | 门已开，撞墙声延迟半拍才响 |
| J-Cut | 声音先于画面切入 | 自然过渡、悬念 | 对白先起，画面后切 |
| L-Cut | 上镜声音延续到下镜 | 时间/情绪粘合 | 上一镜台词延续到反应镜头 |
| 声音桥 | 同一声音跨场景 | 建立时空联系 | 钟声从寺院延续到城市公寓 |
| 突发静音 | 瞬间抽掉环境声 | 主观震撼、失聪感 | 爆炸后环境声骤然消失只剩耳鸣 |
| 频率遮蔽 | 声音被环境吞没 | 心理混乱、现实感 | 呼喊被雨声淹没只看到口型 |
| 声源错位 | 声音来源暂时不明 | 悬疑、超现实 | 画外传来不该存在的童谣 |

## 音乐动机系统（别只写"悲伤音乐"）

| 维度 | 示例 |
|---|---|
| 主题动机 | 3-5音核心旋律 |
| 人物动机 | 特定音色（大提琴=她，合成器=他） |
| 关系动机 | 两人共享一个动机但配器不同 |
| 威胁动机 | 持续低音/不协和音程/脉冲 |
| 记忆动机 | 带滤波、远距离、残响或音色退化 |
| 变奏规则 | 人物改变后动机节奏/和声/配器变化 |

**静默的力量**：不要全程配乐。设计静音段、空气感段、只有环境底噪的段落——声音的留白比满配乐更有电影感。

## 美术设计：让空间参与叙事

### 世界观视觉圣经

| 模块 | 内容 |
|---|---|
| 时代 | 年代、科技水平、社会制度 |
| 地域 | 地理、建筑、材料、气候 |
| 社会层级 | 不同阶层空间尺度与材质 |
| 文化系统 | 纹样、宗教、符号、禁忌 |
| 色彩规则 | 主色、禁色、权力色 |
| 空间规则 | 门、窗、走廊、楼梯、庭院如何构成叙事 |
| 老化规则 | 哪些物件新、哪些旧、谁在维护 |

### 场景叙事五层

1. **功能层**：人物在这里做什么
2. **社会层**：谁拥有这个空间（医院走廊=体制所有，谈漾只是过客）
3. **心理层**：空间让人物舒服还是压迫
4. **时间层**：空间承载过什么事件（墙上的旧痕、磨痕的地面）
5. **象征层**：这个空间代表什么价值（铁笼=囚禁，急诊门=生死边界）

### 空间连续性规则

| 系统 | 规则 |
|---|---|
| 动线 | 人物从哪来往哪去必须可追踪 |
| 入口/出口 | 重要场景至少一个可退出通道 |
| 视觉锚点 | 每空间设2-4个固定参照物 |
| 尺度 | 门高、桌宽、人物与建筑比例稳定 |
| 空间声场 | 同一空间混响与底噪一致 |
| 光源逻辑 | 窗、灯、火、霓虹方向可解释 |

## 服装系统（身份、心理与时间的可视化）

| 维度 | 技法 | 叙事作用 |
|---|---|---|
| 身份 | 阶层、职业、地域、时代 | 观众无需对白即可识别 |
| 状态 | 整洁/凌乱、干燥/潮湿、完整/破损 | 把事件结果留在身体上 |
| 色彩 | 角色专属色群 | 人物识别与关系变化 |
| 材质 | 棉、丝、皮、金属、旧织物 | 塑造社会与触觉 |
| 轮廓 | 肩线、衣长、松紧、体积 | 改变气质与权力感 |
| 连续性 | 服装状态表 | 防止AI前后跳变 |

**服装状态连续性表**（AI分镜必建）：

| 镜头阶段 | 服装状态 | 新增变化 |
|---|---|---|
| S01-S04 | 完整、整洁 | 无 |
| S05-S08 | 衣摆受潮 | 雨水 |
| S09-S12 | 袖口磨损 | 奔跑擦伤 |
| S13-S16 | 肩部破裂 | 战斗结果 |
| S17-S20 | 换上外套 | 进入新阶段 |

## 化妆、发型与身体状态

化妆直接承担年龄、疲劳、疾病、阶层、时间流逝和创伤连续性：

| 系统 | 固定项 | 可变项 |
|---|---|---|
| 脸部身份 | 脸型、眼距、鼻形、发际线、标志痣 | 疲劳、汗、泪、灰尘 |
| 头发 | 长度、发色、发际线 | 湿度、凌乱度、受风状态 |
| 皮肤 | 基础肤色、年龄纹理 | 潮湿、苍白、泛红 |
| 创伤 | 位置与形状 | 颜色、结痂、渗血程度 |
| 妆容 | 基础妆型、唇色、眉形 | 剧情阶段变化 |

**AI特别注意**：必须固定"身份特征"（痣、疤、发际线），否则每镜都是不同的人。创伤要写演变：`指关节伤口：新鲜渗血→第2镜凝固→第4镜崩裂再渗`。

## 道具系统：物件也是角色

### 道具四种叙事功能

| 类型 | 功能 | 示例 |
|---|---|---|
| 功能道具 | 推动行动 | 钥匙、手机、武器、药瓶 |
| 信息道具 | 透露过去 | 照片、信件、账本 |
| 关系道具 | 承载人物关系 | 戒指、礼物、旧玩具 |
| 象征道具 | 承载主题 | 破镜、钟、门、种子 |

### 道具护照（重要道具必建）

名称｜尺寸｜材质｜颜色｜磨损｜持握方式｜首次出现｜最后出现｜剧情所有权｜损坏状态。

**AI道具规则**：一个镜头只给一个道具"表演机会"（特写/交互）；背景道具不得抢主体；道具位置跨镜继承（桌上的杯子下一镜还在原地）。

## 声音+美术联动模板（成品片段）

### 医院走廊（对应24-1场景）
```
声音五层：日光灯电流嗡鸣与远处仪器提示（环境）｜胶底鞋急促摩擦与门轴（动作）｜谈漾沙哑气音与喉咙清嗓（对白）｜推门后耳鸣式静默一瞬再涌入走廊声（设计）｜无配乐（音乐留白）
美术：走廊白绿瓷砖、宣传栏"冷静"大字、急诊室红灯、消毒水瓶——体制空间；谈漾混血的双手与崩裂指节——暴力的身体档案
```

### 雨夜告别
```
声音五层：雨打遮阳棚与檐滴（环境）｜皮箱落地与伞面震动（动作）｜两句没说完的话（对白）｜持续低频在说再见前10秒进入（设计）｜弦乐单音在她转身瞬间停住（音乐）
美术：便利店铺灯只照亮两人之间一米，其余沉入雨夜——关系的最后范围；她的红色围巾是全片色彩母题第三次出现
```
