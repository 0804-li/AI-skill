# 04 环境动态与前后景词库

AI 视频中的背景不能完全静止，环境应存在合理的次级运动；前景是 AI 视频空间感的重要来源。

## 环境元素运动表

| 场景元素 | 常用运动 |
|---|---|
| 云层 / 远景云海 | 缓慢流动 |
| 雾气 | 飘动、扩散、升腾 |
| 树叶 / 植物 / 草地 | 随风摆动 |
| 花瓣 | 飘落、横向飘移 |
| 长发 / 衣摆 | 随风摆动 |
| 烟雾 | 缓慢升腾、向两侧散开 |
| 水面 | 连续波纹 |
| 水流 | 连续向前流动 |
| 火焰 | 自然跳动 |
| 烛火 | 轻微摇曳 |
| 阳光 | 穿过云层变化 |
| 光束 | 缓慢移动 |
| 粒子 / 尘埃 | 空气中缓慢漂浮 |
| 灯光 | 微弱变化 |
| 旗帜 / 丝绸横幅 | 随风摆动 |
| 建筑光影 | 随镜头移动发生变化 |
| 雪 | 连续飘落 |
| 雨 | 连续下落 |

环境运动三原则：**轻微、合理、连续**。环境动态描述用："环境元素产生自然、连续、合理的动态。"

## 环境动态英文对照

自然：wind 风｜rain 雨｜snow 雪｜mist 薄雾｜fog 浓雾｜dust 尘埃｜leaves 树叶｜water 水｜clouds 云｜sunlight 阳光｜moonlight 月光。

城市：traffic 车流｜pedestrians 行人｜neon signs 霓虹招牌｜steam 蒸汽｜smoke 烟｜rain reflection 雨中倒影｜vehicles 车辆｜crowd motion 人群流动。

东方场景：lantern sway 灯笼摇曳｜silk banners flowing 丝绸横幅飘动｜incense smoke 香烟｜falling petals 落花瓣｜mist over mountains 山间雾气｜water ripple 水波纹｜temple bells 钟声｜floating dust 浮尘。

材质运动：silk flowing 丝绸流动｜cloth fluttering 布料飘动｜hair swaying 发丝摆动｜water rippling 水波纹｜smoke drifting 烟雾飘动｜dust floating 尘埃漂浮｜snow falling 落雪｜rain splashing 雨溅｜glass reflecting 玻璃反光｜metal shimmering 金属微光｜fire flickering 火焰跳动｜liquid swirling 液体漩涡。

## 背景动作语言

不要写："背景有很多人在动。"
推荐写："soft pedestrian movement in the background, natural walking cycles, subtle crowd flow, distant vehicles moving laterally, atmospheric depth."（背景行人轻微移动，自然步行循环，微妙人群流动，远处车辆横向移动，大气纵深。）

## 前景元素库

可使用：前景人物｜前景树枝｜前景花瓣｜前景烟雾｜前景建筑｜前景光影｜前景粒子｜前景旗帜｜前景植物｜前景物体（灯笼、柱子、门框）。

作用：增强遮挡、空间层次、视差和电影感。让前景产生运动，可以显著增强视差、空间、真实感、电影感。

## 中景元素库

主体人物｜次要人物｜产品｜建筑主体｜核心道具｜主要动作。作用：承担主要叙事。

## 背景元素库

远山｜城市｜宫殿｜天空｜云层｜远景建筑｜远景人物｜环境光源。作用：建立世界观和空间尺度。

多主体空间层级表达法：主体A = foreground subject（前景主体）、主体B = midground subject（中景主体）、主体C = background subject（背景主体），明确空间层级。

| 提示词 | 作用 |

## 使用要点

1. 每个镜头至少加入 2~3 种环境动态（如"云层缓慢流动 + 衣摆随风摆动 + 光束缓慢移动"）。
2. 前景遮挡 + 运动视差是 AI 视频空间感的最大来源，优先设计。
3. 环境运动幅度要小于主体运动，避免喧宾夺主。
4. 灯光和色彩随镜头运动产生变化（如"建筑光影随镜头移动发生变化"）能显著增强真实感。
