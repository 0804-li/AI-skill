# 01 人物动作与走位词库

人物调度（Blocking）决定"谁在画面里怎么动"。AI 视频中人物运动必须有明确方向和明确路径，模糊描述会导致人物漂移或瞬移。

## 整体调度核心词（电影级）

| 调度词 | 作用 |
|---|---|
| 电影级场面调度 | 建立电影化空间和人物关系 |
| 电影级人物调度 | 强化人物走位和动作逻辑 |
| 专业导演调度 | 建立明确的视觉叙事意图 |
| 精准人物走位 | 控制人物在画面中的位置变化 |
| 多人物空间调度 | 控制多个角色之间的位置和运动 |
| 动态视觉调度 | 让人物、摄影机、环境产生有组织的运动 |
| 连续动作调度 | 保持前后动作连贯 |
| 人物与镜头同步运动 | 让人物动作与摄影机运动形成统一节奏 |
| 人物与环境互动 | 让人物和场景产生真实关系 |
| 前景遮挡调度 | 利用前景物体增强空间和转场 |
| 空间纵深调度 | 建立前后景距离 |
| 视觉中心调度 | 强调主要主体 |
| 对称式人物调度 | 营造秩序、仪式感 |
| 非对称人物调度 | 建立电影式构图 |
| 环形人物调度 | 让人物围绕核心主体运动 |
| 放射状人物调度 | 人物从中心向外或由外向中心运动 |
| 队列式人物调度 | 营造军阵、仪式、史诗感 |
| 前后错位调度 | 利用人物深度位置制造层次 |
| 交叉式人物调度 | 制造人物之间的动态关系 |
| 纵深式人物调度 | 让人物沿空间纵深运动 |
| 引导线式调度 | 利用道路、建筑、走廊等引导视觉 |

## 动作分级（控制 AI 运动复杂度）

- **微动作**（安全，AI 执行最稳定）：呼吸、眨眼、吞咽、抬眉、点头、轻微转头、发丝飘动、衣摆摆动、手指移动。
- **中等动作**（常用）：行走、转身、坐下、站起、拿取、放下、挥手、拥抱、观察、奔跑。
- **大动作**（高风险，一个镜头只安排一个）：跳跃、冲刺、翻滚、打斗、摔落、爆炸、飞行、破坏、坍塌、变形。

英文对照：Walk 行走｜Slow Walk 缓慢行走｜Stride 大步走｜Stagger 踉跄｜Run 跑｜Sprint 冲刺｜Dash 猛冲｜Leap 跃起｜Jump 跳跃｜Roll 翻滚｜Dodge 闪避｜Strike 击打｜Block 格挡｜Grab 抓取｜Throw 投掷｜Catch 接住｜Reach 伸手。

## 微运动语言（防"僵尸式运动"）

AI 视频最容易把人物做成僵尸式静止。给人物加入：

轻微呼吸（subtle breathing）｜自然眨眼（natural blinking）｜细微头部变化（micro head movement）｜肩部轻微运动｜自然重心转移（natural weight shift）｜衣物轻微摆动｜发丝微动（soft hair movement）｜眼球微动｜手指自然放松。

## 使用要点

1. 人物走位必须写明方向（从左向右/向镜头/沿纵深），不写"人物走动"这种无方向描述。
2. 主角走位与摄影机运动绑定描述（如"人物向前走，摄影机同步向后跟拍保持距离"）。
3. 多人物场景先用一个调度词建立整体结构（如对称式/环形/放射状），再描述个体动作。
4. 群像镜头优先保证群体行为一致（同队形/同方向），个体差异放次级。
