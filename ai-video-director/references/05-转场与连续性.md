# 05 转场与连续性词库

转场决定"镜头如何衔接"，连续性控制决定"运动是否稳定不崩"。这两层是 AI 视频从"能看"到"可用"的关键。

> Wipe 高级理解：不要理解为"软件特效"。专业理解是"画面A被视觉边界主动替换成画面B"，边界可来自图形/物体/摄影机运动/光线/阴影/自然环境。传统Wipe=图形移动；现代电影Wipe=现实物体移动完成替换。

无缝转场通用要求："镜头运动连续自然，通过运动方向完成无缝衔接"（seamless transition）。

## 轴线与方向连续性（180度规则）

- 180-Degree Rule：两个主体之间画一条动作线（Axis / Line of Action），摄影机保持在轴线一侧180度内，人物空间方向（左右关系）才不会反转。
- Crossing the Line 跨轴：故意切到轴线另一侧（需要 Neutral Angle 中性角度重新建立空间关系）。
- Screen Direction 屏幕方向：人物从左向右运动，下一镜头不要无故变成从右向左。
- Match on Action 动作匹配：动作在剪辑点两侧延续。
- Eyeline Match 视线匹配：人物看向画外，下一镜头展示其所看对象。

## 负向控制原则（重要）

当前主流模型（Seedance / Runway / Veo）官方指南都倾向于**直接正向描述希望出现的结果**，而不是大量使用"不要……"。把不希望出现的结果转写成希望实现的视觉特征：

- 不写"不要抖" → 写"锁定机位，构图完美稳定"（locked camera, perfectly stable composition）
- 不写"不要人物变形" → 写"人物结构稳定，身体比例一致"（stable character anatomy, consistent body proportions）
- 不写"不要背景乱动" → 写"建筑背景稳定，环境运动受控"（stable architectural background, controlled environmental motion）

## 使用要点

1. 每个"当前镜头"的结尾就是转场设计的入口：人物靠近门→穿门转场；人物经过镜头→擦镜转场；镜头加速→甩镜转场。
2. 多镜头序列必须做三查：人物运动方向连续（180度规则）、光影方向一致、主体外观一致。
3. 稳定性约束放在 Prompt 结尾统一输出（"整体动作连续自然……避免变形、瞬移、跳跃和不自然加速"）。
4. AI 优先级：主体一致性 > 主体动作 > 摄影机方向 > 景别 > 构图 > 光线 > 环境运动 > 复杂特效。要素过多时按此顺序牺牲。
