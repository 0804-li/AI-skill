# 03 景别·机位·焦段·构图词库

控制"拍多近、从哪里拍、用什么视觉看、如何摆放元素"。这一层决定画面的取景与视觉风格。

## 景别体系（Shot Size）

| 景别 | 英文/缩写 | 定义 | 作用 |
|---|---|---|---|
| 极远景/大远景 | EWS / Extreme Wide Shot | 主体极小，环境占绝大多数 | 宏大、孤独、史诗、世界观 |
| 超宽远景 | VWS / Very Wide Shot | 比一般远景更强调环境 | 环境叙事 |
| 远景/广景 | WS / Wide Shot | 人物与环境同时清晰可见 | 建立空间关系 |
| 全身 | FS / Full Shot | 人物从头到脚完整入画 | 展示全身动作与服装 |
| 中全景 | MFS / Medium Full Shot | 小腿或膝盖以上 | 动作与体态兼顾 |
| 牛仔景/美国景 | Cowboy Shot | 大腿以上 | 动作对峙（源自西部片） |
| 中景 | MS / Medium Shot | 腰部以上 | 对话、交流、动作（最常用） |
| 中近景 | MCU / Medium Close-Up | 胸部以上 | 强调表情与反应 |
| 近景/特写 | CU / Close-Up | 脸部或主要物体占大部分画面 | 情绪强调 |
| 大特写 | BCU / Big Close-Up | 进一步压缩人物空间 | 强烈情绪 |
| 极特写 | ECU / Extreme Close-Up | 眼睛、嘴唇、戒指、刀尖等局部 | 极端强调 |
| 微距 | Macro Shot | 极小物体 | 材质细节 |

功能镜头变体：Insert Shot 插入镜头（补充重要信息：手机、钥匙、血迹）｜Cutaway 切出镜头｜Reaction Shot 反应镜头｜Two Shot 双人镜头｜Three Shot 三人镜头｜Group Shot 群像｜Crowd Shot 人群｜OTS 过肩｜POV 主观｜Reverse POV 反向主观｜Profile Shot 正侧面｜Three-Quarter Shot 四分之三角度｜Rear Shot 背面。

镜头基本单位：Shot 镜头（一次连续摄影）｜Take 一条（某次实际拍摄）｜Frame 画格｜Scene 场景（同一时空的戏剧单位）｜Sequence 段落（多个镜头组成的完整事件段）｜Master Shot 主镜头（覆盖场景主要行动）｜Establishing Shot 建立镜头（交代地点空间规模）｜Hero Shot 核心展示镜头。

## 镜头角度（Angle）

| 角度 | 英文 | 效果 |
|---|---|---|
| 平视 | Eye-Level | 自然、中性 |
| 低角度/仰拍 | Low Angle | 强大、权威、英雄 |
| 高角度/俯拍 | High Angle | 弱小、脆弱 |
| 极低角度 | Extreme Low Angle | 极端压迫/崇高 |
| 极高角度 | Extreme High Angle | 极端俯视 |
| 虫视角 | Worm's-Eye | 接近地面极端仰视 |
| 鸟瞰 | Bird's-Eye View | 几乎垂直向下 |
| 正顶拍 | Overhead Shot | 主体正下方平面几何构图 |
| 空中视角 | Aerial View | 高空观察地面 |
| 荷兰角/倾斜 | Dutch Angle / Canted Frame | 水平线倾斜：不稳定、危险、心理异常 |
| 正面角度 | Frontal Angle | 主体正对镜头 |
| 背后四分之三 | Rear Three-Quarter | 从背后斜侧拍摄 |

## 摄影机高度（Camera Height）

Ground Level 地面高度｜Knee Height 膝盖高度（低机位动作）｜Waist Height 腰部高度（常规移动人物）｜Chest Height 胸口高度（自然叙事）｜Eye Height 眼睛高度（平视）｜Shoulder Height 肩部高度（人物交流）｜Head Height 头顶高度｜High Camera Position 高位（俯视空间）｜Crane Height 摇臂高度（环境揭示）｜Overhead 头顶正上方（几何构图）。

## 镜头焦段（Lens）

| 焦段 | 视觉特点 | 适用 |
|---|---|---|
| 超广角 10–20mm | 强烈空间感、夸张透视 | 奇观、第一视角 |
| 广角 20–35mm | 空间扩张 | 建筑、环境、人物与空间关系 |
| 35mm | 经典环境叙事 | 人物与空间兼顾 |
| 40mm | 自然略带环境感 | 纪实感 |
| 50mm | 标准视觉 | 常规叙事 |
| 65mm | 自然偏压缩 | 人物 |
| 85mm | 经典肖像 | 人物肖像、情感 |
| 100mm | 强肖像细节 | 特写 |
| 135mm | 明显空间压缩 | 远距离观察 |
| 200mm+ | 远距离强压缩 | 侦测、窥视感 |
| 鱼眼 Fisheye | 超广角强畸变 | 风格化 |
| 微距 Macro | 极近距离 | 产品材质 |

## 对焦与景深（Focus & DOF）

- Deep Focus 深焦：多个空间层面同时清晰（群像、多层空间调度）。
- Shallow DOF 浅景深：主体清晰背景虚化（情绪特写、肖像）。
- Rack Focus 移焦：焦点从A转移到B（揭示、视线引导——AI 视频高价值技巧）。
- Focus Pull 拉焦 / Focus Shift 焦点转换 / Selective Focus 选择性对焦 / Soft Focus 柔焦。
- Split Diopter 分光镜：前后两个距离同时清晰。
- Tilt-Shift Focus 移轴焦点 / Hyperfocal Focus 超焦距 / Infinity Focus 无限远对焦。

## 构图（Composition）

Rule of Thirds 三分法｜Center Composition 中心构图｜Symmetrical 对称构图（秩序、仪式、权威）｜Asymmetrical 非对称｜Golden Ratio 黄金比例｜Golden Spiral 黄金螺线｜Leading Lines 引导线（道路、走廊、栏杆引导视觉）｜Diagonal 对角线构图（动态）｜Triangle 三角构图｜Circular 圆形构图｜Radial 放射构图｜Frame Within Frame 框中框（门框、窗框）｜Foreground Framing 前景框架｜Negative Space 负空间（孤独、留白）｜Balanced 均衡 / Unbalanced 失衡｜Visual Weight 视觉重量｜Visual Hierarchy 视觉层级｜Focal Point 视觉焦点｜Look Room / Nose Room 视线空间｜Lead Room 运动前方空间｜Headroom 头顶空间。

## 镜头光学语言（Lens & 光学效果）

Anamorphic 变形宽银幕（水平光晕、椭圆散景、电影感）｜Spherical 球面镜头｜Vintage 复古镜头（低对比、柔和）｜Lens Flare 镜头光晕｜Anamorphic Flare 水平光晕｜Halation 高光晕染｜Bloom 泛光｜Chromatic Aberration 色差｜Vignetting 暗角｜Film Grain 胶片颗粒｜Motion Blur 运动模糊｜Light Leak 漏光｜Trails 拖尾｜Glow 辉光｜Volumetric Fog 体积雾。

## 空间、透视与视差

Foreground 前景｜Midground 中景空间｜Background 背景｜Deep Background 远背景｜Layered Depth 分层空间｜Linear Perspective 线性透视｜Atmospheric Perspective 空气透视（远山朦胧）｜Forced Perspective 强制透视｜Spatial Compression 空间压缩（长焦）｜Spatial Expansion 空间扩张（广角）｜Motion Parallax 运动视差（前中后景不同移动速度）｜Z-Axis Z轴空间（纵深）｜Vanishing Point 消失点｜Horizon Line 地平线。

## 使用要点

1. 景别 + 角度 + 焦段三者组合决定镜头性格：如"低机位 + 广角 + 缓慢推进"=力量感；"高机位 + 长焦"=脆弱感。
2. 焦段写在 Prompt 中能显著提升画面控制力（如"35mm电影镜头""85mm肖像镜头"）。
3. Rack Focus（移焦）是 AI 视频中性价比最高的叙事技巧：一个镜头内完成视觉注意力转移。
4. 广角夸大空间和运动速度，长焦压缩空间、制造窥视/观察感。
