# 19 视觉心理与观众注意力系统

> 定位：18号解决“为什么要拍这个镜头”，本库解决“观众会先看什么、注意力如何移动、为什么这个画面会产生某种心理效果”。它不是构图词库，而是**观众注意力 → 视觉层级 → 视线路径 → 镜头行为**的决策层。
>
> 核心原则：**导演不是把所有信息都给观众看，而是控制观众在什么时间看到什么、先看到什么、错过什么。**

## 一、核心模型

视觉注意力可以近似理解为：

**显著性（Saliency） × 叙事重要度 × 运动变化 × 对比关系 × 期待/悬念 × 视线引导**。

AI Prompt 不要只写“主体突出”，应该明确：

> 谁是第一注意点 → 第二注意点 → 视线移动方向 → 注意力停留时间 → 什么信息被隐藏 → 注意力何时发生转移。

## 二、观众注意力六大来源

| 注意力来源 | 机制 | 常用手段 | 适合表达 |
|---|---|---|---|
| 人脸 | 人类天然优先关注脸部 | 近景、眼神、局部光 | 人物心理 |
| 运动 | 运动比静止更容易抢注意力 | 移动主体、擦镜、突然停止 | 危险、发现、动作 |
| 明暗 | 局部高亮形成视觉焦点 | Spotlight、边缘光、暗背景 | 神秘、揭示 |
| 色彩 | 色彩差异形成显著点 | 单一强调色、互补色 | 产品、关键人物 |
| 构图 | 线条与空间关系引导视觉 | 引导线、框景、负空间 | 等待、孤独、方向 |
| 叙事期待 | 观众知道“应该看那里” | 视线、声音、反应、道具 | 悬念、伏笔 |

## 三、Visual Hierarchy 视觉层级

建立三级层级：

### LEVEL 1：主视觉信息
必须被观众看到，例如人物脸、关键动作、产品标志、凶器、目标物。

### LEVEL 2：辅助叙事信息
帮助理解空间与关系，例如另一人物、门、车辆、环境中的线索。

### LEVEL 3：氛围信息
不能抢主体，例如雾、雨、树叶、背景灯、远处人群。

**规则：** 画面中的视觉层级不要全部处于同一强度。

## 四、Eye Trace 视线追踪

导演可以预设观众阅读路径：

**A → B → C**

例如：

> 男人眼睛 → 他手里的照片 → 照片中的女人 → 切入回忆。

AI Prompt中应明确“视觉引导链”：

> 前景虚化的人物肩膀形成框景，观众首先锁定中景男人的眼睛；男人视线转向画面右侧桌面上的旧照片；照片由侧光局部提亮，成为第二视觉焦点。

## 五、注意力转移机制

| 机制 | 做法 | 心理效果 |
|---|---|---|
| 视线转移 | 人物先看A再看B | 引导观众跟随 |
| 动作转移 | A停下，B开始动 | 注意力从A转B |
| 光线转移 | 光源逐渐照亮B | 信息揭示 |
| 声音先行 | 先听见，再看到 | 悬念 |
| 镜头运动 | 推向次要物体 | 强制聚焦 |
| 遮挡揭示 | 前景移开后露出主体 | 惊奇/发现 |
| 焦点转移 | Rack Focus | 主次关系变化 |
| 反应优先 | 先拍人物反应，再揭示原因 | 悬念 |

## 六、负空间与视觉压力

负空间不是空白，而是**叙事空间**。

### 人物位于画面一侧 + 大面积空区
常用于：

- 等待
- 孤独
- 远方目标
- 威胁方向
- 未发生事件

### 负空间方向必须服务于叙事

> 人物向右看 → 右侧留出空间 = 期待/未来目标。

> 人物背向左侧空区 → 左侧空区变成不安来源。

## 七、人物权力与视觉位置

### 高视觉权力
- 占据画面中心
- 低机位
- 更大的视觉面积
- 清晰轮廓
- 独占焦点
- 背景简化

### 低视觉权力
- 画面边缘
- 被前景遮挡
- 小比例人物
- 高机位
- 大面积负空间
- 背景压过人物

**注意：位置不能孤立使用，必须与Blocking、景别、焦段、灯光联合。**

## 八、遮挡与信息控制

遮挡可以制造三级信息状态：

**完全可见 → 部分可见 → 延迟揭示**。

适合：

- 悬念
- 身份隐藏
- 偷窥感
- 记忆
- 恐怖
- 战斗中的目标消失

Prompt示例：

> 前景雨幕和玻璃反射持续遮挡主体面部，只在人物抬头的瞬间露出眼睛，观众先获得情绪信息，随后镜头才揭示完整身份。

## 九、尺度心理

| 画面关系 | 常见心理 |
|---|---|
| 人物占画面很小 | 孤独、无力、世界巨大 |
| 人物占画面很大 | 压迫、亲密、侵入 |
| 两人几乎等大 | 平等/对峙 |
| 一人远一人近 | 权力差/心理距离 |
| 大量留白 | 等待/空缺 |
| 背景拥挤 | 压力/混乱 |

## 十、对称与非对称心理

### 对称
秩序、权威、制度、仪式、控制、宿命。

### 非对称
不稳定、孤独、冲突、现代感、失衡、危险。

### 从对称到失衡
可作为人物心理变化可视化手段：

> 开场严格中心对称 → 人物遭遇冲突 → Blocking逐渐偏离中心 → 镜头构图不再对称。

## 十一、镜头运动与注意力

镜头运动不只是“酷”，它本质上是注意力管理：

- Push In：收缩注意范围，强化信息
- Pull Out：扩大信息环境，降低主体独占
- Pan：从A寻找/发现B
- Tracking：陪伴主体，让注意力稳定
- Orbit：改变主体与背景关系，突出三维关系
- Reveal：延迟信息
- Whip：强制跳转注意力
- Static：让观众主动观察

## 十二、情绪与注意力密度

### 高情绪
减少无关视觉信息；让注意力集中。

### 低情绪
允许环境承担更多叙事；让观众观察空白和细节。

### 高压迫
缩短视野、减少逃逸空间、增加前景压迫。

### 高悬念
信息不完整 + 视线明确 + 原因延迟揭示。

## 十三、导演注意力脚本 Attention Script

每个关键镜头至少写：

```text
第一注意点：
第二注意点：
第三注意点：
注意力移动路径：
隐藏的信息：
揭示时机：
视觉干扰强度：
最终视觉落点：
```

## 十四、Attention Beat

把镜头拆成注意力节拍：

```text
0–20%：建立第一视觉焦点
20–50%：发生视觉/叙事转移
50–80%：第二信息变成主信息
80–100%：留下最终视觉落点并进入下一镜
```

不要求所有镜头都严格按此比例，只作为设计骨架。

## 十六、AI Prompt转译规则

不要写：

> 画面很有层次、观众注意力集中、很有电影感。

改写成：

> 前景保持低对比虚焦，中景人物为第一视觉焦点；人物视线从画面左侧缓慢转向右侧桌面，桌面目标物使用局部暖光形成第二焦点；背景人群持续低速移动但保持低饱和，避免抢夺主体注意力；镜头最后停留在目标物上。

## 十七、导演最终检查

1. 观众第一眼应该看哪里？
2. 第二眼为什么移动？
3. 哪个信息必须隐藏？
4. 哪个信息必须延迟揭示？
5. 画面里有没有一个视觉焦点抢走了主叙事？
6. 人物视线、光线、构图、镜头运动是否把观众引向同一个地方？
7. 最后一帧观众带走的是什么？

## 十八、核心公式

> **视觉心理镜头 = 叙事目标 + 注意力起点 + 注意力路径 + 信息隐藏 + 信息揭示 + 最终视觉落点。**
