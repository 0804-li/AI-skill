# 02 摄影机运动词库

摄影机运动是 AI 视频 Prompt 的核心控制层。核心原则：**一个镜头确定 1 个主要镜头运动 + 0~2 个辅助运动**，避免同时堆叠推、拉、摇、移、环绕、甩镜、升降导致运动逻辑混乱。

推荐组合示例：
- 人物广告：缓慢推进 + 轻微环绕
- 东方建筑：升镜 + 缓慢推进
- 打斗：跟拍 + 快速环绕
- 情绪：缓慢推进 + 轻微变焦
- 转场：穿越 + 前景遮挡

## 核心运动总表

| 运动词 | 核心定义 | 核心作用 |
|---|---|---|
| 推（Dolly In / Push In） | 摄影机向主体靠近 | 强调、聚焦、情绪递进 |
| 拉（Dolly Out / Pull Back） | 摄影机远离主体 | 揭示环境、扩大空间 |
| 摇（Pan 横摇 / Tilt 纵摇） | 摄影机位置固定，镜头方向改变 | 展示环境和空间 |
| 移（Truck / Tracking） | 摄影机整体横向或纵向移动 | 展示人物与环境关系 |
| 跟（Follow / Tracking Shot） | 摄影机跟随主体 | 增强临场感 |
| 升（Crane Up / Boom Up） | 摄影机向上移动 | 展示规模和空间 |
| 降（Crane Down / Boom Down） | 摄影机向下移动 | 揭示主体 |
| 环绕（Orbit / Arc Shot） | 摄影机围绕主体运动 | 展示主体和空间 |
| 穿越（Fly-through / Push-through） | 摄影机穿过空间或物体 | 沉浸、探索、转场 |
| 变焦（Zoom In / Out） | 改变焦距（位置基本不动） | 强调视觉重点 |
| 甩镜（Whip Pan / Whip Tilt） | 摄影机快速转动 | 动态、转场 |
| 希区柯克变焦（Dolly Zoom / Vertigo） | 摄影机运动 + 反向变焦 | 心理空间变化 |
| 长镜头（Long Take / One-Take） | 连续运动不明显剪辑 | 沉浸感和真实感 |
| 主观镜头（POV） | 模拟人物视角 | 增强代入感 |
| 过肩镜头（OTS） | 从人物肩后拍摄 | 建立对话与关系 |
| 固定镜头（Static / Locked-Off） | 摄影机不移动 | 稳定、观察、悬念 |

## 各运动详解与成品 Prompt

### 推镜（Dolly In）

适用：强调、靠近、情绪递进、发现、角色登场。

- 人物/情绪："人物保持静止，摄影机缓慢向人物面部推进，背景逐渐虚化，人物眼神成为视觉中心。"
- 产品："产品静置于画面中央，摄影机缓慢推进，产品材质与结构细节逐渐显现。"
- 建筑："摄影机从建筑前方缓慢向建筑主体推进，建筑细节逐渐清晰，前景产生轻微视差。"
- 东方场景："摄影机缓慢穿过薄雾向东方宫殿推进，前景金色树枝轻微摆动，宫殿逐渐从雾中显现。"
- 打斗前奏："战斗开始前，摄影机缓慢向人物推进，人物握紧武器，眼神逐渐变得坚定。"
- 剧情："人物发现远处异常，摄影机缓慢推进人物面部，人物表情逐渐发生变化。"

### 拉镜（Dolly Out）

适用：揭示环境、扩大世界、制造孤独感和距离感。

- 情绪："人物独自站在空旷场景中，摄影机持续拉远，使人物逐渐变得渺小。"
- 建筑："摄影机从建筑局部缓慢拉远，逐渐展示完整建筑群和周围环境。"
- 东方场景："摄影机从宫殿屋檐缓慢拉远，逐渐揭示群山、云海和巨大东方建筑群。"
- 产品："产品特写逐渐拉远至完整场景，展示产品与环境之间的关系。"

### 摇镜（Pan / Tilt）

水平摇（Pan Left/Right）：摄影机固定原位，从左向右或从右向左改变拍摄方向。
- 建筑："摄影机固定在原位置，缓慢从左向右水平摇摄，逐渐展示完整东方宫殿建筑群。"
- 东方山水："摄影机缓慢从左向右摇摄，依次展示山水、亭台、桥梁与人物。"

垂直摇（Tilt Up/Down）：
- 人物："摄影机从人物脚部开始，缓慢向上摇摄，经过身体最终到达面部与天空。"
- 建筑："摄影机从宫殿基座缓慢向上摇摄，逐渐展示高耸屋檐、飞檐与天空。"

### 移镜（Truck）

- 人物："人物从左向右行走，摄影机与人物保持平行移动，人物始终位于画面中心。"
- 产品："摄影机沿产品表面横向移动，从左向右展示材质和结构。"
- 东方场景："摄影机沿东方宫殿长廊横向移动，柱廊、灯笼和人物依次进入画面。"

### 跟拍（Follow）

- 正面跟拍（Lead Shot）："人物缓慢向前行走，摄影机同步向后移动，与人物保持稳定距离，并始终保持主体处于视觉中心。"——适合人物出场、英雄登场、广告。
- 背面跟拍："人物背对镜头向前行走，摄影机从人物身后平稳跟随，保持人物与背景空间关系稳定。"——适合探索、旅行、仙侠、剧情。
- 侧面跟拍（Side Tracking）："人物从左向右移动，摄影机与人物保持平行运动，始终维持相同速度。"——适合行走、奔跑、运动广告。

### 升镜与降镜（Crane Up / Crane Down）

- 低位升空："摄影机从人物身后低位缓慢升起，逐渐越过人物肩膀，最终展示完整东方宫殿和群山。"——适合建筑、史诗、结尾。
- 垂直升空："摄影机从地面垂直升起，人物逐渐缩小，城市和环境空间不断展开。"——适合城市、世界观展示。
- 高空下降："摄影机从建筑上方缓慢下降，穿过云雾，逐渐揭示下方站立的人物。"——适合仙侠、神秘场景、角色登场。

### 环绕镜头（Orbit / Arc）

- 人物环绕："人物保持静止，摄影机缓慢围绕人物旋转360度，完整展示人物服装、发型与环境。"——适合角色展示、人物宣传。
- 产品环绕："摄影机围绕产品进行缓慢360度环绕，光线沿产品轮廓移动，完整展示材质和结构。"
- 建筑半环绕（Half Orbit）："摄影机沿建筑前方进行180度弧形运动，从侧面逐渐转向正面，完整展示建筑空间。"

### 穿越镜头（Fly-through）

- 穿过人群："摄影机从人群之间平稳穿过，前景人物不断经过镜头两侧，最终揭示远处主体。"——适合广告、剧情、商业片。
- 穿过建筑："摄影机穿过东方宫殿巨大门洞，从阴影空间进入明亮庭院。"——适合空间转场。
- 穿过前景："摄影机从树枝和花瓣之间穿过，逐渐靠近人物。"
- 穿过烟雾："摄影机缓慢穿过流动雾气，雾气暂时遮挡画面，散开后揭示新的场景。"

### 变焦（Zoom）

AI 视频建议优先使用"摄影机运动 + 焦距变化"，避免大量单纯数码变焦。

- 缓慢推近变焦："摄影机缓慢向人物靠近，同时轻微改变焦距，使人物逐渐从环境中突出。"——适合情绪、剧情。
- 快速变焦（Crash Zoom）："快速拉近人物面部，形成强烈视觉冲击。"——适合惊讶、发现、戏剧节点。

### 甩镜（Whip Pan）

- 左甩/右甩："摄影机快速向左/右甩动，产生自然运动模糊，通过高速运动进入下一场景。"
- 人物甩镜："人物快速从画面前方经过，摄影机快速跟随人物运动方向甩动，利用运动模糊进入下一镜头。"——适合运动、打斗、商业广告。

### 希区柯克变焦（Dolly Zoom / Vertigo Effect）

原理：摄影机向前运动同时反向拉远焦距（或后退同时推进焦距），人物大小基本不变，背景空间明显伸缩。
- 恐惧："人物保持在画面中心，摄影机快速向前推进，同时反向拉远焦距，人物大小基本保持不变，背景空间产生明显伸缩感，营造强烈不安与心理压迫。"
- 震撼："主体保持稳定，摄影机缓慢推进，同时反向改变焦距，背景建筑产生明显空间拉伸，形成强烈视觉冲击。"
- 适合：恐惧、发现真相、世界观崩塌、超现实、心理变化。

### 长镜头（Long Take）

- 人物长镜头："摄影机持续跟随人物运动，不进行明显剪辑，从人物出场一直跟随至场景深处。"
- 空间长镜头："摄影机从室外连续移动进入建筑内部，再穿过长廊进入庭院，整个过程保持连续运动。"
- 动作长镜头："摄影机连续跟随人物完成奔跑、转身、跳跃和攻击动作，不进行明显镜头切换。"

### 主观镜头（POV）

- 第一视角："采用人物第一视角，摄影机模拟人物视线移动，人物向前观察周围环境。"——适合探索、恐怖、剧情。
- 奔跑主观："采用第一视角快速向前奔跑，摄影机产生轻微自然身体晃动，两侧环境快速掠过。"
- 战斗主观："采用人物第一视角观察敌人，摄影机随着身体运动自然晃动，敌人快速接近。"

### 过肩镜头（OTS）

- 双人对话："摄影机位于人物A肩膀后方，以人物A肩膀作为前景，焦点集中在对面的角色B。"
- 人物对峙："摄影机位于角色A肩后，角色A虚化形成前景，焦点集中在正面的角色B。"
- 多人对话："摄影机在人物之间缓慢移动，通过不同人物肩膀作为前景建立空间关系。"

## 运动轨迹进阶

螺旋运动（Spiral）｜螺旋升降（Helical，环绕同时上升/下降）｜8字运动（Figure-Eight）｜螺旋钻入（Corkscrew，快速向内穿越）｜弧形（Arc）｜圆（Orbit）｜直线（Linear）。

特殊设备语言（描述视角时用）：Snorricam 斯诺里摄影机（固定在人物身上，人物移动主体保持画面中心，主观眩晕感）｜Bodycam 身体摄影机｜FPV Drone 穿越机（高速穿越、贴近建筑）｜Wire Cam 钢丝摄影系统｜Motion-Control 运动控制摄影（机械重复轨迹）。

## 易混淆辨析（AI Prompt 中不要混用）

| 易混淆对 | 区别 |
|---|---|
| Dolly ≠ Zoom | Dolly 是摄影机真的移动（透视关系变化）；Zoom 是焦距变化（位置基本不变） |
| Pan ≠ Truck | Pan 是原地旋转；Truck 是摄影机整体横向移动 |
| Tilt ≠ Pedestal | Tilt 是镜头上下旋转；Pedestal 是摄影机整体上下移动（朝向不变） |
| Crane ≠ Zoom | Crane 改变摄影机空间位置；Zoom 只改变焦距 |
| Orbit ≠ Pan | Orbit 围绕主体移动；Pan 固定位置旋转 |
| Follow ≠ Tracking | Follow 强调"跟着主体"；Tracking 强调"运动轨迹" |

## 高级组合（中英对照）

推进+环绕：dolly in while orbiting｜后退+跟拍：tracking backward｜升降+俯仰：crane up with tilt down｜横移+移焦：side tracking with rack focus｜推进+遮挡：dolly in through foreground occlusion｜环绕+拉焦：orbit with focus pull｜航拍+下降：aerial descent｜穿越+升高：fly-through and crane upward｜甩镜+转场：whip pan transition｜变焦+推进（希区柯克）：dolly zoom。

## "揭示"（Reveal）语言

Reveal 是 AI 视频最重要的导演逻辑之一：

reveal the subject 揭示主体｜gradually reveal 渐进揭示｜delayed reveal 延迟揭示｜pull back to reveal the environment 从人物拉到环境｜push in to reveal the character 从环境推到人物｜reveal from behind foreground objects 遮挡揭示｜crane upward/downward to reveal 上升/下降揭示｜orbit around the subject to reveal 环绕揭示。

## "穿越"语言

camera passes through a doorway 穿门｜camera moves through a window 穿窗｜camera flies through trees 穿树林｜camera moves through a crowd 穿人群｜camera travels through architecture 穿建筑｜camera pushes through the object 穿物体｜continuous fly-through 连续穿越空间。

## 摄影机质感词（稳定度控制）

- 稳定：locked camera / static camera / tripod shot / perfectly stabilized / controlled movement
- 平滑：smooth camera movement / silky tracking / fluid camera motion / steady gimbal movement
- 真实：natural handheld / documentary handheld / subtle micro-shake / organic camera movement
- 动态：dynamic tracking / fast push-in / rapid orbit / aggressive handheld / high-speed pursuit camera

## 航拍系统（Aerial Cinematography）

航拍最大价值不是"飞得高"，而是**改变观众对空间的认识方式**——建立地理尺度、环境比例、孤独感、压迫感、神圣感、上帝视角。航拍必须明确：主体锁定 + 相对距离稳定 + 运动方向一致，否则 AI 极易丢主体。

### 航拍十二种核心类型

| 类型 | 英文 | 特征/作用 |
|---|---|---|
| 垂直俯拍 | Top Down | 镜头朝地面 90°，地面成主视觉平面，人物呈几何图形，强调构图不重透视。意义：上帝视角/命运视角/系统视角/人物渺小 |
| 高角度俯拍 | High Angle Aerial | 位于主体上方非完全垂直，适合城市/山谷/战场/角色孤独 |
| 超高空建立 | Extreme Aerial Establishing | 高度极高，主体占比极小，强调"环境>人物""世界>个体" |
| 航拍下降 | Descending Aerial | 天空→城市→建筑→街道→人物，从宏观进微观，常用于开场/地理定位/人物登场/神性降临 |
| 航拍上升 | Ascending Aerial | 人物→屋顶→街区→城市→山脉→云层，人物被世界吞没，常见结尾/告别/悲剧/史诗/命运感 |
| 航拍推进 | Aerial Push In | 从远处飞向主体，空间逐渐压缩，适合城堡/巨型建筑/城市核心/战场目标/神秘区域 |
| 航拍拉远 | Aerial Pull Out | 从主体离开揭示更大空间：人物→房屋→村庄→城市→山川，极强"信息揭示" |
| 航拍侧移 | Aerial Truck | 横向飞行，展示城市横向结构/建筑群/山脉/长城/公路/海岸线/大型人群 |
| 航拍平行跟拍 | Aerial Tracking | 与主体相对平行移动（汽车/摩托/马/船/奔跑者/火车/飞行器），核心要求速度稳定 |
| 航拍环绕 | Aerial Orbit | 围绕主体旋转（90°/180°/270°/360°/540°/连续多圈），主体成视觉中心，适合英雄登场/巨型机械/奇观/情绪高潮 |
| 航拍螺旋 | Spiral Aerial | 同时环绕+上升（或环绕+下降），三维螺旋路径，比普通环绕更史诗/神秘/超现实/梦境 |
| 航拍穿越 | Fly Through | 从空间内部飞行（门洞→建筑内部→窗户→街道→城市；或峡谷→山洞→树林→悬崖→云层）。高级穿越必含：明确起点+明确路径+前景遮挡+中景过渡+远景目标 |

### 航拍高级运动分类

- Reveal Shot：通过移动逐渐揭示新视觉信息（人物背后→摄影机上升→城市出现），核心是"揭示"非"飞"
- Fly Over：从主体上方快速经过，适合城市/战场/森林/山川/公路/海洋
- Dive Shot：快速向下俯冲，感觉坠落/攻击/危险/失控/紧张
- Rise Through：穿过垂直空间上升（街道→建筑缝隙→屋顶→高楼→云层）
- Drop Through：从高空快速下降进入环境
- Orbit Reveal：环绕中同时揭示新空间（角色在森林中央→绕180°后森林后方出现巨大古城）
- Chase Aerial：航拍追逐，适合赛车/飞行器/战争/动作/科幻
- Lead Aerial：摄影机飞在主体前方，主体追赶摄影机（与普通跟拍相反）
- Top-Down Chase：垂直俯拍追踪主体，重点不是主体而是路线变化

### 航拍高度语言

- 低空航拍：速度感强/环境细节丰富/主体比例大/空间纵深强，适合动作/追逐/城市/人物
- 中空航拍：平衡主体+环境，适合剧情/广告/人物建立
- 高空航拍：强调环境/地理/规模
- 超高空航拍：强调宏观世界，人物仅作尺度参照

### 航拍高度变化曲线（不能只写"镜头升高"）

- 匀速上升：史诗/稳定/平静/庄严
- 缓升→快升：前半建人物，后半突然揭示巨大空间
- 快升→缓升：先制造冲击再进壮阔空间
- 快速下降→减速：俯冲感，适合战争/动作/灾难
- 缓慢下降→突然加速：悬疑/恐怖/未知场景

### 航拍朝向语言（必须描述摄影机朝向）

水平前视（接近"飞行"）｜轻微俯视 10°-30°（城市/道路/追踪）｜中度俯视 30°-60°（建立空间）｜极端俯视 60°-90°（几何构图）｜垂直俯拍 90°（Top Down）

### 航拍焦段

超广角 14-24mm（空间巨大/透视夸张/前景突出/速度感强）｜广角 24-35mm（自然环境/城市/人物+环境）｜标准 35-50mm（空间自然）｜中长焦 70-135mm（压缩空间，适合山脉/城市层叠/舞台/建筑/远处人物）｜超长焦 135mm+（强压缩，"山峰与人物似乎很近""城市层层叠叠"）

### 航拍前景设计

高级航拍绝不能"纯天空飞行"，应积极利用：树枝/建筑/墙壁/门窗/烟雾/云/山峰/车辆/人群/电线/雨幕/灯光/雾气，形成前景→主体→背景三层空间。遮挡穿越（Foreground Wipe / Object Occlusion Transition）可作天然转场。

### 航拍常见失败

- 无目标飞行（只写"无人机飞过城市"→ 没有目标。高级写法："低空航拍沿街道高速前进，保持车辆位于画面中心，途中逐渐升高，从街道层级揭示城市天际线"）
- 高度变化无逻辑（100m→500m→20m 空间跳变）
- 主体丢失（AI 尤其容易出现主体消失/缩小/位置漂移/尺寸异常）

## 分屏系统（Split Screen）

将一个完整画面分割为两个或多个同时存在的视觉区域，既可同时呈现不同地点和行动，也可制造同一演员出现在同一画面的效果。

### 分屏类型

二分屏（左+右 或 上+下）｜三分屏（左/中/右 或 上/中/下）｜四分屏（2×2，适合多人物/多地点/多事件/时间并行）｜多窗口分屏（大小不一窗口，接近监控/社交媒体/新闻/科技/数字界面）

### 分屏六大叙事用途

1. 平行叙事：不同地点同时发生事件（A准备开枪 / B正在逃跑 / C正在赶来）
2. 时间并行：同一时刻不同人物发生不同事
3. 空间并行：两个空间同时存在（卧室+厨房）
4. 对比叙事：左边贫穷/右边奢华，形成价值对照
5. 人物心理：把心理不同层面分开（表层微笑+内心恐惧）
6. 同一人物复制：一个人物同时存在于多个位置

### 分屏空间设计（不是简单"切两半"）

- 视线方向：左侧人物向右看 + 右侧人物向左看 = 视觉交流
- 动作方向：左→右 与 右→左 形成对冲
- 构图对齐：人物眼睛高度一致 / 地平线一致 / 建筑线一致 / 门框一致 = 视觉同步

### 分屏高级形式

- 动态图形分屏（Dynamic Split Screen）：全屏→中间裂缝→裂成左右→第三画面从缝隙进入→重新合并
- 不规则分屏（三角/圆形/菱形/斜切/曲线/人物轮廓）
- 斜向分屏（对角线切割，更动态/激进/时尚/广告化）
- 嵌套分屏（画面→小画面→小小画面，适合科幻/监控/数字宇宙）
- 镜像分屏（左右镜像关系，一个人物面对自己镜像）
- 时间分屏（同地点同人物不同时间同时出现：左年轻/右老年）

## 倒放系统（Reverse Motion）

将已拍摄动作以反向时间顺序呈现，本质是**视觉时间方向倒置**。可对正常素材时间反转，也可通过反向表演拍摄实现更可信的动作逻辑。

### 倒放类型

完整倒放（整段素材全倒）｜局部倒放（只倒某一动作，如玻璃破碎→恢复完整）｜动作倒放（只逆转动作）｜环境倒放（雨滴向天空飞/烟雾回到爆炸点/沙尘回地面）｜物体倒放（碎片回物体/水回杯子/纸张恢复/建筑碎片重组）｜人物倒放（后退反向/跳跃反向/摔倒反向/奔跑反向）

### 倒放设计原则（核心）

倒放 ≠ "把正常动作反过来"。高级倒放要思考：**什么东西在现实中不会自然发生，但反向之后具有视觉意义？**
- 火焰回到火源
- 鲜血回到伤口
- 烟雾回到爆炸中心
- 碎玻璃回到杯子
- 落叶重新回到树枝
- 人群向后聚合
- 水滴回到云层

### 倒放与正放结合

正放→倒放（动作完成后瞬间反转）｜倒放→正放（先呈现超现实状态再恢复正常时间）｜正→倒→正（时间循环，适合梦境/记忆/时间循环/超现实/MV）

### 倒放与速度设计

可组合慢动作/快动作/冻结/时间跳跃/时间拉伸/时间压缩。例：正常落地→慢动作→突然倒放→极速倒放→冻结，产生极强视觉冲击。
