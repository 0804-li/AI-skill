# 20 摄影机物理与镜头光学系统

> 定位：03号解决“拍什么尺度、从什么位置看”，02号解决“摄影机怎么运动”，本库进一步解决**摄影机和镜头为什么会产生这样的物理视觉结果**。用于把“电影感、真实感、压迫感、空间感”转译为可执行的摄影变量。
>
> 核心原则：**焦段决定空间关系，机位决定视角，景深决定注意力，快门决定运动表现，传感器与镜头决定成像性格。**

## 一、摄影机状态六要素

```text
Camera Body
Lens
Position
Orientation
Exposure
Motion
Focus
```

AI Prompt至少明确其中与镜头目标相关的变量，不必每镜全部写满。

## 二、传感器/画幅对视觉的影响

| 类型 | 常见视觉倾向 | 用途 |
|---|---|---|
| 大画幅/大传感器 | 更容易获得浅景深与主体分离 | 人物、广告、情绪 |
| Super 35类电影画幅 | 经典电影视觉关系 | 剧情、动作 |
| 更小传感器 | 景深更深、空间整体清晰 | 新闻、纪实、空间叙事 |

**注意：** 不要把传感器当作“电影感按钮”；实际效果还与焦距、机位、主体距离、光圈有关。

## 三、焦距的真正作用

焦距不是简单的“远近”。

### 广角
- 扩大近远关系
- 强化前景
- 夸张空间纵深
- 近距离人物更容易产生透视夸张
- 适合环境、沉浸、速度、夸张动作

### 标准焦段
- 空间关系较自然
- 适合人物、对话、叙事
- 视觉不强行表达

### 中长焦/长焦
- 压缩空间层次
- 拉近远近物体的视觉距离
- 减少背景透视夸张
- 适合窥视、压迫、肖像、远距离观察

## 四、机位距离与透视

**透视变化主要来自摄影机位置变化，而不是焦距本身。**

AI Prompt中需要区分：

> 摄影机靠近人物后用广角

与：

> 摄影机远离人物后用长焦保持人物大小。

两者虽然都可以保持相近人物尺寸，但空间感觉完全不同。

## 五、光圈与景深

| 光圈倾向 | 视觉效果 |
|---|---|
| 大光圈 | 浅景深、主体分离、背景虚化 |
| 中等光圈 | 人物与部分环境兼顾 |
| 小光圈 | 更深景深、环境信息更多 |

### AI使用规则
不要只写“F1.4电影感”。应该说明：

> 近距离人物特写，大光圈浅景深，眼睛清晰，耳朵与背景逐渐柔化。

## 六、对焦系统

### Focus Lock
固定主体焦点，适合稳定人物/产品。

### Rack Focus
焦点从A转向B，适合信息揭示。

### Pull Focus
摄影机运动中主动维持或改变焦点。

### Focus Hunting
不应被当成高级效果；除非刻意模拟纪实/真实摄影，否则应避免无意义来回搜焦。

## 七、Lens Breathing

变焦/对焦过程中视场角发生轻微变化，称为镜头呼吸。

适合：

- 真实摄影感
- 手工对焦质感
- 近距离人物情绪

不适合：

- 极端稳定的广告产品镜头
- 要求严格构图锁定的工程镜头

## 八、Motion Blur与快门语言

运动模糊决定动作在单帧中如何被记录。

### 运动模糊较明显
适合：

- 速度
- 打斗
- 快速转场
- 手持纪实

### 运动模糊较少
适合：

- 高速动作的清晰分解
- 产品广告
- 动作分析
- 超现实冻结感

## 九、Shutter Angle / 曝光时间思维

不要机械记参数；从最终视觉效果反推：

> “动作应该是自然电影运动拖影”

> “动作应该像极短曝光一样锐利”

> “人物运动中需要明显拖影表现速度”

然后再选择相应快门/运动模糊策略。

## 十、镜头光学特征

| 特征 | 作用 |
|---|---|
| Bokeh | 背景高光虚化形态 |
| Anamorphic Flare | 横向眩光、宽银幕特征 |
| Halation | 高亮边缘的胶片式光晕 |
| Bloom | 高光柔化 |
| Vignette | 边缘压暗、聚焦中心 |
| Chromatic Aberration | 色散，少量可增加镜头真实感 |
| Barrel Distortion | 广角桶形畸变 |
| Pincushion Distortion | 长焦/特定镜头边缘形变 |
| Ghosting | 眩光重影 |
| Filter Glow | 特殊滤镜柔化 |

**原则：** 光学瑕疵应是“成像性格”，不是无脑叠加特效。

## 十一、Anamorphic vs Spherical

### Spherical
- 画面相对自然
- 几何控制较稳定
- 产品、建筑、清晰叙事常用

### Anamorphic
- 更明显的横向眩光
- 椭圆散景倾向
- 具有宽银幕电影联想
- 适合史诗、都市夜景、商业大片

## 十二、视场角与空间心理

### 宽视场
> 主体+环境+前景均具有强空间关系。

### 窄视场
> 视觉世界被切窄，突出主体、压缩背景。

## 十三、摄影机物理与人物距离

特别注意：

> 镜头越靠近脸部，轻微机位变化都会造成明显透视变化。

AI人物特写应避免：

- 摄影机近距离大幅横向移动
- 同时强烈变焦
- 人物头部朝向频繁变化
- 复杂表情与复杂运镜同时发生

## 十四、运动设备选择

| 设备 | 视觉特征 | 适合 |
|---|---|---|
| Tripod | 稳定 | 情绪、对话、仪式 |
| Shoulder | 人体参与感 | 纪实、冲突 |
| Handheld | 微不稳定 | 紧张、真实 |
| Steadicam | 平滑但有人体重量感 | 长镜头、跟随 |
| Gimbal | 平滑、轻盈 | 商业、移动展示 |
| Dolly | 轨迹明确、稳定 | 电影叙事 |
| Crane/Jib | 高低空间变化 | 史诗、揭示 |
| Drone | 俯视/大尺度空间 | 环境、过场 |

## 十六、摄影机物理冲突诊断

### 典型冲突

“广角近拍 + 极浅景深 + 大幅横移 + 快速环绕 + 人物大幅转头”

问题：摄影机、透视、焦点、表演复杂度同时上升。

修复策略：

> 保留一个主运动，降低镜头复杂度；先稳定人物状态，再改变摄影机。

## 十七、AI Prompt转译模板

```text
摄影机：电影级稳定摄影机，镜头焦段[焦段]，机位高度[高度]，与主体保持[距离]；
镜头光学：[球面/变形宽银幕]，景深[浅/中/深]；
焦点锁定[对象]，在[时间节点]进行Rack Focus到[对象]；
运动：[主运动]，速度[慢/中/快]，保持运动轨迹连续；
运动模糊：[低/自然/明显]；
光学特征：[轻微散景/眩光/halation等]，仅作为成像性格，不喧宾夺主。
```

## 十八、最终检查

1. 焦段选择是否服务空间关系？
2. 摄影机位置是否合理？
3. 景深是否符合主体数量？
4. 对焦对象是否明确？
5. 运镜是否与焦段/人物动作冲突？
6. 光学瑕疵是否有必要？
7. 多镜头Camera State是否连续？

## 十九、核心公式

> **摄影机物理 = 机位 + 焦段 + 主体距离 + 对焦 + 景深 + 曝光/快门 + 运动方式 + 镜头光学性格。**
