# 15 人物站位与场景一致性词库

AI精品电影最难的不是单镜头好看，而是**多镜头连续生成时人物在同一个空间里、不漂移、不瞬移、不换脸**。本词库解决：人物站位(Blocking)怎么设计、人物位置怎么锁定、场景空间怎么保持一致、多镜头怎么继承状态。涵盖：站位系统总论、人物锚点、九宫格、多人物站位、朝向视线系统、180度规则、位置锁与身份锁、连续性状态机、场景一致性、固定区与变量区、AI空间锚定法、六种站位模式、经典构图、漂移修复、三张核心地图、Prompt模板库、18步工作流、检查评分系统、最终知识模型。

**核心原则：固定人物不是把人物钉死在画面里，而是把人物钉在一个稳定、可解释、可继承的三维电影空间里。** 01号词库解决"人物怎么动"，本词库解决"人物站在哪里、为什么站在那里、多镜头怎么保持不动"。

## 一、人物站位系统总论

人物站位（Blocking）不只是"人物站在哪里"，而是导演通过安排人物在空间中的**初始位置、移动路线、停留点、朝向、视线、人物间距离、高低关系、前后关系、出入场、道具互动、与摄影机关系**来组织剧情、权力、情绪、视觉注意力和空间连续性。

- **Blocking** = 演员站在哪里、怎么走、什么时候动
- **Staging** = 导演如何安排人物、场景和摄影机共同形成画面
- **Screen Direction** = 人物在画面中左→右/右→左/前→后/后→前
- **Spatial Continuity** = 人物和场景之间前后/左右/上下/远近关系持续稳定

**人物站位 = 人物在三维空间里的叙事坐标系统。** 人物站在哪里，本身就是叙事——远离他人=孤立疏离；靠近=亲密依赖威胁；中心=权力主导核心；边缘=边缘人物观察者；被遮挡=隐秘不确定心理压迫。

## 二、人物锚点系统

人物锚点是人物在场景中的**固定参考位置**。AI生成时如果不定义锚点，每镜人物位置都会漂移。

### 七种锚点类型

| 锚点类型 | 定义 | 示例 |
|---|---|---|
| 地面锚点 | 人物双脚对应地面固定位置 | 人物固定站在屋顶防护墙左侧 |
| 建筑锚点 | 人物与门/窗/柱/墙/楼梯形成固定关系 | 人物始终站在窗户左侧 |
| 家具锚点 | 人物与大型家具形成固定关系 | 人物始终坐在沙发左侧靠窗位置 |
| 道具锚点 | 人物与关键道具形成固定关系 | 人物始终位于厨房岛台右侧距炉灶一步 |
| 视觉锚点 | 人物始终处于画面特定位置 | 人物始终在画面左三分之一处 |
| 行为锚点 | 人物的行为定义其位置 | 人物始终站在窗边读书 |
| 关系锚点 | 人物A始终在人物B的特定方位 | A始终在B左前方 |

### 三层锚定法

建立锚点的层级关系：**建筑锚点 → 家具锚点 → 人物锚点**。例如：窗户（建筑层）→ 岛台（家具层）→ 站在岛台右侧（人物层）。三层之间形成稳定的参照链。

### 三锚点稳定法 & 五锚点稳定法

- **三锚点**：人物 + 一个大型家具 + 一个建筑结构（如：人物=岛台右侧，家具=冰箱左后方，建筑=窗户右后方）。只要A-B、A-C、B-C关系保持，整个空间就稳定。
- **五锚点**：人物 + 门 + 窗 + 大型家具 + 视觉中心道具，五点之间形成空间关系网络。

## 三、九宫格人物站位系统

把画面划分为九宫格，每个区域有不同叙事功能：

```
┌────────┬────────┬────────┐
│ 左上   │ 中上   │ 右上   │
│ 观察   │ 高位   │ 远端   │
│ 高处   │ 站立   │ 被环境 │
│ 次要   │ 人物   │ 包围   │
├────────┼────────┼────────┤
│ 左中   │ 中中   │ 右中   │
│ 对话   │ 主角   │ 对话   │
│ 行走   │ Hero   │ 视觉   │
│        │ Shot   │ 焦点   │
├────────┼────────┼────────┤
│ 左下   │ 中下   │ 右下   │
│ 边缘   │ 稳定   │ 进入   │
│ 退出   │ 构图   │ 方向   │
└────────┴────────┴────────┘
```

这些不是固定规则，而是构图与叙事设计的常用位置。

## 四、多人物站位模式

### 双人物三种核心站位

| 站位 | 图示 | 适合 |
|---|---|---|
| 面对面 | A↔B | 冲突、谈判、爱情、对峙 |
| 并肩 | A B →→ | 关系亲密、行走、合作 |
| 一前一后 | A→B | 威胁、追随、权力 |

### 三人物站位

三角形站位（A上方，B/C下方）——非常稳定，适合对话、权力关系、群像。一人对两人（A上方，B/C下方）——适合审判、冲突、谈判。

### 四人物以上

多人场景避免"大家平均分布"，使用**主次层级**：一级人物A（★5）→二级人物B、C（★3）→三级人物D、E（★1）→群众（★）。利用景别、景深、明暗、位置、遮挡、服装控制注意力。

### 六种空间关系

| 关系 | 说明 | 示例 |
|---|---|---|
| 左右关系 | A在左B在右 | Shot/Reverse Shot基础 |
| 前后关系 | A在前景B在背景 | 空间层次 |
| 高低关系 | A站楼梯上方B在下方 | Vertical Power Blocking |
| 内外关系 | A在屋内B在门外 | 隔离/威胁 |
| 包围关系 | 多人围住一人 | 审判/围困 |
| 对角关系 | A左前B右后 | 斜线构图 |

### 视觉权力站位

- **中央站位**：英雄登场、神性、权力、仪式、正面对峙。长期使用产生强制视觉中心感
- **边缘站位**：孤独、被排斥、观察者、不确定、留白
- **负空间站位**：人物只占画面10%，环境很大→孤独、渺小、命运、环境压迫
- **垂直权力Blocking**：高位人物站台阶上，低位人物坐地上→权力差异无需对白

### 权力站位设计

会议室：老板=桌子尽头，下属=两侧，新人=远端。角色地位变化→位置变化：开场坐最边缘→剧情发展逐渐坐到中心=权力上升视觉化。空间弧线：角落→站起来→走到中央→走出门=心理成长。

## 五、人物朝向与视线系统

### 朝向三层（三者不一定一致）

| 层级 | 说明 | 示例 |
|---|---|---|
| Body Direction | 身体朝向 | 身体朝右 |
| Head Direction | 头部朝向 | 头转向左 |
| Eye Direction | 眼睛方向 | 看后方 |

这是非常重要的表演信息——身体朝右但头转左眼看后方，可以表达犹豫、回望、不安。

### 人物与镜头夹角

| 夹角 | 效果 |
|---|---|
| 正面 | 直接 |
| 3/4侧面 | 最常用，具有立体感 |
| 侧面 | 强调关系和轮廓 |
| 背面 | 神秘、孤独 |
| 背后3/4 | 非常适合跟拍、等待、眺望 |

### 三种视线

| 视线类型 | 效果 |
|---|---|
| Direct Look（直视摄影机） | 主观、对抗、第四墙感 |
| Off-screen Look（看画面外） | 悬念、等待、信息预示 |
| Eyeline to Character（看另一人物） | 对话 |

**Eyeline Match**：镜头A人物看画面右侧→镜头B另一人物应位于相应视线方向→观众自然理解"他在看对方"。

## 六、180度规则

设定：人物A与B之间存在一条虚拟轴线，摄影机保持在轴线同一侧。

- A=左，B=右→连续镜头中A、B左右关系尽量稳定→空间可读性
- AI多镜头：第一镜建立A左B右→之后全部镜头保持A左B右→除非主动设计过轴

### 什么时候可以过轴

有意识地过轴用于：迷失、精神崩溃、权力翻转、梦境、混乱、恐怖、主观不稳定。关键是让越轴本身有叙事意义。

### 安全过轴方法

| 方法 | 操作 |
|---|---|
| 中性镜头 | 使用正对轴线的中性镜头过渡 |
| 展示跨轴 | 镜头内展示摄影机跨轴移动 |
| 重新建立轴线 | 通过人物移动重新建立空间关系 |
| 遮挡过轴 | 利用前景遮挡完成重新定位 |

## 七、人物位置锁与身份锁

### 位置锁 vs 身份锁必须分开

很多AI创作失败：角色看起来是同一个人但位置变了，或位置相同但人物换脸了。必须建立两套独立规则：

- **Character Identity Lock**（身份锁）：面部、服装、身体比例、道具、行为特征
- **Character Position Lock**（位置锁）：空间锚点、与家具关系、与建筑关系、前后左右关系

### 动作分级（Level 0-5）

| 级别 | 内容 | 说明 |
|---|---|---|
| Level 0 | 完全静止 | 极少用，容易做成蜡像 |
| Level 1 | 呼吸、眨眼 | 肖像、极静情绪 |
| Level 2 | 头部、眼神 | 对话、观察 |
| Level 3 | 手臂、轻微身体动作 | 大部分剧情场景 |
| Level 4 | 原地转身 | 情绪转折 |
| Level 5 | 离开锚点 | 只有剧情需要才进入 |

**"人物不动"容易被理解为完全静止。** 更专业：**"人物保持固定空间站位，仅允许头部、眼神、手臂和身体微动作变化。"**

### 原地动作 vs 位移动作

| 类型 | 动作 | 特点 |
|---|---|---|
| 原地动作 | 抬手、转头、低头、点头、整理衣服 | 不改变空间锚点 |
| 位移动作 | 向前走、向后退、横移、走到门口、坐下、起身 | 改变空间锚点，AI Prompt必须区别描述 |

### Blocking State（站位状态机）

```
S0 起始站位 → S1 转身 → S2 向前一步 → S3 到达桌边 → S4 坐下 → S5 离场
```

### 连续性状态表

| 镜头 | 人物位置 | 状态 | 朝向 | 动作 |
|---|---|---|---|---|
| 01 | 门口 | S0 | 朝内 | 站立 |
| 02 | 门口 | S0 | 朝右 | 看向B |
| 03 | 走向桌边 | S1 | 前进 | 行走 |
| 04 | 桌边 | S2 | 朝B | 停下 |
| 05 | 桌边 | S2 | 朝B | 对话 |
| 06 | 椅子旁 | S3 | 朝下 | 坐下 |

### 道具状态机

```
手机 S0(桌上) → S1(拿起) → S2(使用) → S3(放回) → S4(掉落) → S5(损坏)
```

## 八、连续性状态系统

### 首帧-尾帧连续系统

每个AI镜头建立：**Start State（起始状态）→ Motion（动作）→ End State（结束状态）**。下一镜头的Start State = 上一镜头的End State。

```
镜头01: Start=门口站立 → Motion=走入房间 → End=桌旁
镜头02: Start=桌旁 → Motion=转身 → End=面向窗
镜头03: Start=面向窗 → Motion=走向窗边 → End=窗边
镜头04: Start=窗边 → Motion=抬头 → End=注视天空
```

### 状态继承原则

镜头2继承镜头1的：角色、位置、道具、场景、时间、光线。只修改当前动作。

### Persistent World State（持久世界状态）

整个AI短片的"世界状态"：

```
SCENE-01:
  Architecture: 固定
  Furniture: 固定
  Lighting: 固定
  Character A: 固定
  Character B: 固定
  Props: 固定
  Weather: 固定
  Time: 黄昏
```

任何镜头都从这个状态开始。可变参数：Camera、Character Action、Emotion、Focus。不可变：Architecture、Furniture、Character Position、Props。

### 服装连续性

锁定：衣服、颜色、材质、扣子、袖子、配饰、鞋子。人物站在窗边穿红色外套→下一镜还是红色外套→否则即使位置正确身份也会漂移。

### 姿态连续性

镜头A结束：右手放桌上→镜头B开始：右手仍在桌上。这是Pose Continuity。

### 动作连续性 & Match on Action

镜头A人物开始推门→镜头B继续推门→观众感知一个完整动作。AI Prompt写法："保持前一镜头动作连续，人物从右手触碰门把开始，下一镜继续保持右手与门把接触，动作不重置、不跳跃。"

## 九、场景一致性系统

### 场景一致性不是"背景看起来差不多"

而是：**空间拓扑关系保持一致。** 厨房中门→岛台→灶台→窗户→水槽的关系即使材质、光线、镜头变化，这些基本关系仍然存在。

### 场景一致性四级

| 级别 | 内容 |
|---|---|
| Level 1 | 整体建筑一致 |
| Level 2 | 主要家具一致 |
| Level 3 | 主要道具位置一致 |
| Level 4 | 人物与物体空间关系一致（最重要） |

### 七个固定元素

优先固定：1.建筑结构 2.门窗 3.大型家具 4.关键道具 5.主要光源 6.人物锚点 7.摄影机方向。

### 不可变资产 vs 可变资产

| 类型 | 内容 | 规则 |
|---|---|---|
| Static Assets（不可变） | 门、冰箱、岛台、灶台、水槽、窗户 | 不可改变 |
| Variable Assets（可变） | 食材、杯子、椅子、装饰、灯光强度、烟雾、人物动作 | 可变化 |
| Dynamic Assets（动态） | 动作、光线、天气、粒子 | 为叙事服务 |

### 背景三层

| 层 | 内容 | 规则 |
|---|---|---|
| Structural Layer | 建筑结构 | 不能变化 |
| Prop Layer | 大型道具 | 尽量固定 |
| Atmosphere Layer | 烟雾、雨、光、粒子 | 可以变化 |

### 场景锁定模板

每次生成镜头时先固定：场景ID → Character ID → Anchor Position → 最后变化Camera/Action/Lighting/Time。

### 光照锁 & 天气锁 & 时间锁

- **光照锁**：连续镜头固定主光方向、光源位置、色温、阴影方向、大致光比
- **天气锁**：雨景保持地面湿度、雨势、云层、服装湿度、人物头发湿度
- **时间锁**：黄昏维持太阳高度、天空颜色、窗光、人物阴影

## 十、固定区与变量区

最实用的AI多镜头方法——**场景固定，镜头变化**：

```
FIXED:
  现代公寓厨房
  L型布局
  中央岛台
  窗户在右后方
  冰箱在左后方
  人物A固定站在岛台右侧
  浅木橱柜
  白色石材台面
  夕阳从右侧进入

VARIABLE:
  Camera: 慢慢推进
  Action: 人物切菜
  Focus: 从刀转移到人物眼睛
  Emotion: 紧张
```

### Master Scene（场景母图）

生成多个镜头前，先生成完整场景总览图，确定门、窗、冰箱、岛台、灶台、桌、人物的位置。之后所有镜头都从母场景出发。

### Master Blocking Frame（站位母图）

包含：人物 + 场景 + 人物位置 + 人物朝向 + 主要道具 + 光线 + 摄影机初始位置。不是只生成人物母图或场景母图，而是生成"人物在场景中的标准站位母图"。

### 五图锁定系统

| 图 | 内容 |
|---|---|
| 图1 | 场景全景 |
| 图2 | 人物正面 |
| 图3 | 人物侧面 |
| 图4 | 人物在场景中的固定站位 |
| 图5 | 关键道具布局 |

## 十一、AI空间锚定法

### 语义坐标比数字坐标更适合AI

推荐描述：岛台右侧、门旁、窗边、沙发左端、书桌后方、楼梯底部、柱子右侧——这些关系对视觉模型更容易表达。

### 对象关系定位（Object-to-Character Relation）

不是"人物X=300"，而是"人物位于冰箱右侧、窗户下方、岛台后方"。

### 人物锚点矩阵

| 元素 | 位置 | 关系 |
|---|---|---|
| 人物A | 岛台右侧 | 距岛台0.5m |
| 冰箱 | A左后方 | 固定 |
| 水槽 | A正前方 | 固定 |
| 窗户 | A右后方 | 固定 |
| 门 | A左侧远处 | 固定 |
| 摄影机 | 岛台外侧 | 初始机位 |

### 场景坐标系统

```
        北
        ↑
  ┌──────────────┐
  │    窗户       │
  │              │
西│   A ●        │东
  │              │
  │ 门    冰箱   │
  └──────────────┘
        ↓
        南
```
人物A：固定在X=60%，Y=55%，Z=中景层。

### 反向描述法

当AI难以理解"人物固定在某个位置"时，反过来写："窗户、冰箱、岛台始终保持固定位置，人物始终位于它们形成的三角空间中心。"——用环境反向约束人物。

### 三角空间锁

人物A + 场景锚点B、C、D，保持A-B、A-C、A-D关系。比仅固定A的位置更稳定。

### 世界坐标 vs 屏幕坐标

| 概念 | 说明 | 示例 |
|---|---|---|
| 世界坐标 | 人物在真实场景哪里 | 岛台右侧 |
| 屏幕坐标 | 人物出现在画面左/中/右 | 画面左侧 |

摄影机运动后屏幕位置可以改变，因此：**固定人物位置≠固定画面位置。** 摄影机转到人物右后方拍摄，人物仍应在世界同一位置，虽然画面位置自然变化。

## 十二、六种AI站位模式

| 模式 | 说明 | 适合 | Prompt示例 |
|---|---|---|---|
| Fixed（完全固定） | 人物不动 | 肖像、产品、对话、情绪 | "人物保持固定站位，不改变空间位置" |
| Anchored（锚点固定） | 锚点固定，小动作允许 | 大部分剧情场景 | "人物保持在岛台右侧固定锚点，仅进行上半身自然动作" |
| Path（路径运动） | 沿固定路径运动 | 走廊、入户、出退 | "人物从门口沿桌子左侧直线走到窗边，不改变路径" |
| State（状态切换） | 在几个固定状态点之间切换 | 多段走位 | "人物依次经历门口站立、桌边停留、窗边停留三个固定空间状态" |
| Orbit（环绕） | 人物固定，摄影机绕人物 | 角色介绍、英雄登场、产品广告 | "人物保持脚部位置固定，摄影机围绕人物顺时针180度移动" |
| Dynamic Blocking | 人物和摄影机同时移动 | 最高难度，打斗、追逐 | 需建立多对象空间关系 |

### Blocking与摄影机运动配合难度

| 组合 | 难度 |
|---|---|
| 人物不动 + 摄影机动 | 最容易控制 |
| 人物动 + 摄影机不动 | 次容易 |
| 人物动 + 摄影机同向动 | 中等 |
| 多人物动 + 摄影机动 | 困难 |
| 多人物 + 摄影机 + 场景变化 | 最高难度 |

### 八种漂移

| Position Drift | 人物位置漂移 |

### 漂移原因与修复

| 原因 | 修复方法 |
|---|---|
| Prompt过于泛化 | 增加固定空间锚点 |
| 没有空间锚点 | 指定与某物体的关系 |
| 背景没有固定 | 固定背景建筑/家具 |
| 镜头运动过复杂 | 减少镜头复杂运动 |
| 人物与摄影机同时变化 | 先做Master Blocking Frame，固定Start/End State |

### 位置差异分级

| 级别 | 判断 |
|---|---|
| 微小偏差 | 正常透视变化 |
| 轻微偏差 | AI可能容忍 |
| 明显偏差 | 空间关系开始不自然 |
| 严重偏差 | 人物已经瞬移 |
| 致命偏差 | 空间本身重新生成 |

## 十五、核心原则

### 一镜一变量原则

场景复杂时，一个镜头最好只改变一个主要变量：
- 镜头1：改变摄影机
- 镜头2：改变人物动作
- 镜头3：改变焦点
- 而不是：人物+场景+灯光+摄影机+道具同时改变

### 两锁一变原则

每个AI镜头至少锁定两个核心维度，只改变一个：
- 人物位置锁 + 场景锁 → 只改摄影机
- 人物位置锁 + 场景锁 → 只改人物动作

### 反应式Blocking

人物完成动作→摄影机才开始移动。人物突然发现门→摄影机缓慢推近。非常具有电影感。

### 空间连续五锁

| 锁 | 内容 |
|---|---|
| 锁1 | 建筑结构 |
| 锁2 | 大型家具 |
| 锁3 | 人物位置 |
| 锁4 | 人物关系 |
| 锁5 | 光线方向 |

动作与摄影机才作为主要变量。

### 固定人物+变摄影机

人物固定在屋顶边缘→正面→45°→侧面→背面→高空。保持场景连续+获得多种镜头。Prompt："人物始终站在场景中心固定位置，摄影机围绕人物缓慢270度环绕，人物脚部位置和与地面关系不变。"

### "固定站位"≠"固定构图"

人物可以固定在同一个场景位置，但摄影机可以推进、拉远、横移、环绕、升高、降低，产生不同画面。

### Static Character + Dynamic Environment

人物不动 + 环境变化（下雨、下雪、烟雾、风、人群经过）。非常适合AI。

### 角色锚点转场

人物固定在同一个位置→A世界→环境变化→B世界。适合时间变化、世界转换、角色成长、AI广告。

## 十六、三张核心地图

每个重要场景建立三张地图：

| 地图 | 回答 | 内容 |
|---|---|---|
| Blocking Map | 人物在哪里 | 人物位置+朝向+视线+移动路径 |
| Camera Map | 摄影机在哪里 | 摄影机机位+活动区域+运动方向 |
| Continuity Map | 什么绝对不能改变 | 建筑/家具/人物/道具/光线锁定层 |

### Blocking Map（站位图）

```
  ┌──────────────┐
  │    窗户       │
  │              │
  │   A ●→看B    │
  │   ↑          │
  │   冰箱       │
  │              │
  │ B ●→看A      │
  │    门        │
  └──────────────┘
```

### Camera Zone（摄影机活动区域）

把场景划分成摄影机可活动区域，限制摄影机不能任意穿墙、跳位。人物固定Anchor + 摄影机在Zone里移动 = 人物稳定 + 摄影机自由。

### Coverage Map（镜头覆盖图）

记录固定Blocking下的多角度覆盖：C01正面、C02左前45°、C03右前45°、C04侧面、C05背面、C06高机位、C07低机位、C08环绕。固定Blocking + 多角度Coverage建立完整场景。

## 十七、Prompt模板库

### 人物位置锁定Prompt

> 人物始终固定在厨房中央岛台右侧，双脚保持位于同一地面区域，冰箱始终位于人物左后方，窗户始终位于人物右后方，人物与岛台之间保持稳定距离，除指定动作外不改变站位，不突然移动到其他空间。

### 人物位置锁定关键词

中文：固定站位｜固定位置｜空间锚定｜保持位置｜保持距离｜保持左右关系｜保持前后关系｜保持与家具关系｜不改变空间位置｜不突然移动｜连续空间位置

英文辅助：fixed character position｜spatial anchor｜consistent character placement｜fixed blocking｜stable spatial relation｜consistent left-right relationship｜fixed distance｜persistent position｜unchanged blocking

### 固定区+变量区标准Prompt

> 保持同一固定场景与空间布局：现代L型厨房、中央岛台、右后方窗户、左后方冰箱、浅木橱柜、白色石材台面。人物A始终固定站在岛台右侧，保持与岛台、窗户和冰箱的空间关系不变，人物身份、服装、身体比例保持一致，仅进行指定动作。摄影机从人物正面缓慢推进，焦点从手中的刀转移到眼睛，保持真实透视、固定建筑结构、固定家具位置、固定人物锚点和一致光线方向，不出现人物瞬移、家具漂移、场景重构或空间跳变。

### 单人物完整模板

> 同一固定物理空间，【场景结构】保持完全一致。人物A保持同一身份、服装、身体比例和空间锚点，始终位于【具体位置】，与【锚点物体1】、【锚点物体2】、【锚点物体3】保持稳定相对关系。人物身体朝向【方向】，头部朝向【方向】，视线看向【对象】。从上一镜头继承人物位置、姿态和关键道具状态。当前镜头仅改变【动作/摄影机/焦点】。摄影机使用【焦段】，从【机位】以【运动方式】运动，保持真实透视、稳定空间拓扑、稳定人物比例和连续光线，不出现人物瞬移、左右关系反转、家具漂移、场景重构或空间跳变。

### 双人物模板

> 保持同一真实物理空间和人物站位：人物A始终位于画面左侧/空间左前方，人物B始终位于右侧/空间右前方，两人之间的距离、身高关系和左右关系保持稳定。A的视线始终朝向B，B的视线始终朝向A，摄影机保持在动作轴线同一侧，不跨越180度轴线。仅改变镜头景别与摄影机位置，不改变人物相对空间位置。

### 三人物模板

> 保持固定三角Blocking：人物A位于前景中央，人物B位于中景左侧，人物C位于中景右侧，三人之间的前后与左右关系保持稳定。A主要与B交流，C在背景观察。摄影机可以横移、推进或环绕，但三个角色的物理位置不发生无理由改变，保持稳定视线和空间拓扑。

### 固定厨房Prompt

> 同一现代家庭厨房，固定L型空间布局，中央岛台、窗户、冰箱、灶台和水槽的位置始终不变。人物A始终站在岛台右侧固定锚点，冰箱保持在其左后方，窗户保持在其右后方，人物与岛台保持稳定距离。人物只进行原地切菜、抬头、转头和观察门口等上半身动作，不离开锚点。摄影机可以进行慢推、侧移或45度环绕，但人物和厨房空间的真实物理关系保持一致。

### 固定教室Prompt

> 同一间高中教室，黑板、讲台、窗户、门和学生课桌位置完全固定。教师始终站在讲台中央，学生A固定坐在第一排左侧，学生B固定坐在第二排中央，学生C固定坐在后排右侧。不同镜头仅改变摄影机角度和景别，所有角色保持原有座位和视线逻辑，教师始终朝向学生区域，学生根据对白自然看向教师，不出现座位漂移和人物瞬移。

### 固定屋顶Prompt

> 同一城市高层屋顶，固定水箱、通风设备、门、低矮防护墙和远处城市天际线的位置。人物A始终站在防护墙左侧固定空间锚点，水箱位于人物右后方，门位于人物左后方。人物脚部位置始终保持固定，只允许衣物、头发、呼吸、转头和视线自然变化。摄影机围绕人物进行缓慢180度环绕并逐渐拉远，保持人物与屋顶结构的空间关系不变。

### 固定办公室Prompt

> 现代玻璃办公室，办公桌、椅子、落地窗、电脑和书柜位置固定。人物A始终坐在办公桌后方中央位置，人物B始终坐在桌子另一侧右前方，双方保持固定会议关系。人物A面对B，人物B面对A，镜头在180度轴线同一侧进行正反打和轻微横移，不改变桌子、椅子、人物相对位置，仅通过构图、焦点和摄影机距离改变视觉重点。

## 十九、连续性检查与评分系统

### 人物连续性检查表

生成每个镜头后检查：☑身份 ☑身高 ☑服装 ☑位置 ☑朝向 ☑视线 ☑手部位置 ☑道具 ☑光线 ☑阴影

### 场景连续性检查表

☑墙体 ☑门 ☑窗 ☑地板 ☑天花板 ☑家具 ☑大型道具 ☑小道具 ☑光源 ☑天气 ☑时间 ☑色彩 ☑空间尺度

### 人物+场景联合检查（最重要三问）

1. 人物与门窗关系有没有改变？
2. 人物与家具关系有没有改变？
3. 人物与其他人物关系有没有改变？

### 检查顺序

按 **人物→家具→建筑→道具→光线→摄影机** 检查（人物和大型结构决定空间）。

| 建筑结构 | 20分 |
| 家具 | 15分 |
| 人物位置 | 20分 |
| 人物关系 | 15分 |
| 道具 | 10分 |
| 光线 | 10分 |
| 服装 | 5分 |
| 天气/时间 | 5分 |

| 评级 | 分数 | 判断 |
|---|---|---|
| 电影级稳定 | 95-100 | 通过 |
| 高度稳定 | 90-94 | 通过 |
| 基本可用 | 80-89 | 可用 |

### 最终判断标准

连续生成5-10个镜头后——
- 观众感觉"摄影机真的在同一个空间里拍摄同一批人"→**人物Blocking和场景Continuity成功**
- 观众感觉"每个镜头都很好看，但感觉不是同一个房间、不是同一个人、不是同一个时间"→**视觉生成成功，但空间连续性失败**

## 二十、最终知识模型

### 人物站位的AI控制顺序（从场景向人物锁定）

推荐顺序：**建筑→家具→道具→人物→动作→摄影机**。比"先生成人物再硬塞进场景"更稳定。

### AI生成控制优先级

第一优先空间→第二人物身份→第三人物位置→第四动作→第五摄影机→第六光线→第七粒子/特效。空间一旦错误，后面美学全部失效。

### 三层人物控制

```
第一层：角色身份锁（是谁）
    ↓
第二层：人物空间锁（站在哪里）
    ↓
第三层：人物动作锁（在做什么）
```

### 三层场景控制

```
第一层：建筑结构锁
    ↓
第二层：家具/道具锁
    ↓
第三层：光线/时间/天气状态锁
```

### 六大核心锚点

一个角色至少被六类信息同时约束：
1. **身份锚点**——是谁
2. **视觉锚点**——长什么样
3. **空间锚点**——站在哪里
4. **物体锚点**——和什么东西相关
5. **方向锚点**——朝哪里
6. **状态锚点**——现在正在做什么

### 人物知识模型

```
Character = Identity + Position + Relation + Direction + Pose + Action + State
人物 = 身份 + 位置 + 关系 + 朝向 + 姿态 + 动作 + 状态
```

### 场景一致性知识模型

```
Scene Continuity = Architecture + Objects + Character Anchors + Lighting + Time + Weather + Camera Space
场景连续性 = 建筑 + 物体 + 人物锚点 + 灯光 + 时间 + 天气 + 摄影机空间
```

### AI Blocking模型

```
AI Blocking = Character Anchor + Scene Anchor + Object Relation + Eyeline
           + Screen Direction + Action State + Camera Zone + Continuity State
```

### 电影级Blocking模型

真正优秀的人物站位不是"演员站在哪里"，而是：**人物位置 + 摄影机位置 + 视线 + 光线 + 权力 + 情绪 + 叙事信息** 共同构成场面调度。

### 人物空间一致性的完整闭环

```
人物设计 → 场景母图 → Master Blocking → 人物空间锚点
→ 家具/建筑锚点 → Camera Map → 镜头01 → 记录End State
→ 镜头02继承 → 镜头03继承 → 连续性检查 → 剪辑 → 成片
```

### 十大最终原则

1. 人物位置是叙事，不是摆放
2. 固定人物不等于人物冻结
3. 固定世界坐标，不是固定画面坐标
4. 人物必须和环境建立关系
5. 双人物必须锁定左右关系和视线
6. 多人物必须建立固定席位/锚点
7. 每个镜头都应该有Start State和End State
8. 下一镜头必须继承上一镜头的空间状态
9. 建筑、家具、人物、道具、光线应该分别建立锁定层
10. 摄影机可以变化，但物理世界必须保持可解释

### 六阶段制作逻辑

1. 人物是谁？→ 2. 人物在哪里？→ 3. 人物与谁、与什么存在什么空间关系？→ 4. 人物朝哪里、看哪里？→ 5. 人物现在处于什么动作状态？→ 6. 摄影机怎么拍？

### 最终浓缩

**固定人物，不是把人物钉死在画面里；而是把人物钉在一个稳定、可解释、可继承的三维电影空间里。** 当AI能够持续继承：人物身份+人物锚点+场景结构+道具关系+视线+光线+Start/End State，多个AI镜头才会真正产生"同一个人在同一个世界里，被不同摄影机连续拍摄"的电影感。
