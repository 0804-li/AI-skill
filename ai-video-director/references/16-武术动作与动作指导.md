# 16 - 武术动作与动作指导（Fight Choreography）

> 来源：《AI精品电影与现实影视武术动作指导专业知识库》（253页）
> 定位：01号解决"人物怎么动"，15号解决"人物站在哪"，**本库解决"人物怎么打"**——从人物战斗DNA、Fight Beat节拍系统、战斗空间设计到AI动作生成工程（状态模型/连续性/稳定性/Prompt模板/负面控制）的完整动作设计体系。

---

## 一、总论：影视武打 ≠ 真实格斗

**影视动作 = 战斗幻觉。** 目标不是击败对手，而是"让观众相信正在发生一场危险的战斗"。

| 真实格斗 | 影视武打 |
|---|---|
| 目标：击败对手 | 目标：让观众相信危险正在发生 |
| 不可预测、高度随机 | 动作被设计 |
| 快速结束 | 距离被控制 |
| 动作不一定漂亮 | 镜头被安排 |
| 双方不配合镜头 | 反应被表演、节奏被剪辑、声音被强化、特效被添加 |

**第一原则：人物优先。** 动作必须属于人物，不是"动作越多越好"：

| 人物类型 | 动作特征 |
|---|---|
| 冷静杀手 | 小幅度、精准、节省、极少多余动作 |
| 热血少年 | 大幅度、快速、爆发、不稳定、冒险 |
| 老练高手 | 少、稳、预判、利用对手力量 |
| 普通人 | 慌乱、防守优先、动作不完整、易失衡 |

动作指导的完整工作链：动作设计 → 风格选择 → 人物战斗风格 → 节奏设计 → 空间规划 → 摄影规划 → 排练 → 剪辑衔接 → 声音 → 最终效果。**动作编排必须和摄影机共同设计，同一动作在不同机位完全不同。**

## 二、人物战斗系统

### 2.1 战斗人格（Fighting Personality）
主动性 / 攻击性 / 防守性 / 风险偏好 / 移动习惯 / 空间意识 / 情绪稳定性 / 速度偏好 / 力量偏好 / 技巧偏好。

### 2.2 人物战斗DNA（Character Combat DNA）
身体（身高/体重/灵活性）× 性格（冷静/暴躁/犹豫/自信）× 风格（拳/脚/擒抱/武器/环境利用）× 节奏（慢/中/快）× 攻击（精准/爆发/连续）× 防守（闪避/格挡/退步/反制）× 移动（直线/圆周/跳跃/低位）× 情绪（克制/愤怒/恐惧/绝望）。

**AI应用示例**：`"冷静东方剑客：直立姿态、步伐小、移动平滑、动作极少但有明确攻击方向、衣摆存在延迟运动，习惯停顿后突然爆发。"` 比 `"武侠高手"` 有效得多。

### 2.3 战斗风格五大维度
姿态（站姿）→ 步法（怎么移动）→ 攻击方式（依靠什么）→ 防守方式（如何避险）→ 节奏（如何控制时间）。

### 2.4 角色类型速查
杀手=短准安静 | 暴徒=大重粗暴 | 高手=预判节省 | 新手=慌乱不稳 | 特工=高效空间感强 | 武侠剑客=优雅距离身法 | 战士=沉重持续 | 超级英雄=大幅度力量感。

### 2.5 动作签名（Character Action Signature）
主角需要可辨识的动作签名：固定起手姿势 + 移动方式 + 特殊节奏 + 结束姿势。Signature Move不是"最强招式"，而是**观众看到动作就能认出人物**。三要素：起始姿态 + 核心运动轨迹 + 结束姿态——非常适合AI生成角色固定动作语言。

### 2.6 角色五姿态锚点
Neutral Stance（自然）/ Ready Stance（准备）/ Defensive Stance（防守）/ Recovery Stance（动作结束）/ Victory Stance（胜利）。

## 三、Fight Beat 节拍系统（核心概念）

### 3.1 十一节拍
Beat 1发现 → 2准备 → 3启动 → 4攻击 → 5防守 → 6反应 → 7反击 → 8变化 → 9升级 → 10高潮 → 11结果。**电影动作按明确Beat编排，不随机生成招式串。**

### 3.2 基本结构
准备 → 行动 → 结果。因果链：A靠近→B察觉→B防御→A改变方向→B后退→撞到桌子。比"连续十个随机动作"更像电影。

### 3.3 三种速度
| 速度 | 适合 |
|---|---|
| Slow Beat | 试探、对峙、紧张、高手 |
| Medium Beat | 普通战斗、连续攻击 |
| Fast Beat | 高潮、连招、群战、追逐 |

**节奏不是越快越好**：慢→快→慢→爆发→停顿→高潮。全程高速观众会失去空间感和动作重量。

### 3.4 停顿（Pause）
攻击→停→对视→下一次攻击。停顿创造：紧张、尊重、恐惧、悬念、强者气场。

### 3.5 攻防基础循环
Attack → Defense → Reaction → Counter。建立"双方有互动"的基本结构。

## 四、动作重量与冲击感

### 4.1 重量来源
身体惯性 / 起动 / 停止 / 回弹 / 重心变化 / 反应 / 声音 / 镜头震动。**不能只有"快"。**

### 4.2 Impact = 多层合成
动作本身 + 身体反应 + 声音 + 剪辑 + 镜头 + 特效。**动作不一定真的接触，观众仍然相信"这一击非常重"。**

### 4.3 Reaction——受击反应（AI动作最易失败处）
真正的"打中"感来自受击者：身体后仰 / 肩膀变化 / 头部反应 / 重心变化 / 脚步变化 / 表情 / 呼吸 / 恢复。

**反应四层结构**：L1局部反应 → L2上半身 → L3全身重心 → L4环境互动（后退→撞桌→桌子移动）。

### 4.4 攻击者/受击者双系统
每个攻击至少包含 Attacker（发起）+ Receiver（回应）。**Prompt不要只写"A攻击B"，应写"A进行明确的电影化非接触攻击动作，B同步完成可信受击反应。"**

### 4.5 Action Reaction Matrix
| 攻击视觉 | 受击反应 | 摄影 | 声音 |
|---|---|---|---|
| 快速动作 | 快速后仰 | 中景 | 短促冲击音 |
| 重动作 | 明显失衡 | 广角 | 低频 |
| 连续动作 | 连续反应 | 跟拍 | 节奏音 |
| 角色倒地 | 慢恢复 | 低机位 | 呼吸 |
| 高空动作 | 大幅姿态变化 | 广角 | 风声 |

### 4.6 速度不是重量
力量 = 加速度 + 停顿 + 反应 + 声音 + 重量感。慢速也可以非常有力量；高手可以非常慢（观众关注判断与等待）。启动慢一点 → 中段快 → 结束有回收，而非全程匀速。

## 五、战斗类型与结构

### 5.1 七种战斗类型
| 类型 | 特征 | 适合 |
|---|---|---|
| 主动攻击型 | 持续主动 | 强者/暴徒/Boss/杀手 |
| 防守反击型 | 等对方出手再反制 | 高手/冷静人物/太极式角色 |
| 逃生型 | 闪避推开绕行找出口 | **AI动作生成最推荐** |
| 生存型 | 已受伤、动作下降、绝境求生 | 剧情高点 |
| 追逐型 | 位置变化>招式复杂度 | 追逐戏 |
| 决斗型 | 观察→试探→交锋→停顿→第二轮→高潮 | 武侠/剑客/西部/高手对决 |
| 群战型 | 难点是空间清晰度 | 群战场景 |

### 5.2 群战主次结构
一级主角 / 二级核心对手 / 三级普通敌人 / 四级背景人群。**不要让所有人具有相同视觉权重。** 前景主动作、中景次动作、背景群众运动=动作景深。

### 5.3 Fight Story——战斗故事
一场好的战斗至少回答：**谁想要什么？**（A想逃、B想抓 → 整个动作围绕逃与追。）战斗目标类型：击败/逃跑/拖延/保护/抢夺/救人/阻止/威胁/夺回。

### 5.4 胜负结构与 Power Shift
不能只有"最后谁赢"，更重要的是**中间谁占优**。潮汐式战局变化（A优→B翻盘→A受伤→B失优→A胜）更具戏剧性。

### 5.5 特殊关系战斗
- **Boss战**：试探→轻松防守→逐渐认真→展示实力→高潮（表现角色等级）
- **师徒对决**：熟悉+反差，相似动作/互相预判/模仿/反制/情感停顿
- **亲密关系战斗**：犹豫，"想赢但不愿伤害对方"
- **反派动作**：不必要的展示/故意拖慢/暴力风格/不对称动作
- **成长型设计**：前期手忙脚乱→中期准确→后期简洁稳定（视觉上形成人物成长）

### 5.6 战斗节奏结构
**节奏曲线**：建立→紧张→交锋→缓冲→升级→高潮→余波。
**五段式**：对峙/试探/升级/反转/高潮。**八段式**：发现/对峙/第一次交锋/建立优势/反转/受伤疲劳/最终爆发/结果。
**战斗的呼吸**：打→停→看→喘气→再打。**疲劳设计**：速度下降/呼吸加重/反应变慢/姿态下降/恢复时间增加——比"永远满体力"可信。

**环境破坏曲线**（表现战斗升级）：0%正常 → 20%小变化 → 40%明显损坏 → 60%空间危险 → 80%严重破坏 → 100%最终高潮。环境作为节奏器：撞桌→停顿→镜头转向→继续战斗，家具是节奏标点。

## 六、战斗空间设计

### 6.1 Fight Arena（战斗舞台）
不是必须擂台，而是战斗发生的核心区域：厨房的岛台、走廊的整条动线、屋顶的低矮防护墙（危险边界）。**空间越明确，动作越容易读懂。**

### 6.2 五种空间类型
| 空间 | 特点 | 适合 |
|---|---|---|
| 小空间（卫生间） | 距离近、大动作少、机位难移、环境互动强 | 擒抱/推撞/闪避/短距离 |
| 大空间（大厅） | 奔跑跳跃环绕、拉开距离、多人物 | 群战/大调度 |
| 线性空间（走廊） | A→B→C→D动线 | 追逐型 |
| 垂直空间（楼梯/屋顶） | 上升下降、高低关系、重力、危险感 | 高潮戏 |
| 圆形空间（竞技场） | 不断绕圈 | 决斗/高手对决 |

### 6.3 环境互动（Environment Interaction）
高级武打是"人与空间互动"：柱子/桌子/椅子/墙/门/楼梯/地面/汽车/栏杆/雨水。环境可承担：障碍/掩护/转向/停止/跌倒/空间限制/情绪强调。

设计战斗前必须知道：地面软硬、空间宽窄、有无高差、障碍物、危险边界——这些决定动作风格。

### 6.4 战斗地理（Action Geography）
完整空间关系：主角在哪 / 对手在哪 / 出口在哪 / 危险在哪 / 摄影机在哪 / 可用环境元素在哪。**生成前先画 Fight Geography Map：**
```
出口
 ↑
 B ●
 A ● ──────── 桌子
 摄影机
```
每一次空间变化必须：推进 / 后退 / 转向 / 升级——不能"随机移动"。

## 七、武打摄影系统

### 7.1 第一原则
摄影机必须让动作**读得懂**。三要素：①清楚（知道发生了什么）②有冲击（感觉力量）③有节奏（愿意继续看）。

### 7.2 景别功能
| 景别 | 功能 |
|---|---|
| 全景 | 完整动作、建立真实空间（脚步/跳跃/跑动/群战必须） |
| 中景 | 最常用，上半身+方向+部分脚步 |
| 近景 | 反应 |
| 特写 | 冲击细节（眼神/手/武器/汗水/表情/伤势），但不能代替整个动作 |
| Insert | 拳头/鞋踩地/握剑柄/门撞开/金属碰撞，增强节奏与剪辑密度 |

### 7.3 焦段
24mm大空间高动态环境动作 / 35mm平衡人物+空间（动作电影首选）/ 50mm自然空间 / 85mm反应特写压缩背景 / 长焦观察压缩战场——但不宜全靠长焦，会失去空间清晰度。

### 7.4 机位与方向
- **低机位**：强者、登场、跳跃、踢腿、英雄动作
- **高机位**：群战、空间关系、危险、人物弱势
- **侧面**：看清运动轨迹（横向移动/跳跃/跑步/飞跃）
- **正面**：英雄姿态、对峙、经典Pose
- **背后**：跟拍、追逐、潜行、神秘人物
- **环绕**：决斗、高手、角色介绍、战斗高潮（保持空间中心明确）

### 7.5 手持 vs 稳定器
手持（纪实/生存/混乱/狂暴）≠随机抖动，应有**人体重量感+惯性+可读的运动方向**。稳定器（长距离跟拍/追逐/一镜到底/复杂空间动作）。

### 7.6 动作长镜头结构
人物进入→第一轮交锋→移动到第二空间→环境互动→第二轮交锋→高潮→停顿。要求动作高度排练。**AI虚假长镜头**：用人物遮挡/快速摇镜/墙壁/黑场/门/烟雾/背景物体隐藏生成镜头间的断点，再组合。

### 7.7 Camera Beat
每个动作节拍对应摄影机节拍：发现敌人→推近 / 第一次攻击→镜头跟随 / 被击中→快速切近景 / 反击→回中景 / 高潮→广角长镜头。

镜头提前（预测，产生"期待"）与滞后（稍后追上，产生速度感）改变动作感觉。稳定模式：Tracking跟随 / Lead领拍 / Orbit环绕 / Static固定 / Push推 / Pull拉 / Overhead俯拍 / Low Angle低机位。

### 7.8 摄影机组合速查
| 组合 | 效果 |
|---|---|
| 35mm+跟拍 | 现实动作 |
| 24mm+低机位 | 史诗动作 |
| 50mm+慢环绕 | 高手决斗 |
| 85mm+特写 | 心理压力 |

镜头与动作匹配：小动作50–85mm / 全身动作24–35mm / 群战24mm / 环境动作24–35mm / 表情50–85mm。

## 八、动作剪辑

### 8.1 经典结构
宽 → 中 → 特写 → 宽：先知道空间 → 人物动作 → 关键冲击 → 空间结果。

### 8.2 切得太碎的病
拳特写→脚→脸→手→对手连续切换，观众不知道发生了什么。**可读性5问**：谁在攻击？谁在防守？双方在哪？谁占优？动作结果是什么？答不出=镜头语言有问题。

### 8.3 动作方向连续性
人物向右移动，下一镜继续向右；突然反向必须让观众看到原因。武打尤其需要180度轴线（A左B右保持），**故意越轴**适合混乱/失控/恐怖/心理崩溃/战局反转，但要有意识使用。

### 8.4 四个核心原则
动作方向匹配 / 动作阶段匹配（起始→加速→峰值→回收，在清晰节点剪）/ 身体位置匹配 / 镜头节奏匹配。

### 8.5 Impact Editing
动作峰值可用：Cut / Flash / Shake / Sound Hit / Slow Motion 共同强调。**镜头震动不能每个动作都震，否则失去重点。**

### 8.6 信息管理
- 冗余：连续三个镜头表现同一动作→删除
- 不足：观众不知道"人物怎么从A到B"→增加空间镜头
- 关键位置（群战/地形变化/复杂空间）插入Establishing Shot重新建立"谁在哪里"
- 镜头数量不是越多越精彩，关键是**动作信息是否完整**
- 动作结束后保留**结果镜头**：倒下/环境变化/武器掉落/呼吸/对方离开

### 8.7 动作转场
- **Match on Action**：镜头A动作开始，镜头B动作完成
- **Action Wipe**：人物快速经过前景遮挡画面→切换
- **Impact Cut**：关键冲击直接切到另一地点/人物
- **Sound Cut**：画面快切但冲击音持续，声音加强跨镜连续性

## 九、速度与时间设计

| 速度 | 强调 |
|---|---|
| 慢 | 力量 |
| 中 | 技术 |
| 快 | 危险 |
| 极速 | 超现实或高潮 |

**动作视觉速度五来源**：真实动作速度×镜头速度×背景运动×快门拖影×剪辑速度×声音节奏——单纯让人物"跑得快"并不一定看起来快。

- **Speed Ramp**：准备正常→动作瞬间慢动作→冲击正常→第二动作快速（强调关键Beat）
- **Freeze Beat**：动作冻结+摄影机继续移动（登场/高潮/超能力/MV）
- **Slow Motion**：关键反应/登场/高空动作/情绪高潮/环境碎片——不建议整场慢动作
- **Bullet Time**：角色减速或冻结+摄影机完成空间运动

**运动模糊**：适度强化速度，过多破坏可读性。写法："高速动作具有自然运动拖影，但关键动作轮廓仍然清晰。"

## 十、视觉语言与类型风格

### 10.1 四种视觉语言
| 语言 | 特征 | 适合 |
|---|---|---|
| 现实主义 | 短、快、笨重、反应重、呼吸明显、恢复长 | 犯罪/生存/战争 |
| 写实动作 | 略微强化 | 写实动作电影 |
| 风格化 | 更大、更清楚、轨迹明确 | 功夫/武侠 |
| 超现实 | 飞跃/慢时间/超自然/空间变化（须先建立真实身体动作基底） | 奇幻/科幻 |

功夫片语言：连续动作/节奏/身法/手脚组合/空间移动/角色性格。武侠语言：身法/距离/剑术/轻功式空间想象/留白/诗意/节奏变化——比现实更"干净"且有舞蹈性。

### 10.2 类型×动作风格矩阵
| 类型 | 动作风格 | 摄影 | 节奏 |
|---|---|---|---|
| 文艺 | 极少动作 | 固定 | 慢 |
| 犯罪 | 写实 | 手持 | 中快 |
| Noir | 简洁 | 长焦/低机位 | 中 |
| 动作 | 高密度 | 跟拍 | 快 |
| 武侠 | 写意 | 环绕/长焦 | 中快 |
| 功夫 | 节奏清晰 | 中景 | 快 |
| 科幻 | 空间化 | 广角/虚拟 | 快 |
| 奇幻 | 夸张 | 航拍/环绕 | 中 |
| 恐怖 | 不确定 | 静止/主观 | 慢快交替 |
| 战争 | 混乱写实 | 手持/广角 | 快 |
| 喜剧 | 肢体化 | 广角 | 快 |

动作类型选择：真实→写实 / 好看→风格化 / 东方→武侠功夫 / 宏大→史诗 / 科技→科幻 / 恐怖→生存 / 喜剧→肢体。

### 10.3 表演层
动作演员需表演：恐惧/疲惫/愤怒/疑惑/疼痛/自信/犹豫/杀意/绝望。**同一动作（后退一步）可以是恐惧、诱敌、或准备攻击——动作必须带情绪。** 情绪动作化：愤怒=幅度大 / 恐惧=退缩 / 冷静=动作少 / 绝望=力量下降 / 兴奋=速度增加。

心理Beat：发现对手实力远超自己→害怕→调整策略→重新进入战斗。

## 十一、武器与服装系统

### 11.1 武器分类
剑/刀/棍/枪械视觉表演/长柄武器/盾牌/双持/特殊幻想武器。只从影视表现角度研究：动作轨迹、镜头、节奏、角色风格、安全表演。

### 11.2 武器连续性（AI武器漂移防治）
武器进入镜头必须清楚：**在哪、谁持有、朝向哪里、动作完成后在哪、下一镜是否仍在手中。** 换手必须存在可见动作过程。武器作为视觉锚点：`右手剑+桥中央+环绕机位`——机位改变但剑与人物关系保持。

### 11.3 服装与Secondary Motion
长袍/风衣/盔甲/披风/袖子加强动作轨迹。**东方武侠衣摆系统**：身体旋转→衣摆形成延迟运动→显著增强速度、方向与惯性。身体先动、服装稍后=次级运动（头发/衣服/披风/腰带/武器挂件/饰品/雨水/尘土）提升AI动作真实感。

### 11.4 Action FX
尘土/水花/雨滴/雪/火花/烟雾/碎屑/衣料摆动。**特效不要盖过主体**，优先级：人物动作 > 反应 > 环境 > 特效。视觉层级：人物→动作→环境→特效→装饰。

破坏性动作用 **Before–Impact–After** 结构：Before桌子完整 → Impact动作发生 → After桌子倒下。次级事件：跳跃附带衣摆/灰尘/水花/发丝/背景树叶。

## 十二、声音体系

### 12.1 动作声音清单
出手声/空气运动声/接触模拟音/脚步/衣服摩擦/落地/环境声/武器声/呼吸/受伤呻吟/空间混响。

**动作声音不能完全真实**（真实声音可能很小），电影会强化：脚步、衣服摩擦、武器、撞击、呼吸。

### 12.2 声音节奏
动作"啪"→"砰"→"轰"形成节拍。**Silence Beat**：关键动作前突然安静→动作发生，反差非常有效。

### 12.3 音乐原则
音乐可提速/停顿/强调高潮/人物主题/标记反转。**优秀动作即使关掉音乐，空间仍然清楚、节奏仍然成立。**

### 12.4 场景音效与空间音
竹林=风+竹叶 / 屋顶=风+车流 / 仓库=回声+金属+电机 / 雨夜=水滴+地面+汽车。Prompt空间音写法："宽阔石室中产生明显回声"/"狭窄走廊中的脚步具有短混响"。

## 十三、AI动作生成核心系统

### 13.1 最大问题：动作连续性
AI常见失败：镜头1抬手→镜头2手落下→镜头3已完成攻击。**解法：Start State → Motion → End State 结构。**

### 13.2 AI动作状态模型
S0站立 / S1准备 / S2启动 / S3动作中 / S4完成 / S5反应 / S6恢复 / S7下一动作。

**Prompt必须写清状态**：
- ✗ "人物进行一段武术动作。"
- ✓ "人物从稳定站姿开始，短暂停顿后进入攻击动作，完成动作后保持结束姿态，随后对手做出同步反应，摄影机保持中景跟随。"

### 13.3 四个最重要变量
①起始姿态 ②动作方向 ③结束姿态 ④对手反应——**比"动作名称堆叠"更重要。**

### 13.4 单动作原则与动作链
AI最容易稳定生成**一个明确主动作**（一次踢击/闪避/跳跃/翻滚/擒抱/挥武），然后连接。动作链：动作1→反应1→动作2→反应2→动作3→结束。**不要一条Prompt塞20个连续动作。**

### 13.5 Beat Prompt写法
`"人物A向前一步，短暂停顿，做出明确的电影化非接触攻击动作；人物B向后闪避并做出明显受击预判，随后A恢复站姿，B重新建立防守姿态，摄影机保持中景和双方完整身体可见，动作连续、空间关系稳定。"`

### 13.6 非接触动作表达
优先使用：明确挥击路径 + 视觉错位 + 对手反应 + 镜头角度 + 声音 + 速度变化共同制造冲击。**不要把重点放在现实伤害细节上。**

### 13.7 短动作单元策略
不要生成"30秒完整格斗"，拆成Shot A准备 / B第一次动作 / C反应 / D环境互动 / E第二轮 / F高潮，然后剪辑。

**5秒AI动作单元**：0–1s建立姿态 / 1–2s主动移动 / 2–3s动作发生 / 3–4s对手反应 / 4–5s双方重新建立姿态。

### 13.8 首尾帧与状态继承
每镜明确首帧（距离/位置/姿态）尾帧（位置/结束姿态），**下一镜从上一镜尾帧继续**，不要重新定义"双方重新站好"。

### 13.9 空间与距离锚点
- 空间锚点：`"人物A始终在画面左前方，人物B始终在右后方"` 比"A攻击B"更稳定
- 距离锚点：`"保持双方一臂到两臂的视觉距离"`——重点是距离等级不是精确数字
- 距离视觉分类：极近（拥挤/擒抱/压迫）/ 近 / 中（大部分动作）/ 远（武器/追逐/决斗）

### 13.10 相对速度与惯性
速度层次：A快、B慢、摄影机中快、背景快速移动。**速度曲线Prompt**：`"动作从静止开始，人物短暂停顿后突然加速完成主要动作，动作结束后迅速减速并恢复稳定姿态，摄影机同步跟随但略有惯性，避免机械恒速。"`

高级Prompt加入物理层：重心转移/身体惯性/动作回收/服装延迟/头发延迟/摄影机轻微惯性。

### 13.11 高手与新手
高手视觉原则：**少，但每次运动有意义**（剑客/武术大师/枪术高手/特工）。新手：犹豫/失误/防守/退缩/重心不稳（适合角色成长）。

## 十四、AI稳定性工程

### 14.1 三大铁律
- **一镜一主动作**：一个镜头一个主动作+最多一个辅助动作（如主动作=向前闪避，辅助=摄影机横移）
- **一镜两主体**：A主要动作+B主要反应，不要两人同时各做三组复杂动作
- **一镜一空间**：连续性差时单一空间区域，不要教室→楼梯→屋顶塞一个Prompt

### 14.2 复杂度模型
Complexity = 人物数 × 动作数 × 摄影机运动 × 场景变化 × 特效数。**主动控制同时变化的变量数量。**

- **一主一辅**：主变量人物动作，辅变量摄影机，其余稳定
- **两锁一动**：锁1人物身份+锁2空间位置+动动作；下一镜锁身份+锁空间状态+动摄影机

### 14.3 失败拆解优先级
动作生成失败时依次：①减少动作数量 ②减少人物数量 ③减少摄影机运动 ④固定背景 ⑤拆镜头。

### 14.4 最小可行方案（高失败率时）
1人物 + 1空间 + 1主要动作 + 1反应 + 1种摄影机运动。

### 14.5 由简到繁九级
L1单人物 → L2+摄影机 → L3双人物静态 → L4双人物动作 → L5+摄影机 → L6+环境 → L7多人 → L8多人+摄影机+环境 → L9完整动作长镜头。七阶段搭建：静态人物→原地动作→双方动作→移动→摄影机运动→环境互动→复杂转场。

### 14.6 稳定优先
动作不稳定时不要先加特效，先解决：人物→位置→动作→摄影。

### 14.7 动作复杂度适配不同AI模式
文生视频=简化动作+明确空间 / 图生视频=锁人物姿态和场景锚点 / 首尾帧=明确起止状态 / 多镜头=建立Scene State / 参考图驱动=锁人物外观+姿态+位置。参考图层级：L1人物→L2场景→L3人物+场景→L4动作姿态→L5全锁（越高空间一致性越强）。

### 14.8 Master Action Frame
重要先生成一张**动作标准帧**（A准备姿态+B防守姿态+空间固定），让视频围绕该姿态产生运动。关键姿态优先：模型无法稳定生成完整动作时，先确保关键姿态正确（Pose A→B→C→D对应准备→开始→峰值→结束），用多个短镜头连接。

## 十五、动作连续性系统

### 15.1 Combat Identity Continuity
同一角色跨镜头保持：相似准备姿态/脚步/动作习惯/节奏/攻击倾向/结束姿态。Pose Anchor固定：脚的位置、肩膀方向、胸口方向、头部方向。**Pose Matching**：上镜结束姿态A，下镜从相同姿态开始。

### 15.2 状态锁
- **Character Condition**：人物状态（伤痕/疲劳/姿态）
- **Environment Condition**：环境状态（桌子打翻不恢复）
- **Prop Condition**：道具状态机 P0桌上→P1A持有→P2掉落→P3地面→P4B取得→P5离画
- **服装状态**：扣子/袖子/衣摆/污渍/破损/湿度——动作越激烈越需要记录

| 05 | 55% | 绝望 | 平衡 | 边缘 |

人物身体状态库：完整/疲劳/受惊/轻微受伤/严重疲劳/跛行/失衡/倒地/恢复。**伤势必须影响**速度/姿态/移动/表演/视觉重心——不能"刚重伤下一镜完全正常"。

### 16.6 经典动作参考抽象法（去作品化）
参考经典武打**不要复制**"具体角色+招式+场景"，而抽象为动作语言：
```
原片："雨夜巷战"
抽象：狭窄空间 + 湿地反射 + 前景遮挡 + 中景跟拍 + 冷色 + 高频反应 + 环境声音
→ 换成机场 / 古代城镇 / 未来城市 仍然成立 —— 这才是可迁移动作知识
```
Combat DNA格式：
```
TYPE: 动作惊悚 | CHARACTER: 冷静高手 | SPACE: 狭窄走廊 | STANCE: 稳定
MOVEMENT: 短距离 | ATTACK: 精准 | DEFENSE: 闪避
RHYTHM: 慢→快→停→快 | CAMERA: 35mm中景跟拍 | LIGHT: 硬侧光
SOUND: 呼吸+环境声 | REACTION: 明确 | ENVIRONMENT: 墙面/门框 | EMOTION: 压迫
```
学习经典动作问7个问题：为什么这动作在这里出现 / 为什么摄影机在这 / 为什么观众看得懂 / 为什么角色这样动作 / 为什么这一击有力量 / 为什么这里停顿 / 为什么这里切镜头。

### 16.7 战斗卡片系统
- **战斗角色卡**：姓名/定位/风格/节奏/姿态/移动/攻击/防守/反应/标志动作
- **战斗场景卡**：地点/空间尺寸/障碍/主光/环境/人物位置/出口/高潮区域
- **战斗镜头卡**：Shot号/Beat/景别/焦段/人物/动作/摄影/结束状态/连续性（继承Shot几）

动作Bible八件套：Character Bible + Combat Bible + Scene Bible + Blocking Bible + Camera Bible + Action Beat Bible + Continuity Bible + Sound Bible。

### 16.8 广义动作系统（不只是武打）
行走/奔跑/追逐/跳跃/爬行/攀爬/躲避/翻越/跌倒/起身/翻滚/滑行/推拉/搬运/战斗/武器动作/车辆动作/群体行动/舞蹈/仪式/表演性动作/超自然动作/飞行/水下/失重。

- **行走**：速度/步幅/重心/情绪/身份/地面/摄影机（冷静=稳定笔直，疲惫=慢沉重，焦急=步幅大，恐惧=频繁回头）
- **奔跑**：起跑→加速→匀速→转向→减速→停止（AI不能只写"高速奔跑"）
- **追逐**：核心是**距离变化**（领先10米→缩到5米→再拉开→障碍→追上→高潮）
- **跳跃**：准备→起跳→空中→落地→恢复；**翻滚**：启动→旋转→落地→恢复；**跌倒**：失衡→重心变化→倒下→接触地面→恢复/停留
- **车辆动作**：人物固定车门附近+车辆保持方向+摄影机侧向跟拍，三个方向不要同时无规律变化
- **动作轨迹分类**：直线/弧线/圆/螺旋/S型/Z型/交叉/对冲/汇聚/分离（对冲视觉最强；汇聚适合Boss战；分离适合群战逃跑灾难）

### 16.9 构图与遮挡
**动作线（Action Line）**：每镜一条主要动作线（左→右），其他人物不要乱跑；来源：人物移动/武器轨迹/摄影机/视线/环境线。**视觉重心**：动作高潮靠近视觉中心，背景不抢眼。**前景遮挡**：柱子/门/墙/树/人群/烟雾形成层次，但不要持续遮到关键动作看不见。

## 十八、负面控制与错误诊断

### 18.1 Negative Prompt总库
**人物**：身份漂移 / 身体比例变化 / 肢体变形 / 多余肢体 / 手脚异常 / 面部变化
**动作**：随机招式 / 动作重置 / 动作跳跃 / 方向反转 / 无准备动作 / 无结束状态 / 无受击反应 / 过度连续动作
**空间**：瞬移 / 左右关系改变 / 前后关系改变 / 距离突然变化 / 环境重构 / 背景漂移
**道具**：武器漂浮 / 道具消失 / 数量变化 / 持有手变化
**摄影**：随机旋转 / 无意义摇晃 / 突然变焦 / 摄影机穿透人物 / 摄影机瞬移

英文辅助：`"no random movements, no teleportation, no limb distortion, no extra limbs, no body deformation, no weapon drift, no character identity drift, no spatial discontinuity, no broken motion continuity, no uncontrolled camera movement."`

### 18.2 错误诊断表
| 错误 | 解法 |
|---|---|
| 动作数量太多 | 拆成多个Shot |
| 没有起始姿态 | 写清Start State |
| 没有结束姿态 | 写清End State |
| 没有对手反应 | 增加Reaction Beat |
| 摄影机和人物同时复杂运动 | 降低同时变量 |

### 18.3 高质量关键词（英文）
clear body mechanics / readable action / consistent spatial relationships / controlled cinematic choreography / strong anticipation / clear follow-through / natural weight transfer / convincing reaction / smooth continuity / cinematic camera movement / physically coherent motion。

### 18.4 模糊词转换
- "超级炫酷/无敌/极其震撼/疯狂打斗/世界最强/超快/非常真实/电影感十足" → 缺少可执行结构，禁用
- "非常快" → "短暂蓄力后快速加速，动作峰值清晰"
- "非常有力量" → "启动具有明显重心转移，动作结束有自然回收和身体惯性"
- "非常电影感" → "35mm中景、空间可读、动作节拍清晰、摄影机有惯性、关键反应明确"
- "两个高手大战" → "两个角色相隔数米保持静止，对峙3秒；A首先进入攻击节拍，B完成闪避；双方重新建立距离；B开始主动推进；摄影机从正面中景逐渐移动至侧面；第二轮动作后进入环境互动；最终在中央空间形成高潮。"
- **"武打"一词过于宽泛**，必须展开为：风格+节奏+距离+动作结构+反应+摄影。如"克制、短距离、高手对决、少动作、大停顿、快速爆发"。

## 十九、安全原则

影视动作与真实格斗最大的工业区别：**一切高风险动作必须由专业动作指导、特技协调员、训练人员设计排练和安全控制**，AI Prompt不能当作现实特技动作的执行说明。AI创作的安全关注点：动作视觉设计、起始/结束姿态、摄影、剪辑、节奏、声音、虚拟动作、非接触影视表现。涉及演员、替身、武器、跌落、车辆、高空的真人拍摄应由具备资质的团队进行风险控制。

## 二十、最终知识模型

### 20.1 十层动作制作标准
①故事（谁和谁为什么战斗）②人物（各自怎么战斗）③空间（在哪战斗）④Blocking（站在哪）⑤Beat（什么时候发生什么）⑥动作（具体视觉动作）⑦摄影（怎么拍）⑧剪辑（怎么切）⑨声音（怎么让动作有重量）⑩特效（怎么增强）。

### 20.2 核心公式
- 传统电影动作 = 人物目标 × 武术风格 × Blocking × Beat × 摄影 × 剪辑 × 声音
- AI电影动作 = Character DNA × Spatial Anchor × Fight Beat × Action State × Camera State × Reaction × Continuity
- 精品AI武打 = 人物性格 × 战斗身份 × 空间关系 × 动作因果 × 速度曲线 × 摄影机运动 × 受击反应 × 环境反馈 × 声音 × 剪辑 × 连续性

### 20.3 十五步工作法
①先确定为什么打 ②确定谁占优势 ③确定每个人战斗风格 ④画出战斗空间 ⑤固定双方站位 ⑥写Fight Beat ⑦Beat拆成短动作单元 ⑧每动作确定Start State ⑨确定End State ⑩设计反应 ⑪设计摄影机 ⑫设计剪辑 ⑬设计声音 ⑭加入环境和特效 ⑮每生成一个镜头继承上一镜状态。

### 20.4 四大最终核心
**可读性**（观众看得懂）/ **人物性**（动作属于角色）/ **节奏性**（动作有呼吸）/ **空间性**（动作发生在真实空间）。

终极原则：**不要让AI"生成打斗"，要让AI生成一场具有明确人物、明确空间、明确目标、明确节拍、明确动作状态、明确摄影逻辑和明确结果的电影动作戏。**
