# 18 图生视频上下文分镜衔接工程（I2V Shot-to-Shot Continuity）

面向 Seedance 2.0/2.5 及同类支持「图生视频 / 首尾帧 / 多图参考」的平台。解决一个具体问题：**上下两个分镜之间如何无缝衔接生成**，让 A 镜的尾帧成为 B 镜的起点，而不是每次都重新"抽卡"。

核心命题：**把剪辑点从剪辑软件前移到生成阶段。** 传统流程是"各自生成 → 后期硬接"，衔接工程是"生成时就为下一个镜头留接口"。

与相邻词库的分工：
- `05-转场与连续性.md`：转场**方式库**（用什么手段转）
- `15-人物站位与场景一致性.md`：站位与空间的**语义锁定**（用文字锚定）
- `11-全片一致性与工程系统.md`：整片**工程层**（母Prompt、锁定器）
- **本文件：像素级 + 状态级的跨镜交接（用图锚定 + 用状态账本传递）**

---

## 0. 三种生成拓扑

先决定整条片子的生成结构，再谈单镜衔接。

| 拓扑 | 结构 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| **星形 Star** | 一张母参考图 → 所有镜头引用它 | 一致性最高，误差不累积 | 镜头间**没有像素衔接**，仍是硬切 | 广告、产品、角色宣传短片 |
| **链式 Chain** | 镜N尾帧 → 镜N+1首帧 | 衔接最顺，接近一镜到底 | 误差逐镜累积（漂移） | 连贯动作戏、一镜到底感、连续叙事 |
| **混合 Hybrid（推荐）** | 关键帧锚点 + 链式 + 定期回注 | 兼顾衔接与稳定 | 流程最复杂 | 剧情短片、多镜头叙事、打斗戏 |

**误差累积规律**：链式生成每镜引入 δ 偏差，n 镜后累积偏差约为 √n · δ（随机游走），不是线性叠加但必然发散。经验值：**连续链式不超过 5 镜**，第 4~5 镜起必须回注锚点。

**锚点回注三法（Anti-Drift）**：
1. **直接回注**：下一镜首帧改回母角色图 + 场景描述重新起（放弃像素衔接，换回一致性）。
2. **融合校正**：把当前首帧与母图做一次图生图融合（重绘强度 0.3~0.5），纠正漂移后再送进视频模型。
3. **交叉覆盖**：让下一镜的前 0.5 秒与上一镜尾帧"同构 + 同向运动"，用运动连续性掩盖外观差异。

## 1. 四类衔接模式（M1–M4）

| 模式 | 输入 | 输出控制 | 适用 | 平台要求 |
|---|---|---|---|---|
| **M1 首帧续写** | 首帧图 | 只锁开头，结尾由模型决定 | 环境氛围、B-roll、单镜微动 | 通用 I2V |
| **M2 尾帧继承 / 链式** | 上一镜尾帧作首帧 | 锁开头（=上一镜结尾） | 连续动作、跟拍、一镜到底 | 通用 I2V + 抽帧 |
| **M3 首尾帧双锁** | 首帧 + 尾帧 | 两端都锁，模型补中间 | 揭示/变形/场景过渡/大动作设计 | 支持首尾帧的平台（如 Seedance 2.0+） |
| **M4 桥接帧** | 首帧 + 中间态图 | 分段锁，跨大跳跃 | 景别/机位/时间跳跃过大时 | 通用 I2V，多生成一次 |

**M0（基础）多参考图锚定**：所有镜头引用同一组参考图（角色图/场景图/道具图），保证"不换脸、不换衣服"，但不保证动作衔接。实践中 **M0 与 M1–M4 叠加使用**，不要二选一。

> Seedance 2.0+ 参考图写法：`@Image1 as the first frame` / `@Image1 as the first frame, @Image2 as the last frame` / `@Image1 is the main character`（多镜共用的角色锚点）。

### 模式选型速查

| 上下镜关系 | 用什么 |
|---|---|
| 同机位、同景别、连续动作 | M2 尾帧继承 |
| 同空间、动作要精确落点（推门/回头/出拳） | M3 首尾帧双锁 |
| 景别跳两级（全景→特写）或换机位过轴 | M4 桥接帧 或 T3 遮挡桥接 |
| 换场景 / 换时间（白天→夜晚） | M3 或 T7 同构衔接 |
| 只需"看起来是同一个人" | M0 多参考图锚定 |

## 2. 接缝七要素（Seam Seven）

**接缝 = 上一镜 END STATE 与下一镜 START STATE 的匹配程度。** 每次交接前逐项打分：0=不匹配，1=部分匹配，2=完全匹配。

| # | 要素 | 检查什么 | 常见失配 |
|---|---|---|---|
| 1 | **姿态 Pose** | 人物肢体位置、重心、手势是否可延续 | 上一镜手在抬，下一镜手已放下 |
| 2 | **方向 Direction** | 运动方向、视线方向是否一致（180度规则） | 左→右 变成 右→左 |
| 3 | **景别与轴 Scale+Axis** | 主体大小、机位角度、画面区域 | 同景别同角度 = 跳切感 |
| 4 | **光色 Light+Color** | 光源方向、色温、明暗关系 | 顺光变逆光、暖变冷 |
| 5 | **服装道具 Prop** | 衣服状态、手持物、道具位置 | 上一镜杯子空、下一镜满 |
| 6 | **环境状态 Env State** | 门开/关、灯亮/灭、椅子倒/立 | 门已推开，下一镜又关着 |
| 7 | **情绪余韵 Emotion** | 情绪强度与残留是否延续 | 上一镜崩溃大哭，下一镜平静微笑 |

**评分处置规则**：
- 12–14 分：直接 M2 尾帧继承。
- 8–11 分：M2 + 在 Prompt 中补修失配项（写"保持方向/保持光位"）。
- 5–7 分：必须 M4 桥接帧，或换 T3/T5 掩盖型技法。
- ≤4 分：不要硬接。改设计（换景别换角度重起）、或走黑场/明确转场。

**30度法则**：衔接两镜的机位角度变化不足 30°、且景别未跳级 → 观众读到的是"跳切"而不是"剪辑"。要么把角度拉开 ≥30°，要么景别跳 ≥2 级（如 中景→特写）。

## 3. 八大衔接技法（核心技法库）

| 编号 | 技法 | 一句话 | 适用场景 |
|---|---|---|---|
| T1 | 动作匹配衔接 | 上一镜动作未完成，下一镜接续完成 | 起身/开门/坐下/挥拳 |
| T2 | 动势交接 | 首帧取动作**中段**而非静止起点 | 走路/奔跑/转身/任何连续运动 |
| T3 | 遮挡桥接 | 用遮挡物/黑场吃掉接缝 | 换机位/过轴/大跳跃 |
| T4 | 出画入画接力 | 上镜出画，下镜从画外入画 | 空间移动、跟拍 |
| T5 | 光学软着陆 | 用甩镜模糊/失焦/过曝帧做首帧 | 尾帧质量差时的救场 |
| T6 | 首尾帧双锁关键帧 | 首尾两张图，模型补中间 | 精确设计的动作与转场 |
| T7 | 同构衔接 | 用相同构图/形状/运动形态跨时空 | 时间跳跃、平行叙事 |
| T8 | 静止起步 | 首镜几乎不动，第二镜再加速度 | 图生视频"炸开/乱动"时 |

---

### T1 动作匹配衔接（Match Cut / Cut on Action）

**原理**：动作在剪辑点两侧延续。上一镜收在动作**进行到 60~70%** 处（不要收在完成时），下一镜从 60~70% 处接手做到 100%。

**首帧怎么取**：上一镜尾帧应停在"动作中段"——手已抬起但未落下、身体已转过一半、门已推开三分之一。

**Prompt 模板**：
```
保持首帧中人物的姿态、服装、构图与光位完全不变。
承接上一个动作：人物【继续完成该动作，如：将抬起的手缓缓放下、把门完全推开、身体转过剩余角度】，
动作速度【平稳/缓慢】，保持运动的惯性与重心转移。
摄影机【固定/轻微推进】，保持与上一镜一致的机位高度与光位。
结束时人物姿态稳定停住，动作完整收束，不回弹、不重复起势。
```

**失败信号**：下一镜人物"又做了一遍完整动作" → 首帧取早了（取了起点）或 Prompt 里写了完整动作描述（应写"继续/完成剩余部分"）。

---

### T2 动势交接（In-Motion Handoff）

**原理**：图生视频最容易犯的错是"每一镜都从静止起步"。真实剪辑是在运动中切——所以**首帧必须是运动进行中的一帧**。

**首帧怎么取**：取上一镜尾帧中人物处于动态瞬间的帧（有运动模糊但轮廓可辨，重心在两脚之间/衣摆有摆动）。

**Prompt 模板**：
```
保持首帧构图、人物身份与运动状态，画面从**运动进行中**继续，不从静止起步。
人物保持【原有运动方向】以【原速度】继续【走路/奔跑/转身】，步频与上一镜一致。
摄影机以相同速度【同步后退跟拍/平行横移】，与人物保持固定距离，不重新起势、不减速停顿。
衣摆与发丝保持向后的惯性摆动，环境元素（地面/树影/光影）随运动连续流动。
```

**关键句**：`画面从运动进行中继续，不从静止起步`（from motion, not from still）——这是链式衔接的第一护身符。

---

### T3 遮挡桥接（Occlusion Bridge）

**原理**：当上下镜差异过大（过轴、换景别、换空间），用一个"遮挡事件"把接缝吃掉。遮挡期间观众不比对细节。

**三种做法**：
1. **前遮挡**：上一镜结尾让前景物体（人物/柱子/车/门框/烟雾）快速掠过填满画面 → 下一镜首帧从"遮挡物正在移开"开始。
2. **后遮挡（出遮挡）**：下一镜首帧直接是遮挡物占满 80% 的画面，第一秒物体移开揭示新构图。
3. **黑/白场**：上一镜收在全黑（走进暗处/关灯/闭眼），下一镜从黑场淡入。**黑场不是偷懒，是最可靠的一致性重置点**，也是锚点回注的最佳时机。

**Prompt 模板（后遮挡）**：
```
首帧中【前景遮挡物，如：一根粗壮的石柱/一个人的黑色背影/一团烟雾】占据画面大部分。
遮挡物以【快速/平稳】速度向【左/右】移出画面，逐渐揭示出后面的【新构图与空间】。
揭示过程中摄影机【固定/缓慢推进】，光影方向与被遮挡时保持一致。
揭示完成后构图稳定，人物位于【画面位置】，视线看向【方向】。
```

---

### T4 出画入画接力（Direction Relay）

**原理**：上镜人物从画右出画 → 下镜人物从画左入画（**屏幕方向必须一致**：右侧出画必须左侧入画，观众的心智模型是"向右走"）。

**首帧怎么取**：不用上一镜尾帧（此时人物已出画，画面空）。首帧应是**"人物刚从画左边缘进入"的构图**——通常由母图 + 图生图生成，或取上一镜中人物接近边缘的帧外扩。

**Prompt 模板**：
```
人物从画面【左】侧边缘进入，以【中速】沿【向右】方向走入画面中央。
摄影机固定，保持与人物距离由远及近。人物始终向右运动，不折返、不转向镜头。
进入画面后【减速，停在画面右侧三分之一处，转向/看向画外右侧】。
背景保持稳定，地面光影随人物移动连续变化。
```

**检查**：出画方向 ↔ 入画方向必须反向同向（右出→左入），否则 180 度规则崩。

---

### T5 光学软着陆（Optical Soft Landing）

**原理**：当尾帧质量差（模糊/过曝/变形）时，不要修图，直接把"缺陷"设计成转场：模糊=甩镜，过曝=闪白，暗=黑场。

| 尾帧状态 | 转译成 | 下一镜首帧写法 |
|---|---|---|
| 运动模糊糊成一片 | 甩镜 Whip Pan | "画面从高速横向运动模糊中减速稳定下来，停留在……" |
| 过曝/高光溢出 | 闪白 Light Wipe | "强光从画面消退，亮度回落到正常，显现出……" |
| 过暗/黑 | 黑场淡入 | "画面由暗渐亮，从黑暗中显现出……" |
| 主体畸形 | 不修，改接法 | 退回母图重新起，或插入遮挡桥接 |

**Prompt 模板（甩镜软着陆）**：
```
画面以极高的速度向【右】横向甩动，中途形成连续的运动模糊。
甩动逐渐减速，运动模糊收敛，画面稳定停留在【明确的新构图】。
减速过程中人物与环境的形态由模糊转为清晰，光影与色彩自然过渡，无闪烁、无跳变。
```

---

### T6 首尾帧双锁（First-Last Keyframe）

**原理**：两端定死，模型做中间插值（inbetween），是 AI 时代最接近传统"关键帧动画"的做法。

**两条铁律**：
1. **两张图的构图/比例/光位要接近**，差异过大 → 模型会硬凑出扭曲的中间态。
2. **Prompt 只描述"从 A 到 B 的过程"，不要重复描述 A 和 B 本身**（模型已经看到图了，重述会造成冲突重绘）。

**Prompt 模板**：
```
从首帧状态平滑过渡到尾帧状态。
过渡过程：【主体】以【速度】完成【变化，如：由坐姿转为站姿 / 由含苞转为盛开 / 由白天转为夜色】。
摄影机【保持固定 / 缓慢推进】，过渡全程构图稳定、主体位置连续移动，不瞬移、不跳切。
光影与色彩在过渡中【渐变方式与方向，如：由冷转暖、光位由左后方缓慢移到正前方】。
动作连续自然，中间过程物理合理，结束时准确落在尾帧构图。
```

**时长匹配**：5 秒做小过渡（姿态/微位移），10 秒做大过渡（场景/时间/形态变化）。过渡越大，越要用 10 秒。

---

### T7 同构衔接（Graphic Match）

**原理**：用**相同的视觉结构**跨越不同的时空——不靠像素连续，靠构图同构。观众脑补连续性，实际零像素衔接，因此漂移风险最低。

**同构维度**（任选其一匹配）：形状（圆→圆）、运动形态（旋转→旋转）、构图（人物占画面位置相同）、色彩（主色块一致）、光影（同一方向的强光带）。

**Prompt 模板（时间跳跃）**：
```
画面构图保持与上一镜相同的结构：人物位于画面【同一位置】，占画面比例一致。
在此基础上，时间发生跳跃：【白天 → 黄昏 / 夏天 → 冬天 / 空场 → 人满】。
摄影机保持机位与角度不变，只有光线色温、环境元素与人物服装发生变化。
变化以【渐变/一瞬】方式完成，构图始终稳定，不移动、不变形。
```

---

### T8 静止起步（Micro-Motion Start）

**原理**：图生视频在运动指令过猛时容易"炸开"（人物撕裂、背景扭曲）。遇到这种情况，第一镜降到"几乎不动"，第二镜再加速度，用**两镜接力实现一个大动作**。

**用法**：
- 镜A（0.5~1秒微动）：仅有呼吸、眨眼、衣摆、发丝、光影流动。
- 镜B（承接 A 的尾帧）：开始真正的位移动作。

**Prompt 模板（微动起步）**：
```
画面几乎静止，只有极轻微的生命感运动：人物自然呼吸、偶尔眨眼、衣摆与发丝极轻微飘动。
摄影机完全固定，构图不变，人物位置不变。
光影有极缓慢的流动，空气中的微尘缓慢漂浮。
整体稳定、安静、不产生任何位移与形变。
```

## 4. 尾帧可用性评估：五可三不可

### 可续帧（A/B 级）

| 等级 | 标准 | 处理 |
|---|---|---|
| **A** | 主体完整在画、姿态自然、模糊轻微、构图可承接、无变形 | 直接作下一镜首帧 |
| **B** | 主体完整但构图偏移/略紧/模糊偏重/边缘有杂物 | 图生图轻修（重绘强度 0.2~0.35）后使用 |

### 不可续帧（C/D 级）

| 等级 | 症状 | 处理 |
|---|---|---|
| **C** | 主体出画一半、极端特写无法接全景、姿态扭曲、明显过曝/欠曝、主体被前景大面积遮挡且下一镜需要同一主体 | 换接法：T3 遮挡桥接 / T5 光学软着陆 / T7 同构 |
| **D** | 人物形变（多指、脸崩）、画面糊成一片、多人粘连 | 不修：重生成上一镜，或退回母图重新起（放弃像素衔接） |

### 尾帧不可用时的四种补救

1. **重绘 Re-frame**：尾帧 → 图生图重绘（低重绘强度）修正构图与变形 → 作首帧。
2. **外扩 Outpaint**：主体贴边/出画时，向外扩画生成完整构图再作首帧。
3. **另建首帧**：用"母角色图 + 场景描述"单独生成一张符合下一镜设计的新首帧，靠 M0 多参考图锚定保证一致性（放弃像素衔接，保一致性）。
4. **改接法**：走 T3/T5/T7，把缺陷变成设计。

> 判断优先级：**一致性 > 衔接**。当"像素衔接"和"人物不崩"冲突时，永远选后者。观众能接受一个硬切，接受不了主角换脸。

## 5. 图生视频 Prompt 结构（与文生视频的六大区别）

这是本文件最重要的一节。图生视频不是"文生视频 + 一张图"，Prompt 逻辑完全不同。

| # | 区别 | 文生视频 T2V | 图生视频 I2V |
|---|---|---|---|
| 1 | **描述范围** | 描述整个画面 | **只描述"接下来发生什么"**，图里已有的不写 |
| 2 | **首帧处理** | 无 | 必须加**首帧锚定句**，否则模型重绘首帧 |
| 3 | **运动写法** | 运动在描述中隐含 | 必须显式**运动启动句**，否则"不动" |
| 4 | **镜头声明** | 可选 | 必须写明"固定"还是"怎么动"，不给就随机 |
| 5 | **时间结构** | 起承转合 | **增量时间轴**：0-0.5s / 0.5-3s / 3-5s |
| 6 | **结尾处理** | 不管 | 必须**收束定型句**：为下一镜留可续尾帧 |

### I2V 六句式模板（直接套用）

```
① 首帧锚定句：保持首帧中的【人物身份/服装/发型/构图/光位/色彩基调】完全不变，
② 运动启动句：随后【主体】以【速度：缓慢/平稳/中速/快速】向【方向】【动作】，
③ 镜头声明句：摄影机【完全固定 / 缓慢推进 / 同步后退跟拍 / 平行横移】，与主体保持【距离关系】，
④ 环境激活句：同时【2~3项环境微动：光影缓慢流动 / 微尘漂浮 / 衣摆与发丝轻微摆动 / 背景树叶晃动】，
⑤ 收束定型句：动作结束时【结束姿态与构图】稳定停住，为主体下一镜留出可延续状态，
⑥ 一致稳定句：全程人物身份、身体比例、服装发型一致，光位方向与色彩基调不变，运动轨迹连续自然，无突然位移、无变形、无镜头跳跃。
```

**① 首帧锚定句（Frame Echo）**：短、准、只锚定"怕变的东西"。写太长 = 描述过载 = 模型重绘。
- 好：`保持首帧中人物、服装与光位不变，`
- 坏：`保持首帧中一位穿着深蓝色风衣的短发中年女性站在雨中的街道上……`（这是在重新生成）

**② 运动启动句（Motion Ignition）**：图生视频第一大坑是"图不动"。必须给全 **谁动 + 往哪动 + 多快 + 多久**。主体运动优先于镜头运动；两者都没有 → 必然只出微动。

**⑤ 收束定型句（Landing State）**：为下一镜服务。写清楚结束时人物停在画面哪里、姿态是什么、看向哪。这是链式生成的生命线。

### 运动量—时长匹配表

| 时长 | 能承载的变化 | 建议 |
|---|---|---|
| **5 秒** | 1 个主动作 + 1 个镜头运动 + 环境微动 | 首选。控制力最强，尾帧最可控 |
| **10 秒** | 1 主动作 + 1~2 个阶段变化（起→承→转） | 大过渡、揭示、时间跳跃时用 |
| 首末帧差异大 | — | 用 10 秒；5 秒做不完会硬凑出扭曲中间态 |

### 增量时间轴写法（10 秒镜）

```
0.0–0.5s：从首帧状态起步，【起势动作】，摄影机【状态】。
0.5–3.0s：【主体主动作发展】，【镜头运动】，环境【变化】。
3.0–6.0s：【次级变化：光位移动 / 前景掠过 / 景深变化】。
6.0–9.0s：【动作推进至高潮或转折点】。
9.0–10.0s：动作收束，构图稳定停住，人物姿态停在【可延续状态】，为下一镜留接口。
```

## 7. 平台能力映射

不同平台能力不同，选技法前先确认手上的工具支持什么。**参数名以平台当前版本为准。**

| 能力维度 | 用途 | 备注 |

## 8. 十二种失败症状 → 处方

| # | 症状 | 原因 | 处方 |
|---|---|---|---|
| 1 | 首帧被"重画"，人物变了 | Prompt 重复描述了图中已有内容 | 删掉描述性内容，只留①首帧锚定句；换 M0 多参考图 |
| 2 | 图完全不动/只有微动 | 没有明确运动主体与方向 | 补②运动启动句（谁动+方向+速度）；调高运动强度参数 |
| 3 | 画面炸开/人物撕裂 | 运动指令过猛或时长过短 | T8 静止起步；拆成两镜；时长加到 10s |
| 4 | 接缝像跳切 | 两镜角度差 <30° 且景别未跳级 | 角度拉开 ≥30° 或景别跳 2 级 |
| 5 | 人物运动方向反了 | 违反 180 度规则 | 检查出画/入画方向；加"始终保持向【X】运动" |
| 6 | 下一镜把动作重做一遍 | 首帧取在动作起点 | 首帧取动作 60~70% 中段；Prompt 写"继续完成剩余动作" |
| 7 | 第 4~5 镜开始人物劣化 | 链式误差累积 | 锚点回注（母图直接/融合校正）；缩短链长 ≤5 镜 |
| 8 | 光色在接缝处跳变 | 两镜光位/色温未锁 | 母Prompt 色彩锁；接缝处统一"光源来自【方向】，色温【K】"；图生图统一调色后再入 |
| 9 | 主体贴边/出画，下一镜接不住 | 尾帧构图不可用 | 外扩 Outpaint；或改 T4 出画入画（本就要出画） |
| 10 | 正反打穿帮（两人变同向/换脸） | 反打直接从正打尾帧生成 | 反打用母角色图单独生成：视线方向相反、前景肩位相反、光位相反 |
| 11 | 首尾帧双锁中间态扭曲 | 两图差异过大 | 缩小首尾差异；时长加到 10s；加中间桥接帧分两段做 |
| 12 | 循环接缝有跳（做循环视频时） | 尾帧与首帧不一致 | 首尾用同一张图；Prompt 写"结束时回到起始构图" |

**反打戏正确做法（重点）**：正打与反打**不能链式继承**（会导致两人朝向同侧、光位穿帮）。正确流程是：正打尾帧 → 记录 End State（情绪/台词节点/视线）→ **反打用母角色图 + 反打构图描述单独生成** → 用状态账本保证情绪与光线关系一致，而不是靠像素继承。

## 9. 十六步工作法（衔接工程标准流程）

1. 定生成拓扑：星形 / 链式 / 混合（推荐混合）。
2. 建立母图集：角色母图、场景母图、道具图（M0 一致性基础）。
3. 定关键帧锚点：哪些镜必须是"设计好的关键帧"，哪些可以链式继承。
4. 出分镜表（含接法列）：每镜标注「首帧来源 + 接法 + 尾帧目标状态」。
5. 生成镜 01（通常从母图起，用 M1）。
6. 抽尾帧，做尾帧评级（A/B/C/D）。
7. A/B 级 → 作下一镜首帧；C/D 级 → 走补救（重绘/外扩/另建/改接法）。
8. 填跨镜状态账本：记录本镜 End State 七要素。
9. 按 I2V 六句式写下镜 Prompt（只写增量）。
10. 生成下一镜；比对首帧是否被重绘（漂移检测）。
11. 检视接缝：姿态/方向/景别轴/光色/道具/环境/情绪 逐项打分（Seam Seven）。
12. 分数不足 → 补桥接帧或换接法（T3/T5/T7）。
13. 每 3~5 镜执行一次锚点回注。
14. 全链跑完，通看一遍找累积漂移点，对漂移段做局部重生成。
15. 通过后统一出高清（1080p）。
16. 后期只做微调：接缝处可用 1~3 帧叠化/动效/音效掩盖残余跳点（**后期是补救，不是主要手段**）。

## 11. Prompt 模板库（可直接复制）

### 11.1 首帧续写通用母版
```
保持首帧中的【人物/服装/发型/构图/光位/色彩基调】完全不变，
随后【主体】以【速度】向【方向】【动作】。
摄影机【完全固定 / 缓慢推进 / 同步后退跟拍】，与主体保持【距离关系】。
同时【环境微动 2~3 项】。
动作结束时【结束姿态与构图】稳定停住，为下一镜留出可延续状态。
全程人物身份、比例、服装、发型一致，光影方向与色彩基调不变，运动轨迹连续自然。
```

### 11.2 动作中段交接（接上一镜未完成动作）
```
保持首帧画面中的人物姿态、服装与光位不变。
画面从运动进行中继续，不从静止起步：承接上一镜，人物【继续完成剩余动作】。
动作速度平稳，保持惯性、重心转移与跟随动作。
摄影机保持上一镜的机位高度与运动方式，不重新起势。
结束时动作完整收束，姿态稳定，不回弹、不重复。
```

### 11.3 出画 → 入画
```
人物从画面【左】边缘进入，沿【向右】方向以中速走入画面。
摄影机固定，人物始终向右运动，不折返、不转向镜头。
进入后减速停在【画面位置】，【看向画外右侧 / 转头】。
背景稳定，地面光影随人物移动连续变化，无瞬移。
```

### 11.4 遮挡桥接（前遮挡 → 后遮挡）
```
【上镜尾】前景【遮挡物】快速掠过画面并完全遮挡镜头，画面转暗。
【下镜首】遮挡物向【方向】移出画面，逐渐揭示出后面的【新空间与构图】。
揭示过程摄影机【固定/缓慢推进】，光影方向与遮挡前一致。
揭示完成后构图稳定，人物位于【位置】，视线看向【方向】。
```

### 11.5 甩镜软着陆
```
画面以极高速度向【右】横向甩动，形成连续运动模糊。
甩动逐渐减速，模糊收敛，稳定停留在【新构图】。
减速中人物与环境由模糊转为清晰，光影色彩自然过渡，无闪烁跳变。
```

### 11.6 首尾帧双锁
```
从首帧状态平滑过渡到尾帧状态。
过渡中【主体】以【速度】完成【变化描述】。
摄影机【固定/缓慢推进】，全程构图稳定、主体连续移动，不瞬移不跳切。
光影与色彩【渐变方式】，结束时准确落在尾帧构图。
```

### 11.7 同构衔接（时间跳跃）
```
保持与上一镜相同的构图结构：人物位于【同一位置】，占画面比例一致。
在此基础上时间发生跳跃：【白天→黄昏 / 空场→人满 / 夏→冬】。
摄影机机位与角度不变，只有光线色温、环境元素与服装变化。
变化以【渐变/一瞬】完成，构图始终稳定，不移动、不变形。
```

```
画面几乎静止，只有极轻微的生命感运动：自然呼吸、偶尔眨眼、衣摆发丝极轻微飘动。
摄影机完全固定，构图与人物位置不变。
光影极缓慢流动，空气微尘缓慢漂浮。
整体稳定安静，无位移、无形变。
```

### 11.9 对话正反打（反打单独生成，不链式继承）
```
【母角色图】中的人物位于画面【右】侧，面向画面【左】，视线看向画外左侧。
前景左下方有【对话者】的肩膀与后脑虚化轮廓，形成过肩构图。
人物【说/听】的状态：【口型微动 / 聆听点头 / 眼神轻微下移】，情绪强度【1-5】。
主光来自【与正打相反的方向】，保持与正打一致的色温与环境色。
摄影机固定，轻微呼吸感，构图稳定，人物身份与服装与母图完全一致。
```

### 11.10 打斗接招（配合 `16-武术动作与动作指导.md`）
```
保持首帧中人物的姿态、服装、武器与光位不变。
承接上一镜的攻击动作：【A 的拳/腿/武器】以【高速】击中【B 的部位】。
B 产生完整反应链：接触瞬间身体形变 → 重心被推离 → 沿【方向】飞出/后退 → 衣摆与发丝跟随摆动。

```

## 12. 核心原则（四条）

1. **End State = 下一镜 Start State**：每个镜头的结尾都是为下一个镜头服务的，不是独立结束。写 Prompt 时就写清楚"停在哪"。
2. **只写增量，不重复画面**：图里有的东西不再描述，描述等于命令模型重画。
3. **从运动中接，不从静止起**：链式衔接的本质是动势延续，静止起步必然产生断裂感。
4. **一致性 > 衔接**：像素衔接服务于人物与环境稳定。冲突时，宁可硬切，不可换脸。
