# 07 模板与完整实例

生成完整 Prompt 时使用本文件的模板与实例作为输出格式标准。

## 万能模板（Seedance 2.0 / 2.5 十段式）

```
【01｜主体】
主体：[人物/产品/建筑/生物/场景]
主体位置：[画面中央/左侧/右侧/前景/中景/远景]

【02｜人物动作】
主体动作：[向前走/转身/抬头/回头/奔跑/停止/伸手/环绕/对视/攻击]
动作速度：[缓慢/平稳/中速/快速]
动作要求：动作连续自然，运动轨迹稳定，符合真实物理规律。

【03｜人物关系】
人物关系：[面对面/擦肩而过/追逐/对峙/跟随/围绕/聚拢/分散]
人物走位：人物按照明确空间轨迹运动，保持人物之间稳定的距离关系。

【04｜摄影机】
镜头语言：[推/拉/摇/移/跟/升/降/环绕/穿越/变焦/甩镜/希区柯克变焦/长镜头/主观/过肩]
运动速度：[缓慢/平稳/中速/快速]
镜头方向：[向前/向后/左/右/上/下/环绕]
摄影机要求：摄影机运动平滑、连续、稳定，不出现突然跳跃和不自然位移。

【05｜人物与摄影机同步】（可选）
人物向前移动，摄影机同步向后跟拍。
人物缓慢抬头，摄影机同步向前推进。
人物保持静止，摄影机缓慢围绕主体运动。
人物从左向右移动，摄影机保持平行横向跟拍。

【06｜空间层次】
前景：[树枝/花瓣/人物/建筑/烟雾/粒子/灯笼/植物]
中景：[主要人物/产品/建筑主体]
背景：[山脉/城市/宫殿/天空/云海/远景建筑]
空间要求：前景、中景、背景具有明确空间层次，并形成自然视差。

【07｜环境运动】
环境：[云雾/树叶/水面/火焰/花瓣/光影/粒子/雪/雨]
运动：环境元素产生自然、连续、合理的动态。

【08｜遮挡】（可选）
前景元素偶尔从镜头前经过，形成自然遮挡。
或：人物从镜头前近距离经过，形成自然擦镜效果。

【09｜转场】（可选）
进入下一镜头：[前景遮挡/人物擦镜/烟雾遮挡/穿越空间/镜头推进/镜头拉远/光影变化/甩镜/动作匹配]
要求：镜头运动连续自然，通过运动方向完成无缝衔接。

【10｜稳定性】
整体动作连续自然。
摄影机运动平滑稳定。
保持人物身份、人物比例、服装、发型一致。
保持建筑结构、空间透视和前中后景关系一致。
保持光影方向一致。
保持运动方向一致。
避免人物变形、突然位移、人物瞬移、镜头跳跃、不自然加速、背景结构突然变化。
```

输出时不要保留【】编号，改写为连贯段落（见下方实例）。

## Seedance 高级模板（含摄影规格）

镜头开始：【起始构图】→ 人物：【角色状态】→ 动作：【主体动作】→ 摄影机：【景别+机位+焦段】→ 运动：【推进/后退/跟拍/环绕/升降】→ 焦点：【主体→背景 / 背景→主体】→ 环境：【风/雨/雾/人群/建筑】→ 光线：【主光/逆光/体积光】→ 色彩：【冷/暖/金属/低饱和】→ 物理：【重量/惯性/布料/发丝】→ 结尾：【最终构图】。

## 时间轴式导演 Prompt（适合复杂动作/长镜头）

按秒拆解，比形容词堆砌更可控：

- 0–2秒：建立空间。Wide Shot + Static Camera
- 2–4秒：人物进入。Follow Shot
- 4–6秒：摄影机靠近。Slow Dolly In
- 6–8秒：人物转身。Rack Focus
- 8–10秒：背景揭示。Crane Up
- 10–12秒：视觉高潮。Orbit
- 12–15秒：停留。Hold Shot

英文高级结构：The shot begins with...（镜头起始）→ As the character moves...（动作变化）→ the camera slowly tracks backward...（摄影机变化）→ rack focus from...（焦点变化）→ wind moves...（环境变化）→ light gradually shifts...（光线变化）→ The shot ends with...（结尾状态）。

## 声音 Prompt 词库（Seedance 2.5 支持音视频联合设计）

环境：ambient city noise 城市环境声｜forest ambience 森林氛围｜wind/rain/thunder/water/crowd/traffic。
动作：footsteps 脚步声｜cloth movement 衣物摩擦｜weapon impact 武器撞击｜door creak 门吱呀｜metal clash 金属碰撞｜glass breaking 玻璃碎裂。
情绪：deep silence 深度静默｜tense silence 紧张静默｜eerie ambience 诡异氛围｜peaceful ambience 平静氛围｜mysterious drone 神秘持续音。
音乐：orchestral score 管弦配乐｜minimal piano 极简钢琴｜cinematic strings 电影弦乐｜electronic pulse 电子脉冲｜percussion build 打击乐渐强。

## 三级系统（Prompt 质量标准）

- LEVEL 1 描述："东方女侠在雪中走路，电影感。"——只告诉模型"是什么"。
- LEVEL 2 摄影："东方女侠，35mm，低机位，全身，慢推，浅景深，冷色逆光。"——告诉模型"怎么拍"。
- LEVEL 3 导演："以极远景建立雪夜古城空间，东方女侠作为小型主体位于城门中央。摄影机从静止的远景开始，以35mm逐渐向前推进，经过积雪和灯笼形成的前景遮挡，转为低机位全身镜头。人物开始缓慢向镜头走来，摄影机同步后退保持人物大小稳定，随后进行小幅左侧弧线运动，揭示身后的巨大城门。焦点从前景飘雪转移到人物眼睛，冷色月光与暖色灯笼形成冷暖分离，衣摆、发丝和雪花保持自然物理运动。最后摄影机缓慢升高，将人物重新缩小到宏大环境中，形成史诗式收束。"——导演语言+摄影语言+场面调度+AI生成语言。

输出标准：所有生成的 Prompt 必须达到 LEVEL 3。

## 完整实例库

### 示例一｜东方史诗

"巨大的东方宫殿矗立于群山与云海之间，一名身穿黑金长袍的人物从远处缓慢向宫殿走去，身后数名侍从保持整齐队形跟随；摄影机从人物正前方缓慢向后移动，以与人物相同的速度进行稳定跟拍，始终保持主角位于画面中心；前景金色树枝随着微风轻轻摆动，偶尔从镜头前掠过形成自然遮挡；中景人物保持清晰稳定，远景宫殿和群山笼罩在流动薄雾之中，云层缓慢移动，阳光穿过云层形成动态光束；人物与背景产生明显视差，前景、中景、远景形成清晰空间层次；人物接近宫殿后缓慢停下并抬头，摄影机同步缓慢推进至人物半身镜头，最终通过前景金色树枝遮挡镜头自然进入下一场景；整体采用电影级场面调度，动作连续自然，摄影机运动平滑稳定，保持人物身份、服装、发型、建筑结构和空间关系一致，避免人物变形、突然位移、镜头跳跃和不自然加速。"

### 示例二｜商业产品

"高端科技产品悬浮于深色极简空间中央，产品保持稳定，摄影机缓慢向产品推进，轮廓光逐渐显现；随后摄影机沿产品表面进行平滑横向移动，展示金属纹理和结构细节；摄影机继续完成180度缓慢环绕，光线沿产品轮廓流动；随后摄影机逐渐拉远，完整展示产品与环境关系；背景保持简洁稳定，细微粒子漂浮，局部光束缓慢移动；最终摄影机稳定停留在产品主体构图，品牌视觉区域保持清晰；动作连续自然，镜头运动平滑，产品外观、材质、比例和结构始终保持一致。"

### 示例三｜剧情人物

"人物站在昏暗宫殿中，突然注意到远处异常；人物缓慢抬头并转移视线，摄影机从中景缓慢推进至面部特写；背景逐渐虚化，前景柱子形成轻微遮挡；人物眼神发生明显变化后，摄影机从人物肩后切换至对面方向，形成过肩镜头；远处另一个角色缓慢进入画面，两人保持眼神交流；摄影机进行轻微横向移动建立空间关系；整体保持人物身份、服装、发型、空间位置和光影方向稳定，动作连续自然。"

### 示例四｜战斗

"两名角色在空旷东方庭院中对峙，双方保持一定距离；摄影机低角度缓慢推进至双方眼神特写；其中一名角色突然冲向前方，摄影机立即切换为低角度跟拍；人物挥动武器完成一次攻击，摄影机同步进行短距离半环绕；攻击结束瞬间快速向右甩镜，通过自然运动模糊进入敌方主观视角；镜头继续跟随敌人后退动作；所有动作保持清晰的空间方向关系和连续运动轨迹，避免人物变形、武器变化和突然位移。"

### 示例五｜东方女侠（含摄影规格）

"远景建立镜头，一名身穿黑金汉服的东方女侠独自站在暴雪中的古代城门前。35mm广角，低机位，人物位于画面中央偏下，摄影机从远处缓慢向前推进，同时轻微向左弧形移动，前景飘雪形成明显视差。随着摄影机靠近，背景城墙逐渐进入浅景深，焦点从飘落的雪花缓慢转移到女侠眼睛。冷蓝月光作为环境主色，城门两侧暖黄色火把形成冷暖对比，衣摆和长发被风自然吹动。镜头最后停留在中近景，人物抬眼直视远方，保持稳定构图与自然身体比例。"

### 示例六｜人物情绪（移焦范例）

"中近景，85mm肖像镜头，平视摄影机，人物坐在雨夜咖啡馆窗边。摄影机保持极慢推进，浅景深，背景城市灯光形成柔和散景。开始时焦点停留在人物手中的旧照片，随后缓慢Rack Focus转移至人物眼睛。人物几乎保持静止，仅有细微呼吸、眨眼和肩膀运动，窗外雨滴不断滑过玻璃，冷蓝城市光与室内暖黄色灯光形成明显对比。镜头最后停留在眼睛特写，保持情绪停顿。"

## 导演讲解结构（输出后附的"设计说明"格式）

每次输出 Prompt 后附：

```
【导演设计说明】
- 镜头目的：展示 / 强调 / 转场 / 叙事
- 主镜头运动：XX + 辅助运动：XX（共1主+0~2辅）
- 空间设计：前景XX / 中景XX / 背景XX
- 转场方式：XX
- 连续性保障：人物一致性 / 空间稳定 / 光影方向 / 运动方向
```

## 导演语言九问（最终校验）

生成任何 Prompt 前后自检：
1. 拍什么？（主体）2. 拍多近？（景别）3. 从哪里拍？（机位）4. 用什么视觉看？（焦段）5. 怎么构图？6. 摄影机怎么动？7. 人物怎么动？（调度+表演）8. 光、色、声音怎么组织？9. 为什么这么拍？（戏剧意图）

导演语言 = 视觉选择 + 摄影机选择 + 演员调度 + 时间选择 + 声音选择 + 戏剧意图。
AI 导演 Prompt = 导演语言的机器可执行表达。
