# 24 AI视频生成行为控制引擎

> 定位：本库是整个导演系统从“影视语言”进入“AI生成语言”的翻译层。它解决一个核心问题：**人类导演知道想要什么，但生成模型必须通过明确、有限、可继承的变量才能更稳定地执行。**
>
> 核心原则：**不要把AI Prompt写成形容词清单，要把导演意图拆成可观察、可执行、可验证的状态与变化。**

## 一、AI导演Prompt编译链

```text
用户需求
↓
导演意图
↓
叙事功能
↓
视觉心理
↓
Blocking
↓
Camera
↓
Action
↓
Environment
↓
Light / Color / Sound
↓
Start State
↓
Time Sequence
↓
End State
↓
AI Prompt
↓
生成
↓
失败诊断
↓
修复Prompt
```

## 二、抽象词 → 可执行变量

| 抽象词 | 转译方向 |
|---|---|
| 电影感 | 景别+焦段+景深+光线+运动+色彩 |
| 高级 | 克制构图+材质+低噪视觉+受控色彩 |
| 震撼 | 尺度+低机位+空间层级+运动幅度 |
| 压迫 | 距离+窄视野+遮挡+负空间+低机位 |
| 孤独 | 小主体+大环境+留白+低动作密度 |
| 浪漫 | 柔光+浅景深+缓慢运动+亲密距离 |
| 真实 | 物理动机+次级运动+合理惯性+不完美 |
| 紧张 | 注意力集中+动作停顿+视线+声音领先 |
| 史诗 | 空间尺度+纵深+层级+稳定摄影机 |

## 三、Observable Rule

AI最容易执行的是可观察状态：

### 弱
> 他很害怕。

### 强
> 他先看向门口，停顿半秒，吞咽，肩膀轻微收紧，手指停止敲桌，最后才缓慢转头。

原则：

> **情绪词可以存在，但必须附带行为证据。**

## 四、状态机

所有复杂镜头都拆成：

```text
START STATE
↓
TRIGGER
↓
TRANSITION
↓
PEAK
↓
SETTLE
↓
END STATE
```

适用于：

- 人物动作
- 表情
- 摄影机
- 灯光
- 环境
- 道具状态

## 五、一镜一主变量

每镜只设置一个最高优先级变化：

> 人物走动
或
> 摄影机推进
或
> 表情变化
或
> 光线变化

可以有辅助次级运动，但不能让多个复杂变量同时竞争。

## 六、复杂度预算

一个镜头的复杂度可以粗略理解为：

**人物数量 × 动作复杂度 × 摄影机复杂度 × 环境动态复杂度 × 状态变化数量。**

当多个维度同时升高，AI不稳定概率通常显著增加。

### 降复杂度顺序

1. 删除次要人物动作
2. 删除次要摄影机运动
3. 简化环境运动
4. 固定焦点
5. 缩短动作链
6. 拆镜头

## 七、Prompt中最重要的五类状态

### Identity State
人物身份、脸、服装、身体特征。

### Spatial State
人物位置、空间坐标、相互距离。

### Performance State
表情、眼神、身体状态。

### Camera State
焦段、位置、方向、运动、焦点。

### World State
天气、时间、道具、建筑、光色。

## 八、Persistent State

多镜头生成时，上一镜结束状态必须成为下一镜默认输入：

```text
SHOT 01 END
A站在门左侧，右手握杯，面向B
↓
SHOT 02 START
A仍在门左侧，右手仍握杯，面向B
```

除非剧本明确改变。

## 九、运动语言必须有三件事

任何运动写法尽量包含：

**方向 + 路径 + 速度/节奏**。

例如：

> 从画面左侧向右侧缓慢移动，沿桌边平行横移，速度与人物步幅保持一致。

## 十、人物动作结构

### 弱Prompt
> 男人走到窗边。

### 强Prompt
> 男人从画面左侧起步，沿墙边向右前方走四步，在窗前停下；肩膀先停，脚步再停止，随后抬头看向窗外；结束时保持站立状态。

## 十一、摄影机结构

```text
Camera Position
+ Lens
+ Main Movement
+ Movement Relationship
+ Focus
+ End Position
```

例如：

> 摄影机位于人物前方，50mm中近景，缓慢向后平移跟拍，始终保持胸口以上构图；人物停下时摄影机同时减速并在一步惯性后停稳。

## 十二、Environment Secondary Motion

环境运动分：

- 主环境运动
- 次环境运动
- 微环境运动

例如雨夜：

主：雨线持续下落
次：积水被鞋底踩开
微：衣摆、发丝、远处霓虹反射轻微变化

## 十三、物理真实性语言

优先使用：

- 惯性
- 重力
- 阻力
- 接触
- 反作用
- 软组织延迟
- 布料Secondary Motion
- 水体响应
- 阴影随光源变化

## 十四、AI转译的“导演形容词清洗器”

删除无执行价值的连续形容词：

> 震撼、宏大、唯美、电影感、真实、史诗、超级高级。

然后各自拆成：

> 空间尺度 / 光线 / 镜头 / 材质 / 运动 / 声音 / 色彩。

## 十五、Prompt层级

### LEVEL 1：描述
> 一个男人在雨夜走路。

### LEVEL 2：摄影
> 雨夜街道，中景，50mm，跟拍。

### LEVEL 3：导演
> 男人从左向右沿湿街缓慢走动，摄影机同步后退保持距离，前景车辆偶尔擦过形成视差，冷色街灯在湿地面形成反射，人物经过便利店暖光时肤色短暂转暖，最终停在雨幕前。

### LEVEL 4：工程
> 在以上基础上加入Identity/Spatial/Camera/Performance/World State及Start/End State。

## 十六、AI生成模式选择

### Text-to-Video
适合快速探索：

- 概念
- 环境
- 简单动作
- 非严格角色连续性

### Image-to-Video
适合：

- 已锁定角色
- 已锁定场景
- 产品展示
- 固定构图延展

### 首尾帧/状态帧
适合：

- 起点和终点必须明确
- 大幅空间变化
- 人物位置变化
- 状态连续镜头

### 多参考
适合：

- 角色+服装
- 场景+道具
- 多资产一致性

**注意：具体功能与限制应按所使用模型/版本的当前官方能力调整，不在本文件虚构固定参数。**

## 十七、Prompt四段结构

```text
A. 固定资产
角色 / 场景 / 服装 / 道具 / 风格

B. 起始状态
人物位置 / 动作 / 情绪 / Camera State

C. 时间过程
0–X秒发生什么；X–Y秒发生什么；Y–Z秒发生什么

D. 结束状态
人物位置 / 动作 / 情绪 / Camera State / 环境状态
```

## 十八、失败诊断树

### 人物漂移
→ Spatial State不明确
→ 增加锚点、关系、路径

### 动作跳变
→ Start/End State缺失
→ 拆分动作、明确起止

### 摄影机乱跑
→ 多主运动竞争
→ 保留一个主运动

### 背景变形
→ World State不稳定
→ 固定场景锚点、减少复杂动态

### 表情瞬切
→ Performance State断裂
→ 加入Processing与Reaction

### 光线乱跳
→ 光源动机不明确
→ 固定主光源方向与颜色

### 角色换衣
→ Identity/Costume State未继承
→ 使用角色母状态

## 十九、修复优先级

```text
Identity
>
Spatial
>
Main Action
>
Camera Direction
>
Focus
>
Environment
>
Light/Color
>
Secondary Effects
```

## 二十一、最终Prompt母版

```text
【项目与资产锁定】
角色、服装、场景、道具、时间、风格保持一致。

【START STATE】
主体位于[空间位置]，身体朝向[方向]，当前状态[状态]；摄影机位于[位置]，使用[焦段/景别]，焦点锁定[对象]。

【ACTION / PERFORMANCE】
主体从[起点]向[终点]执行[一个主动作]；动作按“准备→执行→反应→结束”自然完成。

【CAMERA】
摄影机以[主运动]沿[路径]移动，与主体保持[速度/距离关系]；在[时间节点]完成[焦点/构图]变化。

【ENVIRONMENT】
前景[元素]产生[运动]形成视差；中景[元素]跟随主体空间关系；背景[元素]保持低强度连续动态。

【LIGHT / COLOR】
主光源来自[来源]，方向[方向]，色温关系[冷暖]；整体色彩以[主色]为基底。

【TIME SEQUENCE】
开始：...
中段：...
结尾：...

【END STATE】
主体最终位于[位置]，保持[动作/情绪]；摄影机停在[位置]；环境状态为[状态]。
```

## 二十二、核心公式

> **AI可执行导演语言 = 意图 + 状态 + 可观察动作 + 摄影机关系 + 时间顺序 + 结束状态 + 连续性约束。**
