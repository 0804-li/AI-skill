## 主体类型镜头组合库

### 人物类（推荐：推、跟、环绕、主观、过肩、长镜头）

- 角色出场："远景展示环境，人物从背景向前景走来，摄影机缓慢跟随并逐渐推进至中景。"
- 角色展示："人物保持静止，摄影机进行360度缓慢环绕，展示人物服装、发型与整体造型。"
- 情绪镜头："人物保持静止，摄影机缓慢推进至面部特写，环境逐渐虚化，人物眼神发生细微变化。"
- 背影镜头："人物背对镜头向远处走去，摄影机缓慢跟拍，最终逐渐拉远让环境吞没人物。"

### 产品类（推荐：推、环绕、移、穿越、甩镜、拉）

- 高端产品广告："产品静置于黑色空间中央，摄影机缓慢推进，随后沿产品表面横向移动，再进行180度环绕，边缘光沿产品轮廓移动，最终缓慢拉远展示完整产品。"
- 科技产品："摄影机高速穿越产品内部结构，组件依次展开，镜头完成横向移动后快速甩镜进入下一功能展示。"
- 产品细节："摄影机缓慢推进至产品局部，光线沿材质表面移动，强调纹理、结构和质感。"

### 建筑类（推荐：拉、升、摇、移、环绕、穿越）

- 建筑揭示："建筑局部特写，摄影机缓慢向后拉远，逐渐揭示完整建筑和周围环境。"
- 建筑仰拍："摄影机从建筑底部低角度缓慢向上运动，屋檐、楼层和天空依次展开。"
- 建筑环绕："摄影机围绕建筑进行缓慢弧形运动，从侧面转向正面，完整展示建筑体量。"
- 建筑内部："摄影机从门洞进入建筑内部，穿过长廊，横向展示空间结构，最终进入庭院。"

### 东方场景类（推荐：低角度推进、升镜、横向移镜、环绕、穿越、拉远）

- 东方宫殿："摄影机从云海低位缓慢推进，穿过流动薄雾，东方宫殿从远处逐渐显现；随后摄影机缓慢升高，越过屋檐，展示层层建筑、远山与云海。"
- 东方山水："前景竹叶随风摆动，中景人物站立，远景群山隐于薄雾之中，摄影机缓慢横向移动，形成明显前后景视差。"
- 东方古城："摄影机沿古城长街缓慢向前推进，前景行人和灯笼形成遮挡，中景人物向前行走，背景建筑和灯光逐层展开。"
- 东方仪式："主体位于中心保持静止，群体从两侧缓慢向中心聚拢，摄影机低角度缓慢推进，烟雾和旗帜同步运动，形成庄重仪式感。"

### 打斗类（推荐：跟拍、环绕、甩镜、主观、长镜头）

- 战斗开始："双方对峙，摄影机缓慢推进至人物眼神特写，随后快速甩镜进入战斗动作。"
- 追击："摄影机低角度高速跟随人物奔跑，背景快速掠过，保持人物运动方向一致。"
- 近身攻击："摄影机紧跟人物动作，从侧面快速环绕半周，在攻击瞬间产生短促运动模糊。"
- 主观战斗："采用人物第一视角观察敌人，摄影机随着身体运动自然晃动，敌人快速接近。"
- 连续长镜头："摄影机连续跟随人物完成奔跑、转身、闪避和攻击动作，保持空间关系稳定，不进行明显镜头切换。"

**打斗铁律**：AI 打斗一个镜头只设计一个主要动作。不要在单个镜头同时安排跳跃+翻滚+三次攻击+转身+360环绕+甩镜。动作越多，运动越容易失控。

## 商业广告镜头公式

产品广告标准结构：产品出现 → 缓慢推进 → 环绕展示 → 局部细节 → 功能展示 → 空间拉远 → 品牌Logo。

示例："产品静置于深色空间，摄影机缓慢推进，产品轮廓逐渐显现；摄影机沿产品表面横向移动，展示材质细节；随后进行180度环绕，光线沿产品边缘流动；摄影机快速拉远展示完整产品与环境，最终稳定定格在品牌视觉中心。"

广告专属语言：Product Reveal 产品揭示｜Product Hero 产品英雄镜头｜Macro Detail 微距细节｜Material Reveal 材质揭示｜Surface Glide 表面滑行｜Product Orbit 产品环绕｜Floating Product 悬浮产品｜Exploded View 拆解视图｜Splash Shot 液体飞溅｜Beauty Lighting 美妆灯光｜Logo Reveal 标志揭示｜Light Scan 扫光。

## 剧情镜头公式

- **发现**：环境大全景 → 人物发现异常 → 摄影机缓慢推进 → 面部特写
- **决定**：人物低头 → 缓慢抬头 → 摄影机推进 → 眼神坚定
- **离开**：人物背影 → 摄影机跟拍 → 逐渐拉远 → 环境吞没人物
- **相遇**：双方从不同方向进入 → 摄影机横向移动 → 两人逐渐靠近 → 停止 → 过肩镜头
- **冲突**：人物对峙 → 缓慢推进 → 眼神特写 → 快速甩镜 → 动作开始

## 电商带货视频公式（与品牌广告是两套逻辑）

**品牌广告卖形象，带货视频卖转化率。** 品牌广告可以从空镜慢慢铺垫，带货视频前3秒掉完播就全完了。不要套用商业广告公式。

### 一、黄金三段结构

| 段落 | 时长占比 | 任务 | 唯一KPI |
|---|---|---|---|
| **诱惑（0–25%）** | 前3秒是生死线 | 用最强画面锁住手指 | **完播率** |
| **信任（25–55%）** | 中段 | 产地/工艺/规格的可视化证据 | **信任度** |
| **转化（55–100%）** | 尾段 | 使用场景 + 促销信息 + CTA | **点击率** |

**第一帧必须是全片最强的食欲/视觉画面**（不是Logo、不是产地空镜、不是包装盒）。品牌广告那套"先氛围后产品"在带货里等于自杀。

### 二、卖点 → 画面证据对应法（核心方法论）

**不要写"新鲜多汁"，要拍汁水真的流下来。** 每个卖点必须有一条可作为证据的画面，否则就是空话。

| 抽象卖点（废话） | 画面证据（可执行） |
|---|---|
| 新鲜 | 晨露挂在绒毛上 / 刚摘下的果蒂还是青的 |
| 多汁 | 刀切瞬间汁水爆出 / 手捏时汁水从裂缝渗出 |
| 甜 | 糖度计数值 / 果肉断面在光下的蜜色反光 |
| 大个 | 与手掌、鸡蛋、硬币的同框对比 |
| 软糯 | 勺子轻轻一压就陷下去 / 果肉在勺中颤动 |
| 现摘现发 | 枝头→手→包装盒→快递箱的连续动作链 |
| 运输安全 | 凹槽包装 + 开箱时完好无损 |
| 产地正宗 | 桃园/果园的真实环境与土壤植被 |

**自检：如果把所有字幕删掉，画面还能不能把卖点讲清楚？** 不能，就是画面证据不足。

### 三、前3秒钩子的五种类型（选一个，别混）

1. **破坏钩子**（食物类最强）：刀切开/手掰开/咬下去的瞬间，汁水爆出，微距慢动作
2. **反差钩子**：极干 vs 极湿、极热 vs 极冰的同框
3. **过程钩子**：从"原料"到"成品"的一镜到底变化
4. **悬念钩子**：看不到主体，只有声音与局部，最后一刻揭示
5. **尺度钩子**：极微距（肉眼看不见的细节）或极大远景（规模震撼）

**食物类带货，破坏钩子转化率最高。**

### 四、ASMR 声音优先原则

带货视频大量用户静音观看，但**开声音的用户转化率显著更高**。因此：

- **声音按"主声道"标准设计**：切割声、汁水声、气泡声、咀嚼声、冰水声——全部放大、清晰、节奏化
- **同时遵守"静音可看"原则**：每个卖点在纯画面下依然成立，声音是加倍器而非必需品
- **关键动作配关键声音**：掰开必配音、咬下必配音、倒水必配音。ASMR的节奏本身就是剪辑节奏

### 五、竖版与字幕安全区（电商主战场是9:16）

| 区域 | 用途 | 构图要求 |
|---|---|---|
| 上方 1/4 | 平台UI遮挡区 | 不放关键信息 |
| **中部 1/2** | **主体与动作区** | 所有产品与动作集中于此，横版裁切也保得住 |
| 下方 1/3 | **字幕/卖点/价格区** | 保持相对简洁，避免文字压在杂乱纹理上 |

**构图铁律：主体永远在中部安全区，四周留出裁切余量。** 这样一条母版可同时输出9:16（抖音/小红书）、16:9（详情页/淘宝主图视频）、1:1（信息流）。

### 六、信息节奏与CTA

- **每5–8秒一个卖点**，一个卖点只讲一件事，不叠加
- 卖点字幕用"短句+数字"（"单果200g+"优于"我们的桃子非常大"）
- **CTA必须具体**：不是"快来买"，而是"下方链接，现摘现发，今日下单48小时内发出"
- 结尾定格至少3秒，给品牌信息与购买路径留足阅读时间

## 导演意图词库

- 表现力量：empower / dominate / monumental / heroic / commanding / imposing（强大、权威、统治、英雄、压迫、不可挑战）
- 表现脆弱：vulnerable / fragile / isolated / small / exposed（脆弱、孤独、渺小、无助、暴露）
- 表现神秘：mysterious / enigmatic / hidden / obscured / unrevealed（神秘、未知、隐藏、遮蔽）
- 表现紧张：tense / claustrophobic / suspenseful / unstable / urgent
- 表现浪漫：intimate / tender / soft / warm / dreamlike
- 表现史诗：epic / monumental / grand / vast / majestic / mythic

## 导演动作词（比"镜头移动"更专业的表达）

接近：approach / move toward / push into / dolly toward｜远离：retreat / pull away / dolly back｜观察：observe / linger / hold on｜发现：reveal / discover / uncover｜跟随：follow / track / chase｜包围：orbit / circle / encircle｜穿越：pass through / fly through / move through｜窥视：peek / observe from behind / long-lens observe｜进入心理：slow push-in / intimate close-up / rack focus。
