# 10 导演风格签名词库

用户说"我要王家卫的感觉""维伦纽瓦那种压迫感"时，直接调用对应签名卡，输出整组可复制的风格 Prompt 片段。每张卡包含：签名元素清单 + 可复制Prompt片段 + 适用场景 + 注意事项。

**核心原则：风格=镜头调度+光+色+质感的固定组合，缺一个元素风格就不成立。** 用签名卡时整套调用，不要只取单个元素。

## ① 王家卫 Wong Kar-wai

**签名元素**：抽帧/帧频拖影、大广角怼脸、前景遮挡（门框/栏杆/玻璃）、霓虹夜色、暧昧高饱和暖色、人物擦肩与错过、时钟母题

**可复制Prompt片段**：
```
抽帧步进式运动，人物动作带拖影残像，大广角贴近人物面部，前景被门框和玻璃瓶局部遮挡，画面只露出人物半张脸，霓虹灯暖红与暗绿交织的夜色，雨后湿面反射，人物擦肩而过互不对视，暧昧压抑的欲望感，高饱和暖调中透着孤独
```
**适用**：都市情感、暧昧关系、错过与遗憾、夜店/排档/公寓走廊

**注意**：抽帧+拖影是灵魂，AI对"抽帧步进""步进式运动""动作残像"响应较好；少了这个元素就不是王家卫。

## ② 韦斯·安德森 Wes Anderson

**签名元素**：中心对称构图、平面横移跟拍、粉彩色板、俯拍道具排列、快速横摇（whip pan）、人物面镜头表情、画框式布景

**可复制Prompt片段**：
```
严格中心对称构图，人物位于画面正中直面镜头，粉彩色板（奶油黄/雾粉/薄荷绿），摄影机水平横移跟随人物走过一排门洞，每经过一扇门场景元素对称更换，快速横摇切换视线，俯视角度展示桌面道具整齐排列，童话式平面布景，轻微幽默的仪式感
```
**适用**：喜剧、广告、MV、任何需要"设计感"的场景

**注意**：对称必须写"严格中心对称"并强调"直面镜头"；横移+横摇组合缺一不可。

## ③ 丹尼斯·维伦纽瓦 Denis Villeneuve

**签名元素**：极简构图、人物渺小vs巨物尺度对比、单色雾气、剪影逆光、缓慢横移/推近、巨物局部揭示、尘埃粒子

**可复制Prompt片段**：
```
极简构图，人物作为渺小剪影立于画面下三分之一处，背景是沉入雾气的巨大建筑轮廓，单色调（沙金/冷灰），缓慢横移逐渐揭示巨物全貌，逆光下人物边缘一线轮廓光，空气中悬浮尘埃粒子，压迫性的沉默与体量对比，史诗但克制
```
**适用**：科幻、灾难、东方玄幻大场面、任何"个体面对庞然大物"的戏

**注意**：核心是尺度对比——必须同时写"渺小人物"和"巨大对象"；节奏要"缓慢"，禁用快切快摇。

## ④ 罗杰·迪金斯 Roger Deakins

**签名元素**：自然光/单一动机光源、剪影背光名场面、长镜头、柔和中间调、火光/手电光、蓝橙夜色

**可复制Prompt片段**：
```
自然光质感，单一动机光源（窗口天光/手电光束）主导画面，人物背对光源形成半剪影，柔和的中间调过渡，长镜头不切，摄影机缓慢环移，光源色温与环境保护色形成克制的冷暖层次，写实而有诗意的光，画面安静呼吸
```
**适用**：写实剧情、公路片、田园、犯罪写实（他拍过《银翼杀手2049》《1917》《老无所依》）

**注意**：迪金斯的核心是"光的真实感"——光源必须在画内有出处；忌讳彩色滤光片式乱加色。

## ⑤ 克里斯托弗·诺兰 Christopher Nolan

**签名元素**：IMAX大画幅质感、实拍实爆的物理真实、冷暖对撞但整体克制、旋转/倒置空间、时间交叉剪辑线索、宏大配乐驱动

**可复制Prompt片段**：
```
IMAX大画幅质感，超高细节密度的实景空间，物理真实的烟尘与碎屑飞溅，冷蓝环境与暖色光源对撞但整体色彩克制，摄影机随人物冲入危险区域大幅运动，空间在旋转中重新定义上下方向，粒子与气流细节丰富，庄严的宏大感，写实特效质感
```
**适用**：动作、劫案、科幻、反转结构叙事

**注意**：写"物理真实"对抗AI的塑料CG感；诺兰风格忌讳过度滤镜和柔焦。

## ⑥ 张艺谋 Zhang Yimou

**签名元素**：色彩即叙事（红/黄/白/黑的大色块）、大对称与大排布群像、仪式化调度、东方构图、逆光剪影群像

**可复制Prompt片段**：

**适用**：古装、东方玄幻、仪式场面、大群像戏

**注意**：色彩必须"成片成块"而非点缀；群像动作要写"整齐同步"才出仪式感。

```
手绘水彩动画质感，赛璐璐上色，画面充满对自然细节的凝视——风掠过草浪形成波纹，云朵缓慢变形，裙摆和头发被风掀起，蒸汽从食物上升起，广角中景人物与自然环境平等共存，色彩温润饱和但不艳俗，万物有灵的温柔注视感，吉卜力式呼吸感
```

**注意**：必须声明"手绘动画质感"防AI走写实路线；"风的可见化"是吉卜力灵魂。

**签名元素**：一点透视对称走廊、慢推推近、冷峻机器感、广角畸变人脸、完美几何构图、凝视镜头

**注意**：慢推+一点透视缺一不可；人物直视镜头的凝视是点睛之笔（AI可生成，用作镜头结尾）。

## ⑩ 奉俊昊 Bong Joon-ho

**签名元素**：阶级空间隐喻（高低位/楼梯/半地下室）、类型混搭、构图里藏信息（画框内外分层）、精准的黑色幽默时机

**可复制Prompt片段**：
```
构图强调空间高差——上层人物位于画面高处的明亮区域，下层人物在低处阴影中仰望，楼梯作为阶级通道贯穿画面纵深，前后景分层藏细节信息（背景中发生的次要事件与前景主事件并置），自然光写实，画面在平静中暗涌不安，黑色幽默的精准节拍
```
**适用**：现实题材、讽刺、悬疑、阶级叙事

**注意**：核心是"空间关系即人物关系"——把高低、明暗、进深写成权力结构。

### ㉓ CG史诗/概念艺术 Cinematic CG / Concept Art Render
**签名元素**：极端巨物尺度对比、超写实材质与不可能尺度并存、超大单一光源、强体积光与可见光轴、高密度粒子、色彩随情绪整幅突变、无视物理限制的摄影机运动、生长/崩解/化生等变形奇观

**可复制Prompt片段**：
```
电影级CG概念艺术渲染，非游戏过场动画质感。极端尺度对比：巨大物体占据画面绝大部分，人物作为渺小剪影位于画面下三分之一处，以尺度落差制造压迫。超大单一光源（巨型恒星/能量核心/烈焰）主导画面，强体积光与可见光轴穿透大气，空气中悬浮高密度粒子与尘埃，逆光为所有物体边缘勾出明亮轮廓线。材质超写实——岩石纹理、皮肤毛孔、金属氧化、水流折射、火焰层次全部可辨，但尺度被刻意夸张。色彩为高纯度大色块（赤金/正红/桃粉/钴蓝），随情绪节点整幅突变而非渐变。摄影机执行实拍无法完成的运动：从微观特写连续拉升至宏观远景、穿越云层与火焰、环绕巨物飞行。空气透视明显，远处景物流失细节并偏冷，形成强烈空间纵深。动态元素丰富：粒子、烟雾、流体、布料、植被生长始终保持连续受控运动，无塑料感、无均匀布光、无磨皮皮肤、无空洞背景。
```
**适用**：神话/史诗、科幻巨物、自然奇观、时间与尺度叙事、变形与化生场景、任何"实拍拍不出来"的画面

**注意**：这套风格的灵魂是**尺度对比**与**材质真实**——必须同时写"巨物"和"渺小个体"，必须同时写"超写实材质"和"夸张尺度"。最忌讳塑料皮肤、均匀布光、平庸构图（游戏过场CG感的三个来源）。色彩要"整幅突变"而非柔和渐变，这是CG区别于实拍的叙事特权。

**CG风 Negative Prompt 总库**：
game cutscene / video game asset look / plastic skin / uniform flat lighting / low detail background / flat shading / uncanny valley face / oversaturated neon / blurry mush / generic sci-fi interface / CGI cartoon look / overly smooth surface / repetitive particle pattern

## 风格组合与注意事项

1. **一次只用一个签名**：混两个导演（如"王家卫+韦斯·安德森"）会互相打架。若要混，只取各一个元素（如韦斯的对称+王家的暖霓虹）。
2. **签名卡与七层结构叠加**：签名片段放在 Prompt 的风格定调位（开头或结尾），七层调度语言照常写，二者不冲突——签名管"怎么拍出这个味"，七层管"拍什么、怎么动"。
3. **与08/09号词库联动**：签名卡里的光色描述可回查08灯光、09色彩词库做微调（如把王家卫的"高饱和暖调"换成"低纯度色板"做变体）。
4. **AI响应优先级**：构图类词（对称/一点透视/剪影）响应最稳，节奏类词（抽帧/骤停/慢镜）次之，情绪类词（暧昧/宿命）只做氛围辅助不依赖它。
5. **未收录的导演**：让用户描述三个特征（构图习惯/光线习惯/色彩习惯），到08、09、03号词库组装临时签名卡，并把验证有效的结果回填本文件。
