# 11 全片一致性与工程系统词库

AI精品电影最难的不是单镜头，而是**跨镜头、跨场景、跨时段的一致性**。本词库把现实影视的摄影指导/DIT/场记/调色职责工程化为可锁定、可复用、可检查的资产与规则。包含：视觉圣经、三级锁定、角色/场景/道具/时间线卡、六大锁定器、母Prompt+变量结构、镜头组Sequence、画幅语言、帧率语言、质检表、故障处方。

**核心原则：唯一真相源（Single Source of Truth）。** 角色脸型来自角色母图，服装材质来自服装卡，全片色调来自Look板，画幅来自项目设定——后续镜头不得凭感觉重新定义这些变量。

## 视觉圣经 Visual Bible（项目开工第一件事）

| 模块 | 必须锁定 | 检查标准 |
|---|---|---|
| 项目基调 | 题材、时代、世界观、情绪、现实度 | 一句话能描述影片视觉 |
| 色彩 | 主色/辅色/禁用色、肤色方向、黑白关系 | 镜头抽样后色彩重心一致 |
| 光线 | 主光方向、光质、光比、色温规则 | 同一空间光向不打架 |
| 镜头 | 画幅、焦段区间、机位高度、景深倾向 | 同一场戏不无意义跳焦段 |
| 材质 | 皮肤、金属、木石、织物、玻璃 | 反射/粗糙度逻辑一致 |
| 运动 | 人物运动风格、摄影机惯性、快慢规律 | 重心、速度、方向连续 |
| 后期 | 对比度、黑位、饱和度、颗粒、辉光 | 不同镜头像来自同一摄影系统 |

## 视觉锁定三级架构

| 级别 | 内容 | 例子 |
|---|---|---|
| 一级锁定（不可变） | 角色身份/脸型/发型/服装大类/世界观建筑语言/项目画幅/主色 | 谈漾永远是同一张脸 |
| 二级锁定（受规则约束） | 姿势、构图、光比、时间、天气、镜头运动 | 天气可变但需声明 |
| 三级变量（自由） | 情绪、局部道具、背景人群、瞬时光影 | 为叙事服务 |

## 角色一致性系统

| 资产 | 锁定 | 可变 | 常见错误 |
|---|---|---|---|
| 身份DNA | 年龄区间、脸型、五官比例、发型轮廓、体型 | 表情、姿势、轻微发丝变化 | 每镜头重新生成脸 |
| 服装DNA | 版型、材质、主色、饰品位置 | 褶皱、污渍、运动状态 | 衣服细节随机变化 |
| 皮肤DNA | 肤色方向、粗糙度、光泽度、年龄纹理 | 情绪红润、汗、水 | 真人感与3D感冲突 |
| 动作DNA | 走路节奏、姿态、惯用手、重心 | 动作本身 | 左右手/肢体连续性错误 |

**角色卡字段**：角色ID｜固定外貌描述｜固定衣装描述｜发型｜材质｜身高体型｜性格视觉化｜正/侧/背面参考｜全身参考｜表情参考｜禁用变化。

## 场景与道具一致性

**场景卡**：场景不是背景图，是空间规则——坐标关系、主建筑、入口、窗户、道路、水体、地平线、主要道具、光源位置、季节、天气。建立"场景母图+平面关系图+局部资产图"，镜头切换时空间才不漂移。每个空间设2-4个固定视觉锚点（如医院走廊：红灯/日光灯带/安全出口牌）。

**道具护照**（重要道具必建）：名称｜尺寸｜材质｜颜色｜磨损｜持握方式｜首次出现｜最后出现｜剧情所有权｜损坏状态。记录状态连续性：杯中有水→被拿起→水量下降→放回。

**时间线连续性表**：

| 变量 | 必须记录 | 为什么 |
|---|---|---|
| 时间 | 具体日夜、季节、相对时刻 | 太阳高度与色温会变 |
| 天气 | 晴/阴/雨/雪/雾/风力 | 光线、服饰、地面反射改变 |
| 人物状态 | 体力、伤口、湿度、妆容、情绪 | 跨镜头不应突然重置 |
| 空间状态 | 门窗开合、灯亮灭、烟雾方向 | 场景关系可信 |
| 道具状态 | 位置、朝向、破损、数量 | 避免穿帮 |

## 六大锁定器（一致性的总控开关）

| 锁定器 | 作用 | 失控症状 | 解决方法 |
|---|---|---|---|
| Identity Lock | 锁人物/物体身份 | 脸变化、衣服变化 | 母图+角色卡+固定描述 |
| Spatial Lock | 锁空间 | 房间结构变化 | 场景母图+空间关系图 |
| Camera Lock | 锁摄影机逻辑 | 焦段乱跳、视角不稳 | 镜头家族+机位规则 |
| Light Lock | 锁光线 | 同场戏光向不同 | 主光方向+色温+光比 |
| Motion Lock | 锁运动 | 速度/方向不连续 | 运动向量+关键状态 |
| Color Lock | 锁调色 | 镜头像不同影片 | 统一Look+后期匹配 |

## 母Prompt + 变量Prompt结构（核心工程模板）

**不要每个镜头重新定义全片风格。** 用固定母Prompt描述影片DNA，镜头变量Prompt只描述当前镜头：

```
【固定母Prompt】影片视觉DNA + 角色DNA + 场景DNA + 光线DNA + 色彩DNA + 摄影机DNA + 纹理DNA
【镜头变量】景别 + 焦段 + 机位 + 构图 + 主体动作 + 摄影机运动 + 环境运动 + 节奏
【连续性约束】角色外貌不变 + 服装不变 + 场景布局不变 + 光向一致 + 运动方向一致 + 画幅/帧率一致
```

**中文母Prompt成品模板**：
```
电影级叙事画面，统一项目视觉DNA；[角色身份与固定外貌]；位于[场景及空间关系]；[时间/天气]；使用[画幅]；[景别]，[焦段]，[机位高度/角度]；摄影机以[运动方式]移动；主光来自[方向]，光质[硬/软]，色温[暖/冷]，阴影[描述]；色彩以[主色]为主，肤色自然稳定，黑位与高光保持[Look特征]；运动具有真实惯性和连续重心，自然运动模糊；统一镜头光学特性、颗粒与微对比；保持角色、服装、道具、建筑结构和时间状态连续。
```

**参考图优先级**：A角色/场景母图（锁身份空间）> B构图参考（锁机位）> C材质参考（锁表面）> D风格参考（锁倾向）> E运动参考（锁节奏）。参考图不是越多越好——过多互相矛盾会"平均化"，建立主参考/辅助参考/禁止参考三级体系。

## 画幅语言 Aspect Ratio

生成第一张基准图前确定，全片锁定：

| 画幅 | 视觉倾向 | 适合内容 |
|---|---|---|
| 4:3 (1.33:1) | 垂直信息强、复古纪实 | 人物、家庭、旧时代、心理戏 |
| 16:9 (1.78:1) | 主流数字平台 | 剧集、广告、通用AI视频 |
| 1.85:1 | 标准宽银幕自然电影感 | 剧情片、商业片 |
| 2.00:1 | 现代流媒体宽幅 | 史诗、都市戏 |
| 2.39:1 | 强烈电影宽银幕、横向语言 | 史诗、动作、公路、科幻 |
| 9:16 | 竖屏移动端 | 短视频、手机主观视角 |

**选择原则**：环境重要→宽画幅；脸与身体语言重要→窄画幅；压迫感→窄画幅+正面构图+长焦。无叙事理由不要换画幅，改变本身应是剧情语言。**安全区**：字幕/Logo/裁切预留空间，关键脸部和道具不压边缘；宽转竖需预设中心安全构图。

## 帧率语言 Frame Rate

| 帧率 | 运动感 | 用途 |
|---|---|---|
| 24fps | 电影式自然运动模糊 | 剧情片、叙事主段落 |
| 25fps | PAL节奏 | 地区性影视 |
| 30fps | 更平滑数字化 | 网络/广告/直播感 |
| 48-60fps | 流畅高清晰 | 动作、产品、慢动作素材 |
| 120fps+ | 极慢动作采集 | 水、碎片、爆破细节 |

**快门角**：180°=自然运动模糊（24fps≈1/48s）；90°=锐利动作边缘（冲击/紧张）。**拍摄帧率vs播放帧率**：60fps采集在24fps时间轴播放≈2.5倍慢速；120fps≈5倍慢速。慢动作自然的关键=帧率+快门+光照+播放速度同步。

**帧率作为叙事语法**：正常叙事24fps｜情绪慢主观→高帧率采集慢速播放｜失控冲击→短快门锐利边缘｜梦境记忆→慢门拖影/帧率变化建立媒介差异。

**画幅+帧率组合**：2.39+24fps=经典史诗｜1.85+24fps=自然剧情｜2.00+24fps=现代流媒体｜4:3+24fps=复古心理｜16:9+30fps=平台数字感｜9:16+30fps=移动原生。

## 镜头组 Sequence（一致性的真正单位）

AI精品电影的单位不是单镜头，是**镜头组**——共享场景、时间、光线、角色状态与镜头语法，组内产生景别变化：

| Sequence类型 | 镜头组织 | 常用策略 |
|---|---|---|
| 对话戏 | 主镜+反打+插入+反应 | 焦段变化小、视线严格 |
| 追逐戏 | 建立空间+跟拍+切分动作 | 方向连续、速度递进 |
| 情绪戏 | 环境→人物→眼神→细节 | 景深逐渐收窄 |
| 史诗场面 | 大全景→中景→局部→特写 | 先空间后主体 |
| 动作高潮 | 空间建立→动作分段→冲击特写 | 短快切+高时间采样 |
| 梦境 | 现实建立→媒介变化→非线性运动 | 帧率/快门/光学故意改变 |

## 运动连续性检查（四种运动变量）

主体运动（人物怎么动）｜摄影机运动（镜头怎么动）｜空间运动（环境怎么动）｜时间运动（快慢怎么变）。

- 方向连续：左→右不无故变右→左
- 惯性连续：镜头突停应有惯性或明确切断
- 重心连续：转身/起跳保持支撑脚与质量感
- 幅度连续：同一动作相邻镜头速度不突变
- 镜头速度连续：慢推接高速甩镜需叙事理由

## 工程化制作流程（10步）

1. 建立 PROJECT_MASTER：一句话视觉概念、画幅、主帧率、镜头家族、色彩母系统
2. 建立角色资产：母图、三视图、服装、表情、动作基准
3. 建立场景资产：环境母图、空间关系、时间天气、关键道具
4. 制作 Look Board：曝光、色彩、黑位、高光、颗粒、辉光、锐度
5. 建立镜头语言表：景别、焦段、机位、运动、帧率、快门
6. 生成 First Frame：每镜头先解决静态构图与身份，再进视频
7. 生成 Motion Pass：只改运动变量，不重写角色/空间/光线
8. 镜头组匹配：同场戏先内部统一，再跨场统一
9. 后期匹配：曝光、白平衡、肤色、对比度、纹理
10. 质检交付

**资产命名**：PROJECT_MASTER_v01｜CHAR_001_FRONT_V03｜ENV_001_WIDE_V02｜PROP_001_DETAIL_V01｜LOOK_001_NIGHT_V02｜S001_V05。

## 常见工程故障处方

| 症状 | 根因 | 修复顺序 |
|---|---|---|
| 人物每镜不同 | 身份参考不足 | 角色母图→固定描述→参考权重 |
| 空间漂移 | 没有场景母图 | 平面关系→局部资产→机位约束 |
| 色彩忽冷忽暖 | 白平衡/Look未锁 | 统一色彩基准→镜头匹配 |
| 运动像游戏 | 没有真实摄影惯性 | 定义速度/加速度→镜头惯性→运动模糊 |
| AI感明显 | 材质光线细节不统一 | 减少过锐→统一光学→统一纹理 |
| 连续动作跳变 | 没有状态分段 | 拆为准备/执行/结束状态 |
| 慢动作不自然 | 只提帧率没管快门 | 同步运动模糊、光照、播放速度 |
