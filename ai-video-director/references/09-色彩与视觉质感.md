# 09 色彩与视觉质感词库

色彩是情绪的底层操作系统——观众意识不到它，但全程被它支配。本词库包含：快速决策表、色调与饱和度、配色方案、色彩叙事（母题/弧线/对比）、调色风格签名、视觉质感词、情绪→色彩映射、场景色彩模板、Seedance使用要点。

**核心原则：色彩是关系，不是形容词。** 写"画面很美"不如写"画面以青色阴影托底，人物肤色和灯笼橙是唯二暖点，互补色分离让主体自动跳出来"。

## 快速决策表（你想表达什么效果？）

| 你想表达的效果 | 优先色彩方案 |
|---|---|
| 电影感/大片感 | 青橙体系（Teal & Orange） |
| 高级感/性冷淡 | 低饱和 + 大地色 + 负空间 |
| 复古年代感 | 胶片色彩 + 低饱和 + 颗粒 |
| 梦幻少女 | 粉彩 + 柔光 + 高调 |
| 科技冷感 | 单色蓝 + 金属色 + 高对比 |
| 危险/欲望 | 霓虹红 + 深黑 + 高饱和局部 |
| 贫困写实 | 低纯度色板 + 大地色 + 灰调 |
| 奇幻华丽 | 金属色系 + 高饱和 + 深底色 |
| 忧郁文艺 | 冷调 + 低饱和 + 蓝调时刻色 |
| 愤怒/暴力 | 高饱和红 + 去饱和环境对比 |

## 色调与饱和度（基础层）

| 词条 | 英文 | 触发效果 | Prompt写法 |
|---|---|---|---|
| 暖调 | Warm Tone | 亲近、记忆、情感浓度 | 整体暖调，琥珀与橙主导 |
| 冷调 | Cool Tone | 疏离、理性、悲伤 | 整体冷调，青蓝主导 |
| 中性色 | Neutral Tone | 客观、纪实、克制 | 中性色调，几乎无色彩倾向 |
| 高饱和 | Saturated | 情绪浓烈、奇观、卡通化 | 高饱和色彩，色块浓烈如油画 |
| 低饱和 | Desaturated | 压抑、写实、战争/疾病记忆 | 低饱和，色彩像被抽走了一层 |
| 单色 | Monochromatic | 形式感强、主题压迫 | 单色蓝调笼罩全画面，只有明度变化 |

## 配色方案（关系层）

| 词条 | 英文 | 视觉逻辑 | 使用示例 |
|---|---|---|---|
| 互补色 | Complementary | 色环对撞，冲突与张力最强 | 青橙对撞：冷青阴影 vs 暖橙肤色 |
| 邻近色 | Adjacent/Analogous | 色环相邻，和谐统一 | 蓝紫青邻近色构成雨夜统一色调 |
| 分裂互补 | Split Complementary | 互补的柔和版，丰富不失稳 | 蓝底 + 橙黄双暖点 |
| 三角色 | Triadic | 三等分色环，活泼均衡 | 红/黄/蓝三色分置画面 |
| 双色 | Duotone | 只留两色，强形式感 | 青与品红双色调赛博夜景 |
| 色彩对比 | Color Contrast | 用色差引导视线 | 红伞在灰色人流中成为唯一焦点 |
| 色彩分离 | Color Separation | 主体与环境色拉开 | 主体保留暖肤色，背景统一冷青 |

## 色彩叙事（电影层——这是精品与普通的核心差距）

| 词条 | 英文 | 用法 | 示例 |
|---|---|---|---|
| 色彩母题 | Color Motif | 一种颜色反复出现，绑定主题/人物 | 她出现时画面总有红——观众形成条件反射 |
| 色彩弧线 | Color Arc | 角色随剧情变化的色彩轨迹 | 开场白衣冷调 → 中段渐暖 → 结局金色逆光 |
| 色彩和谐 | Color Harmony | 场景内部色彩秩序 | 灵堂全场白灰，只有遗像一点红 |
| 全片色彩弧线 | — | 整部作品的色彩节奏 | 第一幕冷蓝压抑 → 第二幕冷暖交替 → 第三幕暖金释放 |

**跨镜头色彩连续性**（模式D分镜必查）：同场戏内色温基调、人物服装色、环境主色必须跨镜锁定。写法——`全场景锁定：走廊冷白荧光基调，谈漾深色外套，不随镜头变化`。

## 调色工程操作词（精确控制画面层次）

| 操作 | 视觉效果 | 适用 | 风险 |
|---|---|---|---|
| S曲线 | 增加中间调对比 | 商业、动作 | 肤色过硬、黑位断层 |
| 抬黑位 Lifted Blacks | 黑位抬起，复古雾化 | 复古、日系 | 灰雾感、失去深度 |
| 压黑位 Crushed Blacks | 阴影压死 | 低调、动作 | 暗部细节消失 |
| 高光柔和滚降 Soft Roll-off | 高光进白前柔和过渡 | 电影、人像 | 过度会发灰 |
| 阴影降饱和 | 阴影色彩褪去 | 电影自然主义 | 阴影变脏 |
| 保护肤色 | 肤色区域独立稳定 | 人像、对白 | 过度导致贴纸感 |

## 胶片与数字质感层（最后一步，全部"轻"）

| 元素 | 视觉表现 | 推荐强度 | Prompt写法 |
|---|---|---|---|
| 胶片颗粒 | 暗部和中调有机颗粒 | 轻到中 | fine organic film grain |
| Halation晕光 | 高光边缘暖红晕 | 极轻 | subtle warm halation |
| Bloom泛光 | 高亮区域柔化扩散 | 轻 | controlled highlight bloom |
| Gate Weave胶片漂移 | 画面微小位置抖动 | 极轻 | subtle gate weave |
| 曝光闪烁 | 亮度轻微波动 | 极轻 | subtle exposure flicker |
| 镜头光晕 | 光斑、条纹、鬼影 | 受控 | controlled cinematic lens flare |
| 色散 | 边缘轻微彩边 | 极轻 | subtle chromatic aberration |
| 晕影 | 边缘暗化聚焦主体 | 轻 | natural optical falloff |

**胶片感失败的头号原因**：颗粒、划痕、漏光、抖动、光晕全部叠加。高级质感=低强度、分布合理、服务于画面结构——"察觉到但说不出"的程度。

## "电影感"专业替换词表（禁用空洞形容词）

| 不要只写 | 专业替换 | 为什么 |
|---|---|---|
| 电影感 | 动机光+受控反差+电影级色彩分离 | 电影感由多个变量组成 |
| 高级感 | 克制色板+高光柔和滚降+受控黑位 | 把"高级"落到影像结构 |
| 真实感 | 自然动机光源+一致的阴影方向+真实曝光 | 解决光源不可信 |
| 胶片感 | 轻颗粒+halation+柔和滚降+有机质感 | 避免只加颗粒 |
| 氛围感 | 空气透视+薄雾+分层布光 | 把氛围变成空间参数 |
| 大片感 | 大画幅透视+深度分层构图+受控动态范围 | 避免空泛 |

## 质感故障排查表（为什么看起来像AI）

| 问题 | 常见原因 | 修复策略 |
|---|---|---|
| 塑料皮肤 | 过锐、皮肤纹理算法化 | 降锐化；加自然微对比；让光线塑形而非纹理堆积 |
| 光源不可信 | 脸亮但环境找不到来源 | 补充动机光源；统一影子方向与色温 |
| 全片都很亮 | AI倾向把主体展示清楚 | 重建黑位、局部高光和层级，不要求所有区域可见 |
| 过度HDR | 高光过亮+阴影提亮 | 压缩高光、降低局部对比，恢复自然滚降 |
| 颜色艳但廉价 | 所有颜色饱和度相似 | 只保留1-2个高饱和重点，其余降饱和 |
| 电影感只有颗粒 | 没有光、色、镜头结构 | 先重做灯光构图，最后再加颗粒 |
| 肤色漂移 | 混合光/模型随机性 | 指定肤色稳定、保护肤色色相 |
| 景深假 | 模糊不符合空间距离 | 明确焦平面、焦段、机位距离 |
| 霓虹过量 | 每个光源都成主色 | 定义主色、辅色、背景色层级 |

## 场景色彩模板（成品片段）

### 都市雨夜
```
蓝调时刻冷调打底，霓虹品红与青色在湿路面反射，青橙色彩分离，人物暖肤色是唯一暖点，电影感，低照度高质感
```

### 医院走廊（对应24-1场景）
```
冷白荧光低饱和，临床青灰色调，去饱和肤色，环境近乎无色，只有走廊尽头安全出口一点绿光，压抑疏离
```

### 古代宫殿
```
暖金主调，红柱与金瓦高饱和撞色，体积光中尘埃粒子呈琥珀色，深色阴影托底，史诗质感，东方色彩体系
```

### 战场写实
```
跳漂调色，低饱和高对比，土黄与铁灰大地色，硝烟漫过画面时色彩进一步剥离，战地纪实质感
```

### 童年回忆
```
胶片色彩，暖调偏黄，柔和高光溢出，轻微褪色与暗角，16mm家庭录像颗粒感
```

## Seedance 使用要点

1. **色彩词要落到具体物**：`画面中只有灯笼是暖橙色，其余压入青蓝` 比 `冷暖对比` 更可控。
2. **一个画面一个主色调 + 最多一个强调色**：主色定氛围，强调色定视线，再多就糊。
3. **色彩变化可以承担转场**：`画面从暖金逐渐褪成冷蓝，暗示真相浮现`——色彩即情绪剪辑点。
4. **质感词放Prompt首尾**：开头定风格基调（如`胶片色彩质感`），结尾可以重复强调防丢失。
5. **跨镜锁定服装色和环境主色**：分镜表中单列"色彩连续性"一栏，逐镜检查。
6. **警惕AI色彩漂移**：连续镜头易出现饱和度漂移，每镜Prompt都显式写明饱和度档位（高/低/极低）。
