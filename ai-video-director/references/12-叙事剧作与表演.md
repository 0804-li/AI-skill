# 12 叙事剧作与表演词库

解决"画面很美但没有故事""情绪一条线""对白很深但人物空"——AI视频最常见的假深度问题。本词库包含：叙事七层结构、因果链公式、结构法、场景设计公式、信息控制、人物弧线、关系动力学、对白潜台词、表演八层、情绪强度分级、母题系统、叙事变量、Master Prompt、假深度修复。

**核心原则：表演不是做表情，情绪是内部结果，行为是可被摄影机观察到的证据。**

## 叙事七层结构（深度自检）

表层事件（发生了什么）→ 因果层（为什么发生）→ 欲望层（谁想要什么）→ 关系层（权力/依赖/误解在变化）→ 主题层（讨论什么价值冲突）→ 潜台词层（说的不是全部）→ 余韵层（结尾后观众继续思考）。

## 因果链公式（每个镜头的叙事骨架）

`状态 → 刺激 → 选择 → 行动 → 结果 → 新状态`

| 模块 | 定义 | 常见错误 | AI写法示例 |
|---|---|---|---|
| 状态 | 人物/世界当前平衡 | 只写地点不写关系状态 | 两人互不信任，桌上留着未拆的信 |
| 刺激 | 迫使反应的新信息 | 凭空转折 | 门外传来三次固定敲门声 |
| 选择 | 面对代价后的决定 | 只发生事件人物没选择 | 她没有开门，先把戒指藏进袖口 |
| 行动 | 选择外化为行为 | 动作只是装饰 | 她熄灭烛火并后退三步 |
| 结果 | 行动造成的新变化 | 结局被下一镜取消 | 门被撞开，她失去藏匿时间 |
| 新状态 | 进入下一段因果链 | 每场戏回到原点 | 她必须从逃跑改为对峙 |

**AI生成最容易出现"漂亮但没有因果"的镜头——每个镜头都应能回答：当前什么状态？什么打破状态？人物做了什么？产生什么不可逆后果？**

## 剧作结构法速查

| 结构 | 适合 | 核心节点 | AI应用 |
|---|---|---|---|
| 三幕 | 商业叙事、短片 | 建置—对抗—解决 | 快速规划全片 |
| 五幕 | 人物成长、悲剧 | 开端—上升—转折—崩溃—结局 | 强化中段复杂度 |
| 八序列 | 90-140分钟 | 每序列有目标与小高潮 | 分段生成与剪辑 |
| 英雄旅程 | 成长冒险神话 | 召唤—试炼—危机—归来 | 东方神话/修仙题材 |
| 碎片/倒叙 | 悬疑心理 | 信息重排而非事件重排 | 建立时间轴和观众知情矩阵 |
| 环形回环 | 寓言宿命 | 结尾重新定义开头 | 重复意象产生意义变化 |

## 场景设计公式

一场戏≠有对白的地点。高质量场景必备：**场景目标+关系目标+阻力+信息变化+选择+视听记忆点+退出状态**。

| 变量 | 问题 | 技法 |
|---|---|---|
| 场景目的 | 删掉这场戏故事损失什么？ | 信息损失测试/因果损失测试 |
| 角色目标 | 谁主动想得到什么？ | 主动角色原则 |
| 阻力 | 谁/什么阻止他？ | 人、制度、时间、空间、身体、信息 |
| 反目标 | 另一方想阻止什么？ | 目标对撞而非单向表达 |
| 升级 | 冲突是否越来越贵？ | 代价递增、时间压缩、空间收窄 |
| 转折 | 观众判断在哪里被修改？ | Reveal / Reversal / Reframe |
| 出口 | 人物离场时什么新状态？ | 状态必须改变 |

## 信息控制（观众知道多少）

| 模式 | 观众信息量 | 效果 | 适用 |
|---|---|---|---|
| 神秘型 | 比人物少 | 悬念、猜测 | 悬疑、恐怖 |
| 戏剧型 | 与人物同步 | 共情、期待 | 人物片 |
| 讽刺型 | 比人物多 | 焦虑、黑色幽默 | 喜剧、犯罪 |
| 延迟揭示 | 先现象后原因 | 重新解释前面 | 记忆、家庭、历史 |
| 错位揭示 | 先事实后动机 | 道德判断摇摆 | 反英雄、复杂关系 |

## 人物弧线系统

### 角色六维卡

| 维度 | 写到什么程度 | 示例 |
|---|---|---|
| 表面目标 | 公开追求 | 找到失踪弟弟 |
| 真实需求 | 真正要学的 | 接受弟弟拥有独立人生 |
| 核心恐惧 | 最怕失去什么 | 被再次抛下 |
| 错误信念 | 导致错误选择的认知 | "控制别人才能留住别人" |
| 底线 | 什么条件下突破自己 | 弟弟面临真实危险 |
| 转变方式 | 通过哪些不可逆事件改变 | 失去控制后主动放手 |

### 弧线四类与视觉化

| 类型 | 变化 | AI视觉化方法 |
|---|---|---|
| 正向弧线 | 错误信念被修正 | 动作越来越主动、空间越来越开放 |
| 负向弧线 | 恐惧/错误信念强化 | 镜头越来越封闭、重复动作越来越严重 |
| 平坦弧线 | 人物不变，世界被改变 | 角色成为价值锚点 |
| 循环/悲剧 | 看似改变回到原点 | 重复同一意象但语义反转 |

### 关系动力学（写成向量不写标签）

不写"朋友/敌人/夫妻"，写动态变量：**信任、控制、依赖、羞耻、亏欠、竞争、吸引、恐惧**。每场戏至少改变一个变量。

| 关系变量 | 正向 | 负向 | AI视觉提示 |
|---|---|---|---|
| 信任 | 主动透露秘密 | 隐藏信息 | 距离缩短、遮挡减少 |
| 控制 | 命令并执行 | 失去控制 | 站位高低、通道封锁 |
| 依赖 | 等待对方许可 | 被迫服从 | 跟随、停顿、回望 |
| 羞耻 | 回避目光 | 自我暴露 | 脸被物体遮挡、动作缩小 |
| 吸引 | 主动接近 | 欲言又止 | 共同构图、视线交汇 |
| 敌意 | 试探 | 攻击 | 前景切割、空间对撞 |

## 对白与潜台词

**对白三层**：表层（说了什么）→ 意图层（要达成什么）→ 潜台词层（不愿直说什么）。判断标准：删掉这句对白，动作/停顿是否仍能表达？

**信息七通道**：把信息拆给对白、动作、视线、道具、声音、空间、剪辑——七通道越互补越有电影感，对白不要承担所有信息。

**无对白叙事工具库**：看门把手不看人（回避关系）｜反复整理同一件物品（焦虑外化）｜准备开口改成喝水（压抑表达）｜走进光里又退回阴影（心理立场变化）｜声音先出现画面后出现（观众先获威胁信息）｜物件放错位置（伏笔）。

## 表演八层（写人物动作时逐层自查）

| 层级 | 核心问题 | 可视化元素 |
|---|---|---|
| 目标 | 我现在要从对方那得到什么？ | 靠近、阻止、试探、说服 |
| 策略 | 我打算怎么得到？ | 讨好、威胁、回避、诱导 |
| 身体 | 身体是否支持语言？ | 重心、肩颈、手部、脚步 |
| 目光 | 我真正想看哪里？ | 看人、看物、躲开、偷看 |
| 语气 | 语言如何改变意思？ | 快慢、音量、尾音、气息 |
| 节奏 | 什么时候停？ | 停顿、抢话、延迟回答 |
| 潜台词 | 没说出来的是什么？ | 动作替代语言 |
| 关系反应 | 对方一动我如何改变？ | 微反应、呼吸变化、姿态变化 |

## 情绪强度分级（1-5）

**情绪强度≠表情强度。** 高手用低强度演高情绪：

| 强度 | 表演方式 | AI描述 |
|---|---|---|
| 1/5 | 极微变化 | 呼吸轻微变化、视线停留0.5秒 |
| 2/5 | 身体小动作 | 手指收紧、吞咽、短暂回避 |
| 3/5 | 动作与语气改变 | 语速变化、重心前移 |
| 4/5 | 明显失控 | 声音裂开、步态紊乱、呼吸急促 |
| 5/5 | 爆发/崩溃 | 喊叫、哭泣、倒地、剧烈动作 |

**表演节奏曲线**：不要一个镜头同一情绪到底。真实电影表演="进入—压制—泄漏—重新控制—决裂"。AI提示应**指定变化节点**而非只写"悲伤"：`开头克制（2/5）→中段手指收紧泄漏（2/5转3/5）→结尾下颌绷紧重新控制（3/5回落）`。

## 视觉母题系统

叙事深度来自重复出现并改变意义的视觉/声音/动作。母题必须有"**首次定义—中段变形—结尾重解释**"：

| 母题 | 第一次 | 中段变化 | 结尾意义 |
|---|---|---|---|
| 门 | 阻隔 | 人物开始主动开门 | 选择与自由 |
| 水 | 平静 | 被污染/暴雨 | 创伤被释放 |
| 镜子 | 自我确认 | 镜中出现差异 | 身份重构 |
| 火 | 温暖 | 失控燃烧 | 爱与毁灭双义 |
| 钟 | 秩序 | 停止/错时 | 时间与死亡 |

## AI镜头叙事变量（直接进Prompt）

| 变量 | 作用 | 示例 |
|---|---|---|
| 信息可见性 | 控制观众知道多少 | 只露出半张照片 |
| 动作起点 | 避免无因果动作 | 手先停在门把上再转动 |
| 动作终点 | 保证剪辑可接 | 停在人物回头瞬间 |
| 反应顺序 | 建立真实表演 | 声音出现→眼神变化→身体转向 |
| 声音时间 | 制造预期 | 敲门声提前0.8秒 |
| 视觉母题 | 跨镜头重复 | 红色雨伞连续出现 |
| 状态继承 | 防止AI刷新人物 | 湿发、破袖、污渍持续 |

## 叙事深度 Prompt 词典（直接调用）

| 中文专业词 | Prompt语义 |
|---|---|
| 潜台词表演 | 说出口的话与真实意图存在差距 |
| 压抑反应 | 情绪被主动控制，不立即爆发 |
| 微反应 | 细小眼神、呼吸、手部、重心变化 |
| 行为动机明确 | 每个动作都有剧情原因 |
| 关系张力 | 人物靠近但情绪上相互防御 |
| 信息不对称 | 观众与角色掌握不同信息 |
| 延迟揭示 | 关键信息故意晚于现象出现 |
| 空间压迫 | 建筑与机位让人物感到无出口 |
| 叙事留白 | 故意不给出唯一解释 |
| 情绪递进 | 状态逐级升级而非瞬间切换 |
| 反高潮 | 结果低于预期但主题更强 |
| 环境叙事 | 不靠对白由空间透露过去 |
| 状态连续 | 服装、伤口、湿度、道具损坏跨镜头继承 |

## 叙事 Master Prompt 模板（可复制）

```
【项目主题】明确主题句与核心价值冲突。
【故事状态】当前世界处于什么状态，什么事件打破平衡。
【人物目标】主角此刻具体想得到什么；阻力是什么；失败会失去什么。
【潜台词】人物嘴上说什么，心里真正想说什么。
【行为】用具体动作表达关系与情绪，不依赖夸张表情。
【关系变化】本镜头前后，信任/控制/依赖/敌意/亲密至少改变一项。
【空间叙事】场景中的建筑、光线、道具、站位体现阶层、历史或心理。
【服化道连续】继承上一镜头的服装、发型、妆容、伤口、污渍、道具状态。
【声音】对白、呼吸、环境、动作音、设计声音、音乐分别描述；指定声源距离与进入时间。
【摄影】画幅、景别、焦段、机位、运动、景深、镜头节奏。
【剪辑连接】明确与上下镜头的动作/视线/声音连接点。
【情绪曲线】开始强度→中段变化→结尾状态。
【结尾】镜头必须停在可用于下一镜头的清晰状态。
【禁止项】禁止人物身份漂移、服饰漂移、空间重构、无因果动作、无目的表演、随机镜头运动、随机新增道具、随机改变时间天气。
```

## 假深度修复表

| 问题 | 表现 | 根因 | 修复 |
|---|---|---|---|
| 对白很深但人物空 | 大量哲理台词 | 没有目标与关系冲突 | 先写人物行为目标，再写对白 |
| 画面很美但无故事 | 镜头彼此无因果 | 只设计构图 | 每镜头增加状态变化 |
| 情绪一条线 | 一直哭/一直愤怒 | 把情绪当表演 | 使用情绪曲线与反应链 |
| 道具丰富但无意义 | 大量装饰物 | 美术服务"好看" | 给关键道具剧情功能 |
| 声音很满 | 全程配乐音效 | 害怕空白 | 设置静音、空气、远场层 |
| 每镜头都高潮 | 没有强弱 | 把电影感误认为密度 | 建立强度曲线 |
