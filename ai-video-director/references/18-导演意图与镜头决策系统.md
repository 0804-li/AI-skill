# 18-导演意图与镜头决策系统

> AI Video Director / Director Intent & Shot Decision System
>
> 定位：把“剧情/场景/情绪/信息”转化为“为什么这样拍”，再由导演意图驱动景别、机位、焦段、构图、摄影机运动、人物调度、前后景、灯光、声音、剪辑与AI执行方式。
>
> 本文件不重复 02 摄影机运动、03 景别机位焦段构图、06 情绪与场景、08 灯光、09 色彩、12 叙事、15 Blocking、16 动作、17 表演中的具体词库；它负责建立它们之间的“决策关系”。

---

## 一、系统定位

传统镜头语言库主要解决：

> **“有哪些拍法？”**

导演决策系统解决：

> **“为什么此刻选择这个拍法？”**

AI导演不能从“漂亮词汇”直接跳到Prompt，而应经过以下决策链：

```text
用户需求 / 剧情 / 场景
        ↓
场景目标 Scene Objective
        ↓
导演意图 Director Intent
        ↓
叙事功能 Narrative Function
        ↓
观众信息控制 Information Control
        ↓
人物关系 Relationship / Power
        ↓
情绪与潜台词 Emotion / Subtext
        ↓
视觉心理 Visual Psychology
        ↓
镜头策略 Shot Strategy
        ↓
场面调度 Blocking
        ↓
摄影机 Camera
        ↓
前中后景 / 环境运动
        ↓
光线 / 色彩 / 声音
        ↓
剪辑与切点
        ↓
AI执行约束
        ↓
最终Prompt
```

核心原则：

> **镜头不是装饰，而是叙事行为。**

任何镜头至少需要回答四个问题：

1. 观众现在应该看到什么？
2. 观众现在不应该看到什么？
3. 观众应该产生什么感受或判断？
4. 这个镜头结束时，观众相比镜头开始时多知道了什么？

---

# 二、导演决策的12个核心变量

| 编号 | 决策变量 | 核心问题 | 最终影响 |
|---|---|---|---|
| 01 | Scene Objective 场景目标 | 这一场戏要完成什么？ | 镜头组织方式 |
| 02 | Director Intent 导演意图 | 导演希望观众怎样感受/理解？ | 全部视听语言 |
| 03 | Narrative Function 叙事功能 | 该镜头是在展示、隐藏、揭示还是转折？ | 镜头目的 |
| 04 | Information Control 信息控制 | 观众此刻知道多少？角色知道多少？ | 构图、遮挡、剪辑 |
| 05 | Subject Priority 主体优先级 | 谁/什么是视觉主角？ | 景别、对焦、构图 |
| 06 | Relationship 人物关系 | 两个人距离、权力、亲密度是什么？ | Blocking、机位 |
| 07 | Emotional State 情绪状态 | 外显情绪和内在情绪分别是什么？ | 表演与镜头距离 |
| 08 | Visual Psychology 视觉心理 | 观众眼睛先看哪里？ | 视觉层级 |
| 09 | Temporal Behavior 时间行为 | 情绪/信息应该多久发生？ | 镜头时长、速度、切点 |
| 10 | Spatial Logic 空间逻辑 | 观众是否清楚人物在哪、朝哪走？ | 镜头轴线、Blocking |
| 11 | Visual Motif 视觉母题 | 是否有重复视觉符号？ | 构图/色彩/道具 |
| 12 | Execution Constraint 执行约束 | AI最容易在哪一步失败？ | Prompt简化与锁定 |

# 三、第一步：先定义 Scene Objective（场景目标）

不要一开始写“中景、35mm、慢推”。

先判断场景属于哪类目标。

## 3.1 场景目标六大类

### A 建立 Establish

目的：让观众知道人物、空间、时间、环境状态。

常见视觉策略：
- 大景别
- 空间关系优先
- 主体可暂时较小
- 摄影机运动克制
- 声音先建立空间

### B 信息 Information

目的：提供关键剧情信息。

策略：
- 主体优先
- 减少无关运动
- 利用Insert、细节镜头、视觉引导
- 必要时先给环境，再给关键细节

### C 关系 Relationship

目的：建立或改变两人/多人关系。

策略：
- 双人镜头
- OTS
- 距离变化
- 高低关系
- 谁占画面更多
- 谁被遮挡

### D 情绪 Emotion

目的：让观众感受到人物状态。

策略：
- 缩短或拉远观看距离
- 留白
- 反应镜头
- 微表演
- 减少非必要动作

### E 转折 Turn

目的：让观众意识到某件事情发生变化。

策略：
- 镜头方向变化
- 构图重新平衡
- 焦点转移
- Camera Move开始
- 信息揭示
- 音响先于画面改变

### F 冲突 Conflict

目的：建立危险、压迫、竞争、对抗或权力变化。

策略：
- 空间压缩
- 视线对抗
- 画面重量不平衡
- Camera / Blocking互相施压
- 动作与反应形成节拍

# 四、第二步：导演意图 Director Intent

场景目标不是导演意图。

例如：

> 场景目标：人物等待。

不等于：

> 导演意图：我要让观众觉得这个人站得很孤独。

应进一步选择一个“观众体验”。

## 4.1 导演意图20类

| 意图 | 观众体验 | 常见镜头方向 |
|---|---|---|
| 亲近 | “我正在靠近这个人” | Close / Slow Push |
| 疏离 | “他离我很远” | Wide / Long Lens / Negative Space |
| 压迫 | “空间在逼迫他” | Low / Tight / Compression |
| 孤独 | “只有他一个人” | Wide / Empty Space |
| 神秘 | “我还不知道真相” | Partial Reveal / Obstruction |
| 悬念 | “马上要发生事了” | Slow Approach / Hidden Information |
| 惊讶 | “信息突然进入” | Reveal / Abrupt Cut |
| 威胁 | “危险正在靠近” | Push / Low Angle / Occlusion |
| 权威 | “他掌控空间” | Stable / Low / Centered |
| 弱势 | “他被空间吞没” | High / Wide / Off-center |
| 浪漫 | “时间似乎慢下来” | Soft Motion / Intimate Framing |
| 怀旧 | “像记忆一样” | Diffuse / Drift / Gentle Transition |
| 冷漠 | “角色没有情绪出口” | Static / Symmetry / Long Hold |
| 疯狂 | “现实正在失控” | Unstable / Rhythmic Shift |
| 史诗 | “人物处在巨大世界中” | Wide / Scale / Vertical Movement |
| 神圣 | “人物被某种力量包围” | Upward / Light Reveal |
| 幽默 | “观众比角色知道更多” | Wide / Timing / Deadpan Hold |
| 悲剧 | “结局似乎已经注定” | Distance / Delay / Negative Space |
| 亲密压抑 | “两人很近却说不出口” | Tight Two Shot / Stillness |
| 真实纪录 | “我像现场目击者” | Observational / Handheld / Minimal Manipulation |

# 五、第三步：Narrative Function 叙事功能

每个镜头至少选择一个主功能，最多两个。

## 5.1 镜头功能矩阵

| 功能 | 解决什么问题 | 适合的视觉策略 |
|---|---|---|
| Establish | 这里是什么地方？ | EWS / WS |
| Introduce | 这个人是谁？ | MS / MCU / Reveal |
| Orient | 人在哪里？ | Master / Geography |
| Observe | 我在观察 | Static / Slow Track |
| Emphasize | 注意这里 | CU / Insert / Focus |
| Reveal | 真相出现 | Rack Focus / Reframe / Reveal |
| Conceal | 暂时不知道 | Occlusion / Crop / Off-screen |
| Connect | 两者有什么关系？ | Two Shot / Match Cut |
| Isolate | 强化孤立 | Negative Space |
| Compare | 强调差异 | Symmetry / Cross Cut |
| React | 显示反应 | Reaction Shot |
| Transform | 状态发生改变 | Push / Pull / Blocking Shift |
| Escalate | 冲突升级 | Tightening / Speed Increase |
| Release | 压力释放 | Pull Back / Wide |
| Foreshadow | 埋伏笔 | Background Action / Insert |
| Misdirect | 引导错误判断 | Visual Misdirection |
| Confirm | 证实信息 | POV / Insert / Reaction |
| Transition | 引导下一场 | Visual / Audio Bridge |

# 六、第四步：Information Control 信息控制系统

导演不是决定“给观众多少信息”，而是决定：

> **什么时候给、给谁、给到什么程度。**

## 6.1 信息状态

```text
I0 = 观众完全不知道
I1 = 观众知道空间
I2 = 观众知道主体
I3 = 观众知道行动
I4 = 观众知道动机
I5 = 观众知道危险
I6 = 观众知道真相
I7 = 角色与观众信息完全对等
I8 = 观众知道、角色不知道
I9 = 角色知道、观众不知道
```

## 6.2 信息差设计

### 观众知道 > 角色知道

常用于：
- 悬疑
- 惊悚
- 惊吓
- 黑色喜剧
- 戏剧性预知

视觉方法：
- 背景埋伏
- 前景遮挡
- 让镜头停留在危险位置
- 不立即切到角色视角

### 角色知道 > 观众知道

常用于：
- 神秘
- 隐瞒
- 人物秘密
- 内心戏

视觉方法：
- 避免直接展示目标
- 反应镜头
- POV延迟
- 局部细节

### 观众与角色同时发现

常用于：
- Surprise
- Reveal
- Discovery

视觉方法：
- 跟随人物移动
- 视线带动Camera
- Reframe
- 同时发现

# 七、第五步：Subject Priority 主体优先级

所有复杂镜头都必须建立视觉层级。

## 7.1 视觉优先级

```text
P1 主叙事主体
P2 关键动作 / 表情
P3 关键道具
P4 关系主体
P5 环境叙事
P6 氛围装饰
```

原则：

> P1-P2不允许被P5-P6抢走注意力。

AI Prompt中不要让大量环境特效与人物主动作争夺主导权。

## 7.2 主体突出方式

- 尺寸优先
- 对焦优先
- 亮度优先
- 色彩优先
- 运动优先
- 反差优先
- 位置优先
- 留白优先

同一个主体不应同时使用过多“突出机制”，否则容易变成视觉过载。

---

# 八、第六步：人物关系与权力视觉化

导演不只拍人物，还要拍人物之间的关系。

## 8.1 五种关系变量

| 变量 | 低值 | 高值 |
|---|---|---|
| 距离 | 疏离 | 亲近 |
| 高度 | 弱势 | 权威 |
| 画面占比 | 次要 | 主导 |
| 遮挡 | 被压制 | 主动控制 |
| 视线 | 回避 | 控制 |

## 8.2 Power Shift 权力变化

镜头必须记录“关系变化”，而不是只记录人物位置。

典型过程：

```text
A占优势
↓
B进入空间
↓
两者平衡
↓
B获得信息
↓
A失去控制
↓
构图权力交换
```

可以通过：

- Camera Height变化
- Frame Size变化
- Blocking变化
- Eye-line变化
- Foreground遮挡
- Focus Priority变化
- Negative Space变化

完成权力转移。

# 九、第七步：情绪不是“表情”，而是镜头状态

17号解决人物表演层。

本模块负责：

> **人物情绪变化后，摄影机应该如何回应。**

## 9.1 情绪×镜头距离

| 情绪目的 | 推荐距离 | 镜头行为 |
|---|---|---|
| 内省 | 中近景/近景 | 缓慢接近或静止 |
| 孤独 | 全景/远景 | 拉远/保持距离 |
| 紧张 | 中近景/近景 | 缓慢推进 |
| 恐惧 | 中景→近景 | 视线引导、焦点变化 |
| 震惊 | 近景 | 保持观察，不急切切镜 |
| 压抑 | 中近景 | 静止、空间压缩 |
| 兴奋 | 中景 | 跟随、速度增加 |
| 释然 | 中景→宽景 | 拉远/释放空间 |

### 重要规则

> **人物越激烈，不代表Camera就一定越激烈。**

高级导演语言常出现：

> 人物剧烈变化 + 摄影机极度克制

或：

> 人物几乎不动 + 摄影机不断接近

两者都会形成强烈心理效果。

# 十、第八步：Visual Psychology 视觉心理

## 10.1 观众注意力七个主要触发器

1. 人脸
2. 眼神方向
3. 高对比区域
4. 高亮区域
5. 饱和色区域
6. 明确运动区域
7. 强烈轮廓 / 几何形状

## 10.2 注意力链

```text
Trigger 视觉触发
↓
Eye Trace 视线移动
↓
Information Reveal 信息揭示
↓
Emotional Response 情绪反应
↓
Next Trigger 下一注意力目标
```

## 10.3 Eye Trace

人物看向画面右侧：

> 下一镜头可以切到右侧目标。

人物低头：

> 下一镜头可以切手部、道具或地面信息。

多人争论：

> 可以利用视线交叉建立剪辑节奏。

核心：

> **下一镜头应该尽量接住上一镜头留下的视觉问题。**

# 十一、第九步：镜头选择决策矩阵

这是本文件最重要的部分。

## 11.1 根据导演意图选择镜头策略

| 导演意图 | 首选策略 | 次选策略 |
|---|---|---|
| 亲近 | CU/MCU + 慢推 | OTS |
| 疏离 | WS/EWS + 留白 | 长焦观察 |
| 压迫 | Tight + 低机位/压缩 | Slow Push |
| 孤独 | Wide + 主体偏置 | Pull Back |
| 权威 | 低机位 + 稳定构图 | 居中 |
| 弱势 | 高机位 + 大空间 | 拉远 |
| 神秘 | 遮挡 + 局部揭示 | 慢移 |
| 悬念 | 受控推进 + 延迟揭示 | 固定观察 |
| 震惊 | 反应近景 + 停留 | 突然切换 |
| 史诗 | EWS + 低机位 + 纵深 | 升降/航拍 |
| 亲密 | Two Shot/OTS | 极近特写 |
| 冲突 | 对向视线 + 空间压缩 | 运动跟拍 |
| 释放 | Pull Out + Wide | Stabilized Move |
| 混乱 | 手持/动态变化 | 快速剪辑 |

注意：表格只是“默认解”，不是硬规则。真正决策必须结合叙事目的与主体状态。

# 十二、景别选择的真正逻辑

不要使用：

> “因为这是情绪戏，所以用特写。”

应该使用：

> “需要让观众读取人物眼神与呼吸变化，因此缩短观看距离。”

## 景别决策

### EWS / WS

回答：

> “人在什么世界里？”

### MS

回答：

> “人在做什么？”

### MCU / CU

回答：

> “这个人此刻是什么状态？”

### ECU

回答：

> “观众必须读取什么细节？”

### Insert

回答：

> “哪个物件承担剧情信息？”

# 十三、焦段选择的导演逻辑

焦段不是“画面好不好看”，而是：

> **改变观众与人物/空间的心理距离。**

| 焦段倾向 | 主要心理效果 |
|---|---|
| 超广角 | 空间感、夸张、距离冲突、环境存在感 |
| 广角 | 临场、空间关系、运动感 |
| 标准焦段 | 中性、自然、观察 |
| 中长焦 | 压缩空间、孤立、观察感 |
| 长焦 | 疏离、窥视、压缩、隐藏空间层次 |
| 超长焦 | 极端压缩、隔岸观察、强烈距离感 |

导演使用焦段时，应先问：

> 我要观众感觉“身在其中”还是“远远观察”？

# 十四、摄影机运动的决策原则

02号提供“怎么运动”。

18号决定：

> **为什么运动。**

## 14.1 运动触发原因

| 运动 | 导演意图 |
|---|---|
| Push In | 接近信息/情绪/危险 |
| Pull Out | 释放/揭示环境/孤立 |
| Pan | 信息转移/发现新目标 |
| Tilt | 权力/高度/揭示 |
| Tracking | 与人物行动建立关系 |
| Orbit | 改变人物与空间关系 |
| Crane Up | 获得规模/释放/全局信息 |
| Crane Down | 接近人物/进入空间 |
| Whip | 强制视觉跳转/能量 |
| Static | 强调观察、冷静、沉默 |

### 核心原则

> **每个Camera Move都必须改变至少一件事情：信息、关系、情绪、空间或时间。**

如果运动结束后什么都没改变，它很可能只是装饰性运动。

---

# 十五、Camera + Blocking联合决策

摄影机不能单独决定。

必须考虑：

```text
人物走
+ 摄影机跟
+ 空间变化
+ 观众看到的新信息
```

例如：

### 情况A

人物向前走，Camera后退。

意义：

> 保持亲密关系 / 观察人物。

### 情况B

人物向前走，Camera不动。

意义：

> 让人物逐渐脱离镜头/进入空间。

### 情况C

人物不动，Camera向前。

意义：

> 摄影机主动进入人物心理。

### 情况D

人物不动，Camera向后。

意义：

> 人物逐渐被环境吞没。

这是AI导演生成中非常重要的“动作—镜头关系”。

# 十六、镜头时长与心理节奏

不要只按“5秒一镜”机械切片。

## 16.1 镜头时长功能

| 时长倾向 | 适合 |
|---|---|
| 极短 | 冲击、信息闪现、动作连接 |
| 短 | 动作、节奏、对抗 |
| 中 | 叙事、对话、观察 |
| 长 | 情绪、沉默、等待、空间 |
| 极长 | 沉浸、压迫、纪录感、戏剧停留 |

## 16.2 预期-延迟设计

```text
建立预期
↓
延迟揭示
↓
观众等待
↓
信息出现
↓
情绪释放
```

悬念不是“镜头晃”。

悬念核心是：

> **观众知道有东西，但不知道什么时候发生。**

---

# 十七、镜头内部的“状态变化”

一个镜头至少应该有：

```text
Start State
↓
Development
↓
End State
```

## 17.1 Start State

镜头开始时：
- 人物在哪里
- 人物状态
- Camera位置
- 对焦对象
- 环境状态

## 17.2 Development

镜头中间：
- 人物发生什么
- Camera是否回应
- 信息是否增加
- 光线/环境是否变化

## 17.3 End State

镜头结束：
- 人物位置
- 人物动作状态
- 表情状态
- Camera位置
- 对焦对象
- 下一镜头入口

### 强制原则

> **没有End State的Prompt，不算完整导演Prompt。**

# 十八、镜头与镜头之间的“信息接力”

相邻镜头不能只追求“画面漂亮”，应该形成：

> A镜头提出问题 → B镜头回答/扩大问题。

## 18.1 五种接力关系

| 类型 | A镜头 | B镜头 |
|---|---|---|
| 视觉接力 | 看向右 | 右侧目标 |
| 动作接力 | 手开始开门 | 门打开 |
| 情绪接力 | 惊讶 | 反应/真相 |
| 空间接力 | 人进入 | 空间内部 |
| 声音接力 | 声音先出现 | 来源出现 |

# 十九、导演镜头决策树

每次生成单镜头，内部按以下顺序判断：

```text
Q1 这一镜头最主要的叙事任务是什么？
 ├─ 建立空间 → 优先空间型镜头
 ├─ 提供信息 → 优先信息型镜头
 ├─ 建立关系 → 优先关系型镜头
 ├─ 强化情绪 → 优先情绪型镜头
 ├─ 制造悬念 → 优先延迟揭示
 ├─ 冲突升级 → 优先关系压迫/动作节奏
 └─ 转折 → 优先视觉状态改变

Q2 观众应该知道什么？
 ├─ 全部 → 直接展示
 ├─ 部分 → 局部/遮挡
 ├─ 暂时不知道 → 隐藏
 └─ 比角色知道更多 → 保留危险信息

Q3 谁是P1主体？
 ├─ 人物
 ├─ 道具
 ├─ 环境
 └─ 关系

Q4 观众与主体应该多近？
 ├─ 身临其境 → 广角/近距离
 ├─ 正常观察 → 标准
 ├─ 远距离观察 → 中长焦/长焦

Q5 Camera是否需要运动？
 ├─ 信息不变 → 静止优先
 ├─ 信息转移 → Pan/Track
 ├─ 情绪接近 → Push
 ├─ 关系释放 → Pull
 ├─ 空间发现 → Move/Reveal
 └─ 没有明确理由 → 不运动

Q6 人物是否移动？
 ├─ 是 → 明确方向+路径+速度+终点
 └─ 否 → 使用表演/环境/镜头变化推动

Q7 画面层级是什么？
 ├─ 前景
 ├─ 主体
 ├─ 关键道具
 └─ 背景信息

Q8 镜头结束时必须留下什么？
 ├─ 新信息
 ├─ 新情绪
 ├─ 新空间
 ├─ 新关系
 └─ 下一镜入口
```

# 二十、“一镜一变量”与导演信息密度

AI生成不意味着导演可以让镜头同时发生所有事情。

## 20.1 镜头复杂度分级

### Level 1：观察

主体基本静止 + Camera静止/轻微运动

### Level 2：单动作

主体完成一个明确动作

### Level 3：动作+Camera

主体一个动作 + Camera响应

### Level 4：动作+环境

主体 + Camera + 单一环境变化

### Level 5：关系变化

两人/多人关系发生改变

### Level 6：高复杂度

人物 + 多主体 + Camera复杂运动 + 环境变化 + 特效

原则：

> **剧情复杂，不等于单镜头复杂。**

高级导演会把复杂叙事拆成多个简单、可读、可连续的镜头。

# 二十一、镜头复杂度预算

```text
一个镜头最多：
1个主叙事动作
+1个Camera主运动
+1个环境主变化
+1个信息变化
+1个情绪变化
```

超过预算时，优先拆镜头。

# 二十三、从剧本到镜头的标准决策模板

用户输入：

> “一个老人坐在屋顶，看着远处城市灯光。”

不要直接写Prompt。

### Step 1：场景目标

情绪观察 / 人物孤独。

### Step 2：导演意图

让观众感觉“城市很大，而老人很小”。

### Step 3：信息控制

没有秘密需要隐藏，重点是空间关系与情绪。

### Step 4：主体优先级

P1老人；P2城市灯光；P3屋顶空间。

### Step 5：视觉策略

让人物占画面较小比例，保留大量城市空间。

### Step 6：镜头策略

宽景优先，人物偏置，使用负空间。

### Step 7：Camera

轻微Pull Out，使人物逐渐被城市吞没。

### Step 8：环境

城市灯光闪烁、远处车辆流动、风轻微吹动衣物。

### Step 9：End State

镜头结束时城市占据更大比例，人物依旧保持静止。

### 导演结论

> 这不是“老人+屋顶”的漂亮风景镜头，而是利用“尺度差”表达人物的孤独与渺小，因此选择大空间、人物偏置、负空间和缓慢拉远，而不是近景推进。

# 二十四、复杂场景的导演决策示例

## 示例A：男人发现门后有人

### 不推荐

“男人惊恐地转身，镜头快速环绕，门突然打开，人物后退，灯光闪烁，镜头甩到门后。”

问题：
- 多个主动作
- 多个Camera运动
- 信息一次性全部释放
- AI容易失控

### 推荐镜头链

```text
SHOT 01
男人听见声音
→ 静止观察
→ 信息不完整

SHOT 02
男人缓慢回头
→ Camera轻微跟随
→ 观众只看到门

SHOT 03
门缝出现影子
→ Insert / Tight
→ 提供局部信息

SHOT 04
男人眼神变化
→ CU
→ Reaction Delay

SHOT 05
Camera缓慢移向门
→ Reveal
→ 最后才进入真相
```

导演逻辑：

> **不是增加镜头运动制造恐怖，而是控制信息释放速度制造恐怖。**

# 二十五、导演意图与镜头反例诊断

## 25.1 “为了电影感而推镜”

错误：

> 人物走路，镜头慢慢推进。

问题：

推进没有叙事理由。

修复：

> 人物意识到远处出现目标，眼神先转向目标，Camera在反应后缓慢Push In，把观众注意力从人物带向目标。

## 25.2 “情绪戏镜头一定要特写”

错误：

> 悲伤=ECU。

修复：

先判断观众需要读取：
- 面部微表情 → CU/ECU
- 人物与环境关系 → Wide
- 行为与沉默 → MCU/WS

## 25.3 “紧张就手持”

错误。

真正产生紧张的变量可能是：
- 信息延迟
- 视线
- 距离
- 遮挡
- 声音
- 静止
- 镜头接近

手持只是其中一种表达。

## 25.4 “史诗就是航拍”

错误。

史诗感核心是：

> Scale + Spatial Hierarchy + Subject Importance + Environmental Magnitude

航拍只是其中一种摄影工具。

# 二十六、导演设计的“必要性测试”

每一个镜头设计完后，逐项问：

### 必要性测试1

> 去掉这个Camera Move，信息有没有损失？

如果没有：可以删。

### 必要性测试2

> 把Wide换成CU，会损失什么？

如果没有明确答案，说明景别选择没有导演理由。

### 必要性测试3

> 把静止换成手持，会增加什么信息？

没有答案就不要加手持。

### 必要性测试4

> 这个镜头结束后，观众知道了什么新东西？

如果答案是“没有”，检查是否只是装饰镜头。

### 必要性测试5

> 下一镜为什么必须接在这里？

没有答案，说明镜头之间还没有建立信息接力。

# 三十一、最终导演决策九问

任何镜头生成前，至少回答：

# 三十二、AI导演的终极模型

完整AI导演镜头决策可以抽象为：

```text
故事 Story
↓
导演意图 Director Intent
↓
信息 Information
↓
关系 Relationship
↓
情绪 Emotion
↓
视觉心理 Psychology
↓
空间 Space
↓
摄影 Camera
↓
调度 Blocking
↓
表演 Performance
↓
光色 Light / Color
↓
声音 Sound
↓
剪辑 Edit
↓
AI约束 AI Constraint
↓
Prompt
↓
生成
↓
质检
↓
修复
```

最终公式：

> **导演镜头 ≠ 景别 + 焦段 + 运镜**
>
> **导演镜头 = 意图 × 信息控制 × 人物关系 × 视觉心理 × 空间调度 × 摄影策略 × 时间节奏 × 观众体验**

最终目标：

> **让AI不是“看到导演写了什么就生成什么”，而是按照导演的意图理解“为什么这样拍”。**

# 三十五、最终使用原则

### 原则1

> **先定目的，再定镜头。**

### 原则2

> **先定观众看到什么，再决定怎么拍。**

### 原则3

> **摄影机的每一次运动都应该产生意义。**

### 原则4

> **情绪不要直接写形容词，要转译成空间、距离、运动、时间和信息。**

### 原则5

> **镜头之间不是拼图关系，而是信息接力关系。**

### 原则6

> **复杂剧情应该拆成简单镜头，而不是把所有动作塞进一个Prompt。**

### 原则7

> **一个镜头结束时必须发生至少一个有效变化：信息、关系、情绪、空间、时间五者之一。**

### 原则8

> **AI导演不是Prompt堆词，而是决策链。**
