# 17 · 微表情与人物表演

> 定位：01号管"人物怎么动"，15号管"人物站哪"，16号管"人物怎么打"，12号管"叙事剧作"——**本库管"人物的脸和表演"**：微表情、眼神、讲话、对白、聆听、Performance DNA、情绪状态机。核心解决：AI人物"脸很逼真但眼睛没在想事情"的假人感。
>
> 一句话总纲：**人物不是"做表情"，而是"经历事件"**——事件改变注意力→注意力改变眼神→眼神改变微表情→影响呼吸→影响声音→影响口型→身体次级反应→事件结束留下情绪余韵。

---

## 一、表演系统总论

**影视人物表演 ≠ "做一个开心表情"。** 它是：

```
人物内在状态 → 潜台词 → 注意力 → 情绪变化 → 面部动作 → 头部动作
→ 身体姿态 → 声音 → 呼吸 → 眼神 → 动作节奏 → 摄影机记录
```

**AI人物真实感七要素**：Identity（身份）+ Anatomy（面部结构）+ Motion（动作）+ Timing（时间）+ Intention（意图）+ Reaction（反应）+ Continuity（连续性）。

最易被忽略的是 **Intention**——人物为什么看？为什么停顿？为什么笑？为什么不笑？为什么话说到一半停下来？这些才是"表演"。

---

## 二、FACS科学基础

**FACS**（Facial Action Coding System，面部动作编码系统）：按可观察面部动作把面部活动拆成 **Action Units（AU，动作单元）**。动画师与计算机科学研究者也使用该系统。

**为什么对AI创作特别重要**：AI最易犯的错误是把情绪当成静态表情模板——"悲伤"直接生成"皱眉+嘴角向下"。真实悲伤可能只是：眼睛停留变长→眨眼减少→眉毛轻微靠近→吸气→嘴唇闭紧→最后才有轻微嘴角变化。

**真实情绪 ≠ 固定表情。** 笑不是不可分割的动作，可拆为：嘴角运动+面颊变化+眼周变化+眼睑变化+眉毛变化+鼻翼变化+下颌变化。AU可组合、有不同强度与时间动态（FACS用 trace/slight → extreme 描述强度层级）。

## 四、微表情的正确理解

**微表情 ≠ 超短表情**。创作层面定义：**小幅度、局部、瞬态、具有潜台词意义的面部行为**——幅度小，但信息量高。

**三个核心维度**：幅度（多明显）/ 持续时间（保持多久）/ 变化速度（突然还是渐进）。

**五级幅度**：
- Level 0 不可见 | Level 1 Trace（痕迹级：嘴角几乎不可察觉地动一下）| Level 2 Subtle（轻微：观众"似乎感觉到变化"）| Level 3 Clear（明显：正常剧情最常见）| Level 4 Strong（强烈：高潮）| Level 5 Extreme（极强：崩溃/惊恐）

**微表情重要的是"变化"而不是"表情"**：
- ❌ "生成一个愤怒脸"
- ✅ "人物原本平静，听到一句话后，眉间先轻微收紧，眼神停顿半秒，嘴唇逐渐压紧，下颌开始产生轻微紧张，随后恢复克制。"

**五种时间结构**：
| 类型 | 特征 | 适合 |
|---|---|---|
| 突发型 | 瞬间出现 | 惊讶/恐惧/意外 |
| 渐进型 | 逐渐增强 | 愤怒/怀疑/悲伤 |
| 延迟型 | 事件发生后过一段时间才出现 | 非常电影化 |
| 抑制型 | 情绪出现，人物主动压制（眼睛已湿润但脸仍平静） | 高级克制 |
| 残留型 | 事情结束表情未立刻恢复（惊讶结束后仍保持一秒不确定） | 余韵 |

**Reaction Lag（反应延迟）是高级表演的重要来源**：AI人物常见问题是反应太快——听到"你父亲去世了"立刻悲伤脸。真实表演：听见→短暂停顿→眼神改变→吸气→嘴唇轻轻打开→努力控制→最后才产生情绪。

## 五、情绪连续状态模型

**情绪不是按钮，而是连续状态**：

```
Neutral（平静）→ Stimulus（刺激）→ Processing（信息处理）→ Reaction（反应）→ Regulation（情绪调节）→ Residual（余波）
```

- **Stimulus**：对白/声音/看到的人/道具/记忆/环境/摄影机外事件
- **Processing**（AI最常省略的一层）：先理解→再确认→再怀疑→再决定是否反应。Prompt加入 `brief processing pause / momentary hesitation`
- **Emotion Regulation**：内心愤怒100，外部只有10——这就是抑制表演

**内外情绪必须分开**：Internal Emotion（真正感受）≠ External Expression（允许观众看到的程度）。**内外情绪差（Internal-External Contrast）** 是高级表演机制：内心极度恐惧+外部保持礼貌微笑。

**潜台词**：人物说"没事"可能是"我很生气/我不想让你担心/我不相信你/我决定离开/我在忍"。AI表演必须=台词+潜台词。

**情绪连续性**：用 Emotion State 0-100 描述（0平静→20轻微警觉→40怀疑→60不安→80恐惧→100爆发），走情绪曲线而不是"平静→爆发→平静"。**情绪惯性（Emotional Residual）**：冲突结束后人物仍呼吸急促、眼神仍紧，过几秒才恢复。

**情绪状态机**：Neutral → Stimulated → Alert → Emotion → Peak → Regulation → Residual → Neutral

**情绪与动作可分离/反向**：静态身体+高心理张力（恐怖片）；外表冷静但手指轻微颤抖——身体泄露内心（Subtle Leakage）。

## 六、讲话表演（Speech Acting）

**对白基本错误**："人物自然地说这句话"→嘴动、脸不动、眼神不动、头也不动=**人形播报机**。

**真正的讲话表演七要素**：Speech（声音）+ Face（面部）+ Eyes（眼神）+ Head（头部）+ Breath（呼吸）+ Gesture（手势）+ Timing（时间）。

**Speech Acting七层**：①发音（说清楚）②节奏（快慢变化）③重音（哪个词重要）④停顿（什么时候不说）⑤呼吸（什么时候吸气）⑥情绪（为什么这么说）⑦行为（说话时身体在做什么）。

**口型三层**：
1. Lip Sync（声音嘴动对齐）——只是第一层
2. Viseme连续性（口型自然过渡；一个嘴型不一定只对应一个音，Coarticulation协同发音：一个音的嘴型受前后音影响，不是PPT式切换）
3. Emotional Speech（嘴、眼、眉、头、呼吸与声音意图同步）——第三层才接近电影表演

**讲话自然幅度**："嘴巴一直大张大合"=AI感。真实对白嘴幅小、下颌变化有限、某些词几乎不明显。分级：普通对白小-中 / 情绪对白中 / 喊叫大 / 耳语非常小 / **克制愤怒嘴部很小但眼周呼吸下颌张力增强**。

**不同讲话状态**：
| 状态 | 嘴部 | 眼睛 | 头部/呼吸/其他 |
|---|---|---|---|
| 平静陈述 | 规则 | 稳定 | 少量移动 |
| 激动 | 幅度增加 | — | 头部/手势增加 |
| 愤怒 | 可能反而减少 | 眼神固定 | 下颌紧/嘴唇压紧/声音更有力 |
| 悲伤 | 减慢 | — | 呼吸不规则/停顿增加 |
| 恐惧 | 可能突然打开 | 关注危险 | 声音断裂/呼吸增多 |

**低声/耳语**：气流>口型幅度。"轻微耳语，嘴唇仅小幅运动，呼吸声更加明显，眼神保持近距离聚焦。"

**大声/喊叫**：不只是嘴巴变大——需要呼吸准备+下颌打开+脖颈张力+眉眼变化+头部稳定+身体支撑。优秀喊叫=声音+面部+身体同步。

**下颌**：真实说话不是"开—关—开—关"，而是细微连续运动。

**头部动作**：点头/摇头/侧头/微抬头/低头/停顿/视线移动——但不应每句话都点一次头。频率与性格挂钩：冷静角色极少 / 热情角色更多 / 犹豫角色轻微频繁 / 权威角色少而明确。

## 七、眼神表演（Eye Acting）——AI人物最重要的表演器官

AI人物最大问题之一：脸很逼真，但眼睛没有在"想事情"。

**眼神词汇**：看向对象 / 看开 / 看回 / 回避 / 锁定 / 扫视 / 短暂失焦 / 重新聚焦 / 追随移动目标。

**眼神不只是"看哪里"，还有"什么时候看"**：听到"我知道你做了什么"→先看对方→眼神短暂移开→重新看回来——比"惊讶表情"更有戏剧性。

**Eye Contact语义**：稳定直视=自信/对抗/亲密/权力；视线回避=羞耻/谎言/不确定/疏离（必须结合剧情）。

**Saccade式快速视线变化**（思考感来源）：思考时眼睛不会机械锁住——快速扫向道具→对方眼睛→门→旁边人物→然后返回。

**眨眼**：不是装饰，与讲话节奏/情绪/紧张程度/注意力/关联。四种常见AI错误：频率太高像NPC / 所有镜头频率相同 / 眨眼与讲话无关 / 双眼完全机械同步。**Micro Blink**（眼睑轻微收动）比大幅眨眼更自然。

**Look-At三层分离**：Body Direction / Head Direction / Eye Direction 三者可以不同。

**眼神先行是高级技巧**：听到"他死了"——不直接悲伤脸，而是眼神先停→人物理解→眉间变化→呼吸→表情。**"嘴巴最后反应"**：复杂情绪中眼睛先知道，嘴巴最后才承认（适合真相/爱情/悲伤/恐惧）。

**视线与镜头关系**：直接看镜头=主观/对抗/第四墙；看镜头附近=自然对白；看镜头外=对空间反应。剧情没要求时不要所有人物都直视摄影机。

## 八、眉/嘴/下颌/呼吸/吞咽

- **眉毛**：上提/下压/内收/外侧变化/**左右不对称**（只右眉轻微上扬=怀疑/讽刺/玩味/不完全相信——不要让左右眉始终完全同步）
- **嘴角微动作**：单侧上扬/双侧轻微上扬/轻微下压/瞬间压住。听到荒唐答案不是大笑，只是右嘴角轻微动一下——非常电影化
- **抿嘴（Lip Press）**：克制/犹豫/愤怒/压抑/不想说话
- **下颌紧张**：不说话时通过下颌收紧+咬肌张力+嘴唇压紧表达克制愤怒
- **吞咽**：紧张/恐惧/欲言又止/压力——Subtle Body Cue
- **呼吸**：平静（胸腹小、节奏稳）/ 紧张（更浅更快、停顿不规则）/ 悲伤（吸气不连续、呼气长、情绪性停顿）
- **憋泪**（重要）：不要直接"哭"——眼睛湿润→眨眼减少→下巴轻微紧张→鼻息改变→嘴唇压紧→最后才可能出现泪水。**哭泣五级**：L1眼睛湿润 / L2呼吸变化 / L3声音不稳定 / L4嘴部眉眼明显 / L5完整哭泣

**微笑分级（0-5）**与**"眼睛参与微笑"**：真实微笑不只嘴角上扬，还有眼周和面颊协调（FACS的AU6 cheek raiser + AU12 lip corner puller）。**嘴笑但眼睛完全不变=AI微笑**。
- 假笑：嘴角微笑但眼睛不笑、停留短、随后恢复中性（非常适合电影角色）
- 强忍笑：嘴角想动→压住→眼神变化→呼吸→最后轻笑
- 讥笑：单侧嘴角+轻微眯眼+头略偏+眼神带距离
- 轻蔑：单侧嘴角+眉眼变化+头部微抬+视线略向下

## 九、八种情绪的专业拆解

| 情绪 | 专业解法（≠表情模板） |
|---|---|
| 怀疑 | 眉间轻微收紧+眼睛聚焦+头微侧+嘴保持中性 |
| 惊讶 | 刺激→眉毛/眼睑快速变化→嘴部短暂打开→恢复（不一定持续很久） |
| 恐惧 | 重点是注意力集中：眼睛快速锁定威胁+呼吸改变+身体冻结，不一定张大嘴 |
| 愤怒 | 分**爆发性**（动作大声音大）与**克制性**（声音低动作少下颌紧眼神固定——后者更电影化） |
| 悲伤 | 不一定哭脸：眼神下降+反应变慢+嘴唇收紧+呼吸变化+肩膀下降+讲话停顿 |
| 羞愧 | 目光回避+头部下降+嘴唇紧张+肩膀收缩 |
| 紧张 | 眨眼改变+视线快速变化+吞咽+下颌轻动+呼吸变化+手部微动作 |
| 放松/疲惫 | 放松：肩膀下降+眉间松开+呼吸变深+眼神重新稳定；疲惫：眨眼变慢+眼皮略沉+头轻微下垂 |

**怀疑到确认完整心理过程**：怀疑（眉间微皱）→观察（眼睛停留）→寻找证据（视线移动）→确认（眼神稳定）→表情恢复中性。

## 十、身体微表演

微表情不能只拍脸，还包括：手指/手腕/肩膀/胸腔/呼吸/脚/重心/坐姿。

- **手指**：轻敲/摩擦/握紧/松开/触碰物体（焦虑/等待/克制/思考）
- **肩膀**：下降=放松 / 上提=紧张 / 一侧抬高=不确定
- **重心**：左脚→右脚→回到中央，非常细微但提升真人感
- **坐姿**：微微前倾/后靠/改变脚位/调整手部——不要"坐着完全不动"

**身体与脸的协调/反差**：脸平静+身体轻微紧张；脸愤怒+身体反而冻结——反差非常有表现力。

**微动作预算与密度**：不能每秒都眨眼+点头+转头+微笑+抬眉+手势（动作过密）。密度推荐：安静场景极低 / 普通对白低-中 / 情绪对白中 / 激烈争吵中-高 / 疯狂状态高。

**微表情的"空白"（高级表演）**：听到坏消息不一定马上皱眉——完全没有表情，只是眼睛停止移动，这本身就是表演。**Neutral Face非常重要**：AI人物必须有可信的中性表情，基础模板是 Neutral→短暂变化→重新中性。

## 十一、预备/后续/次级运动

- **Anticipation预备动作**：动作前有呼吸准备/眼神准备/肌肉准备/头部变化
- **Follow Through后续动作**：转头后头先停、头发继续微动、衣服仍有惯性
- **Secondary Motion**：头发/衣服/饰品/肩膀/呼吸/胸口/眼睛——显著提升真人感
- **Facial Follow Through**：说完话嘴唇不要瞬间归零，短暂保持→呼吸→恢复
- **眼神Follow Through**：头先停止，眼睛稍后重新锁定——细微时间差非常自然

## 十二、聆听表演（Listening Acting）——听比说更难

AI最容易做错："听"不是"保持一个表情"。真实聆听=眼神反应+微表情+点头+停顿+呼吸+视线变化+微小表情抑制。

**聆听五步**：接收（看向对方）→理解（眼神轻微变化）→判断（短暂移开视线）→选择（准备说什么）→回应（嘴部准备启动）。

**AI人物的高级真实感很多时候来自Listening Performance**——人类对话中大量时间不是讲话，而是听、理解、判断、等待。

**台词前微动作（Pre-Speech）**：吸气→看向对方→微微点头→开口。**台词后微反应**：说完"我没事"→停顿→目光下降→呼吸——让台词产生新意义。

**Dialogue Beat**：对白拆成 说→停→听→反应→再说，而不是从头到尾不停说。

**沉默也是对白**：人物不说话，但眼神已经回答。沉默表演Prompt："人物没有对白，保持安静观察对方，眼神先保持接触，随后短暂移开，嘴唇轻微收紧，下颌略微紧张，吸气后仍然没有说话，情绪受到压抑，保持克制。"

## 十三、对白设计核心

**每句话至少考虑**：目的+情绪+重音+停顿+视线+反应。

**重音改变意义**："你真的来了。"重音在"你"/"真的"/"来了"意义完全不同。Prompt写法："人物低声说出一句话，将重音放在'真的'上，说话中间出现短暂停顿，眼神始终锁定对方。"

**节奏语义**：快=紧张/兴奋/愤怒；慢=权威/悲伤/谨慎；断裂=恐惧/犹豫/冲击；平稳=冷静/职业。

**停顿**表现：思考/犹豫/恐惧/控制/欺骗/情绪压制。

**手势**：不应每句话都做。指向=强调目标 / 开放手掌=解释 / 握拳=压抑 / 手指轻动=紧张 / 摊手=无奈。性格映射：权威少 / 热情大 / 焦虑微动作多 / 冷静少 / 犹豫断断续续。

**动作错位增强真实感**：不是每句话嘴→头→手→眼完全同时。真实：眼睛先看过去→头跟过去→嘴才说话。**Face Lead vs Body Lead** 两种都自然。动作先于意识=惊吓；意识先于动作=谨慎。

**讲话情绪与身体姿态**：愤怒胸腔更稳 / 恐惧身体收缩 / 悲伤肩膀下降 / 自信身体开放 / 羞耻身体缩小。

## 十四、镜头尺度与表演强度（关键原则）

**镜头越近，表演越克制**（小变化已经足够大）；**镜头越远，动作越大**（远景微表情看不到，由姿态/方向/手势/运动承担信息）。

**表演尺度公式**：可见表演幅度 ∝ 摄影机距离（创作规律，非机械数学）。

| 景别 | 表演强度 | 主信息 | 辅助 | 禁止 |
|---|---|---|---|---|
| 大特写ECU | 极低 | 眼神 | 嘴部/呼吸 | 大幅身体动作 |
| 特写CU | 低 | 眉眼+口部 | 头部 | — |
| 中近景MCU | 中低 | 面部 | — | — |
| 中景MS | 中 | 面部 | 手势/肩膀 | — |
| 中远景MFS | 中高 | 身体姿态 | 微表情不作主信息 | — |
| 全景FS/WS | 高 | 身体+空间+重心 | 行走 | — |

**大特写AI微表情原则**：一次只强调一个主面部动作+一个辅助动作（主：眼神变化；辅：嘴唇轻微收紧）。不要眉毛、嘴、鼻子、眼睛、头全部同时剧烈变化。

**特写中的"表演呼吸"（静态活性/Living Stillness）**：人物站着不动，但呼吸/眼神/微眨眼/面部张力/衣物轻微运动仍然存在。**活人感公式：Life = Breath + Eye Activity + Micro Motion + Weight + Attention**。

## 十六、Character Performance DNA（角色表演基因）

**每个核心人物建立**：Baseline（默认状态）/ Emotional Range（情绪范围）/ Blink Pattern（眨眼习惯）/ Eye Contact（视线习惯）/ Head Gesture / Speech Rhythm / Gesture Frequency / Emotion Suppression（情绪压制程度）。

**Performance DNA模板**：
```
CHARACTER: 人物名
BASELINE: 默认中性表情
EYES: 眼神习惯 | BLINK: 眨眼特征 | BROW: 眉毛动作
MOUTH: 嘴部习惯 | JAW: 下颌张力 | BREATH: 呼吸节奏
HEAD: 头部动作 | POSTURE: 身体姿态 | GESTURE: 手势频率
SPEECH: 讲话节奏 | PAUSE: 停顿习惯 | EMOTION: 主要情绪
SUPPRESSION: 情绪抑制程度 | REACTION: 反应速度
MICRO EXPRESSION: 标志性微表情（如"右侧嘴角轻微上扬"）
```

**角色差异化**（避免"统一AI演员感"）：所有人同样眨眼/点头/微笑/看人=整片AI感。
- 冷静角色A：少眨眼+少手势+长时间眼神接触+极少表情
- 焦虑角色B：频繁视线移动+微动作多+呼吸明显+说话更快
- 温和角色C：眼神柔和+微笑频繁+头部轻微倾斜

**同一句台词不同角色**："你来了。"——冷静（平静陈述）/ 惊讶（"你……来了？"）/ 开心（眼亮嘴扬）/ 不想见（下沉收束）。真正不同的不是文字，是表演。

**情绪外显率（Expression Ratio = External / Internal）**：愤怒内部90外部20=强烈抑制。高外显人物内外差距小，低外显人物差距大——这直接形成角色个性。

**多层表演**：Speech（"没问题"）/ Face（中性）/ Eyes（警惕）/ Body（紧张）四层分别定义——**信息不同步比全部一致更真实**（声音平静，眼睛已经泄露秘密，身体轻微后退）。

## 十七、注意力系统

**注意力层级（Attention Hierarchy）**：一级=当前讲话者（高注意力）/ 二级=最重要反应者 / 三级=次要人物 / 四级=背景人物（偶尔移动）。群体对白不要所有人同时点头/眨眼/看说话的人。

**Attention Shift（注意力转移）**是高级AI人物表演核心：对象A→听声音→转向B→发现C→重新回到A。

**Attention Beat**：每次注意力改变都是一个Beat。A说话→B看A→门外声音→B转向门→A停止讲话→两人都看门=注意力驱动的场面调度。

**事件驱动而非持续微表情**：不要"持续自然微表情"，让事件触发表情——声音→眼睛→眉毛→呼吸→台词。

**Trigger → Reaction参数化**：
- **Reaction Delay**：0.2秒=快速反应 / 0.8秒=思考反应 / 1.5秒=迟疑反应
- **Reaction Intensity**：10%几乎不动 / 30%明显微表情 / 60%强反应 / 100%情绪爆发

**三轴控制模型**：Amplitude（幅度）× Latency（延迟）× Duration（持续时间）× Coordination（协调性）= Performance。AI角色"假"很多时候不是面部不好，而是：幅度太大 / 所有部位同时动作 / 反应没有延迟 / 动作没有情境。

## 十八、微表情真实感四大原则与"受控随机"

**四大原则**：①小幅 ②有原因 ③有时间差 ④有余韵。

**随机≠自然**：AI随机眨眼/点头/微笑是错的。真人动作有自然波动但有状态约束——由注意力、情绪、语言、呼吸和环境共同驱动（受控随机：眨眼呼吸头部微动作略有变化，但角色身份和情绪状态保持稳定）。

**面部非同步与不对称**：真人面部不是绝对对称；左右眉/左右眼/嘴角完全同步=CG感。允许"轻微非对称变化"（如右眉+10%、左眉+4%——不需要写数字，写"轻微非对称"即可）。**Temporal Offset时间偏移**：眼睛先动→眉毛随后→嘴角稍后→头部最后。微妙异步示例：0.0秒眼神锁定→0.1秒眉毛上提→0.2秒嘴角变化→0.4秒头微转→0.7秒说"你来了"。

**讲话动作时间轴模板**：0.0s眼神锁定→0.2s吸气→0.3s眉眼变化→0.4s嘴部启动→0.5s开口→1.5s中间停顿→1.7s眼神偏移→2.0s重新聚焦→2.2s结束。

## 二十、连续性与四锁系统

**表演连续性**：镜头1压抑愤怒→镜头2仍应压抑，不能突然开心（除非剧情触发事件）。

**Performance State模板（每个镜头定义）**：
```
EMOTION: 愤怒 30%
ATTENTION: 锁定B
SPEECH: 低声
FACE: 眉间轻收紧
EYES: 稳定直视
HEAD: 轻微前倾
BODY: 静止
BREATH: 略快
GESTURE: 低
END: 情绪保持
```

**Start/End Performance State（首尾帧继承）**：每个镜头开始前应知道人物上一秒在做什么（上一镜刚听到坏消息，下一镜不能瞬间恢复平静）。End State包括最终表情/视线/姿态/情绪——下一镜继承。

**AI人物连续性四锁**：Identity Lock（身份）/ **Performance Lock（表演习惯：默认表情+眨眼+视线+语速+手势+头部+情绪压制+反应速度）**/ Emotion Lock（当前情绪）/ State Lock（当前状态）。与15号的Character Identity Lock结合成完整锁系统。

**表情Transition不瞬切**：快乐→悲伤要走：笑意消失→眼神停顿→嘴角归零→眉眼变化→呼吸改变→最终情绪形成（开心→悲伤的动作层：笑容减弱→眼神停止→嘴角归零→眉眼变化→呼吸改变→情绪形成）。

**微表情时间设计**：普通微表情0.5–2秒 / 较慢心理变化2–5秒 / 极端情绪更快（创作参考非生理标准）。**给表演留时间**：每1秒切一次，很多微表演无法成立；最好的微表情可能只发生一次，其余时间什么都不发生（留白）。

## 二十一、常见错误与修复

**AI讲话10大错误**：①嘴巴开合过大 ②口型机械 ③眼睛完全不动 ④每句话都点头 ⑤眉毛一直运动 ⑥嘴说话和情绪不匹配 ⑦没有呼吸 ⑧没有停顿 ⑨说完瞬间表情归零 ⑩聆听者完全没有反应。

**"AI说话像AI"核心症状**：嘴在说脸没说 / 脸在说眼睛没说 / 眼睛在看身体没回应 / 声音自然动作机械=Audio Realism + Visual Roboticism。修复：同时加入口型+眼神+呼吸+头部+停顿+潜台词。

**死脸修复**：增加呼吸+微眨眼+视线变化+轻微下颌变化+情绪微变化+头部微动作——而不是增加大表情。
**木头感修复**：降低表情幅度/头部频率/手势数量；增加时间差+停顿+聆听+注意力+呼吸。
**塑料感修复**：增加面部非同步+细微肌肉变化+眼神+表情余韵+皮肤光线微变化；避免过度磨皮和完美对称。

**"表情堆叠"为什么AI化**：同时皱眉+瞪眼+张嘴+点头+微笑——现实人物很少所有动作同时满强度发生。**协调但不完全同步**。

**自然误差预算**：允许小幅视线变化+微小左右不对称+呼吸波动+轻微姿态调整；**不允许**五官漂移+脸型改变+眼睛方向异常+嘴型语音明显脱节（Natural Imperfection≠Model Failure）。

**红线（出现即优先重做Performance State，而不是加"电影感"）**：眼神漂移 / 嘴脸不同步 / 表情突然跳变 / 反应明显过快 / 眨眼机械重复 / 下颌机械开合 / 说话时脸完全静止 / 聆听者完全没反应 / 情绪突然归零。

## 二十二、Prompt模板库（可直接复制）

**母版·微表情**：
> 电影级人物微表情表演，人物从自然中性状态开始，保持真实呼吸和极轻微面部活性。当听到【触发事件】时，不立即切换成固定情绪表情，而是先产生短暂信息处理停顿，眼神首先发生变化，随后眉间和眼周出现细微张力，嘴唇与下颌产生轻微不同步变化，人物努力控制外部情绪，仅通过眼神、呼吸和局部肌肉运动泄露内在状态；表情变化连续、渐进、低幅度、具有自然时间延迟，左右面部保持轻微非对称，事件结束后保留短暂情绪余韵，不立即恢复完全中性状态。

**母版·讲话**：
> 电影级自然对白表演，人物先以真实聆听状态观察对方，准备回答前存在短暂眼神确认和吸气动作，随后自然开口，口型与语音准确同步，嘴唇、下颌和面部动作连续而不机械，不夸张开合；讲话过程中根据语义产生自然重音、停顿和语速变化，眼神根据潜台词发生轻微移动，眉眼只在关键内容处变化，头部动作少量且不与每句话机械同步，身体持续保持自然呼吸和轻微重心变化。说完后保留短暂反应余韵，不立即恢复静止中性表情。

**母版·双人对话**：
> 电影级双人对白表演，两个人处于同一真实物理空间，人物A讲话、人物B认真聆听，双方拥有不同的表演节奏和情绪状态。A讲话时保持与B的自然眼神接触，并根据潜台词产生轻微眉眼、嘴唇和下颌变化；B不说话时保持真实Listening Acting，通过眼神、微眨眼、轻微呼吸和少量头部变化回应A。两人动作不同步、不机械点头、不同时眨眼、不同时做手势，偶尔出现自然停顿和反应延迟，讲话者与聆听者存在明确注意力关系，形成真实电影对白感。

**专项模板**：
- 低情绪对白：极度克制地说话，声音平稳低沉，口型幅度较小，下颌轻微运动，几乎没有夸张手势，眼神持续观察对方，眉间仅有极轻微紧张，说完后保持短暂停顿和沉默，情绪隐藏在眼神和呼吸中。
- 愤怒对白：压抑愤怒地说话，不大喊，声音低而有力量，讲话前短暂吸气，眼神持续锁定对方，眉间逐渐收紧，下颌和嘴唇出现轻微紧张，句子之间存在短暂停顿，手部保持克制，情绪逐渐升高但外部表演始终控制。
- 悲伤对白：带着强烈悲伤却努力保持镇定地说话，声音轻微颤抖，语速比平常略慢，句子中出现自然停顿，眼神短暂回避后重新看向对方，眼睛逐渐湿润，嘴唇轻微收紧，呼吸不规则但不夸张，说完后保持短暂沉默，不立即恢复中性表情。
- 恐惧对白：压低声音说话，身体保持谨慎，眼神持续关注画面外危险，视线偶尔快速偏移，讲话前明显吸气，嘴部动作小而紧张，句子之间存在短暂停顿，头部只进行极小幅度移动，保持高度警觉，不夸张尖叫。
- 紧张对白：说话时保持轻微紧张，眼神偶尔快速移开再回来，眨眼频率轻微增加，嘴唇和下颌存在细微紧张，手指轻微移动，讲话速度略快，中间偶尔出现自我修正与短暂停顿，保持真实自然，不连续点头，不夸张表情。
- 开心对白：自然开心地说话，眼神明亮并持续关注对方，嘴角自然上扬，眼周出现轻微同步变化，讲话节奏轻快但不夸张，偶尔自然点头和小幅度手势，说完后保留轻微笑意和呼吸余韵。
- 撒谎：表面保持平静地说话，嘴部动作自然，声音稳定，但眼神在关键问题出现时短暂回避，随后重新建立眼神接触，眉毛出现极轻微变化，下颌短暂紧张，回答前存在很短的信息处理停顿，随后恢复自然表情，不使用夸张的"撒谎脸"。
- 犹豫：准备回答问题，先保持沉默，眼神短暂移向一侧，嘴唇轻微收紧并放松，吸气后开始说话，说出前几个字后出现短暂停顿，再继续回答，头部微微倾斜，表情克制，表现真实的信息处理和犹豫过程。
- 冷漠角色：始终保持低幅度面部表演，眼神稳定、眨眼较少，嘴部动作精确但克制，讲话速度均匀，头部动作极少，身体保持稳定，只允许呼吸和极细微重心变化，情绪几乎全部隐藏，仅在关键台词时出现极轻微眼神变化。
- 聆听：人物不讲话，认真听对方说话，保持自然眼神接触，随着对方内容产生细微信息处理反应；眼神短暂移动、轻微眨眼、眉间细小变化，下颌和嘴唇偶尔出现极小幅度动作，偶尔产生轻微点头但不是每句话都点头，呼吸自然，保留真实聆听状态。
- 反应镜头：对白结束后不要立刻切回说话者，镜头停留在聆听者脸上，聆听者保持沉默，仅眼神发生微小变化，先短暂回避，再重新看向说话者，嘴唇保持闭合，下颌轻微紧张，呼吸自然，以极低幅度表演呈现真实反应。
- 大特写微表情：85mm电影级面部大特写，人物几乎静止，仅通过眼神、眼睑、眉间、嘴角、嘴唇和呼吸表现复杂情绪。人物从中性状态缓慢进入怀疑状态：眼睛先停止移动并重新聚焦，随后眉间产生极轻微张力，右眉略高于左眉，嘴唇轻轻压紧，下颌产生微弱紧张，呼吸稍微加深，表情保持克制，不出现夸张皱眉、瞪眼或张嘴，左右面部保持轻微自然不对称，摄影机几乎静止，保留表情变化完整过程。
- 克制哭泣：电影级克制哭泣表演，人物起始保持中性状态，听到触发信息后首先出现短暂停顿，眼神停留并逐渐湿润，眨眼减少，眉间轻微收紧，嘴唇压紧以努力控制情绪，下颌产生细微紧张，呼吸逐渐变得不规则，声音开始轻微不稳定，人物仍试图保持平静，最终只有很少量眼泪出现，避免立即大哭、夸张嘴部变形和剧烈身体动作。
- 隐藏笑意：人物努力隐藏笑意，听到一句话后先保持中性表情，眼睛短暂变亮，嘴角单侧出现极轻微上扬，随即主动压回，嘴唇轻轻抿住，头部保持稳定，随后低头短暂调整呼吸，再恢复平静，只有眼睛仍残留微弱笑意，形成"想笑但忍住"的真实微表演。
- 压抑愤怒：人物表面极度克制，内心明显愤怒，开始时保持平静直视，听到挑衅后眼神先固定，眉间逐渐产生轻微张力，嘴唇缓慢压紧，下颌出现细微咬紧，呼吸更深但仍受控制，声音保持低沉平稳，身体几乎不动，仅手指产生极轻微收紧动作，情绪不会突然爆发，而是在镜头结束时保留高张力余韵。
- 恐惧不尖叫：人物发现画面外异常，最初保持平静，声音停止后眼神先快速锁定异常方向，随后身体短暂冻结，眼睑略微张开，眉毛轻微上提，嘴唇微张但没有尖叫，呼吸暂时停顿后变快，头部缓慢转向声音来源，恐惧主要通过注意力、呼吸和眼神体现，而不是夸张表情。
- 思考：人物在回答前没有立即说话，先看向对方，随后短暂将视线移开，眼睛停留在远处几百毫秒，轻微吸气，嘴唇微张后重新闭合，短暂组织语言，再恢复与对方的眼神接触并回答。
- 回忆：人物想到过去，不一定直接哭——眼神短暂失焦→环境声音变化→呼吸减慢→脸部轻微放松。
- 情绪转移（Neutral→怀疑）：人物起始保持中性表情，在听到对方一句话后先短暂保持不动，眼神出现轻微变化，随后眉间慢慢产生张力，嘴唇逐渐收紧，呼吸稍微加深，最终形成克制的怀疑表情，变化连续缓慢，不突然切换表情。
- 表演连续性：保持同一角色的表演DNA：相同的情绪外显程度、相同的眨眼习惯、相同的眼神模式、相同的手势频率、相同的讲话节奏和相同的头部动作习惯。镜头之间继承上一镜头的情绪状态和表演余韵，不突然改变表情，不随机改变视线，不突然增加动作幅度，不让角色变成完全不同的表演风格。
- 5秒讲话标准时间轴：0-1秒听到/准备回答 → 1-2秒眼神确认 → 2秒吸气 → 2-4秒讲话 → 4秒轻微反应 → 5秒保留余韵。

**Negative Prompt总库（讲话）**：
robotic facial movement / excessive lip motion / repetitive blinking / constant nodding / exaggerated facial expressions / synchronized eyebrow movement / frozen eyes / dead gaze / unnatural lip opening / mechanical jaw / expression reset / emotionless listening / random gestures / repetitive gestures / instant reaction / overacting / facial jitter / identity drift（中文：机械嘴型/过度开口/重复眨眼/连续点头/表情过度/眉毛机械同步/眼神呆滞/口型不自然/下颌机械运动/情绪突然归零/聆听时无反应/随机手势/动作重复/反应过快/过度表演/面部抖动/人物身份漂移）

**电影演员式总模板**：
> 以电影演员的克制式表演方式呈现人物，不直接展示固定情绪表情，而通过注意力、眼神、呼吸、微小面部动作、头部和身体姿态逐渐表达内在状态。人物始终保持明确的角色表演基线，反应由场景事件触发，并存在自然的信息处理延迟。面部动作低幅度、连续、非完全同步，左右面部保持轻微自然不对称。讲话时口型与语音准确同步，同时结合自然下颌运动、呼吸、语速、重音、停顿、眼神和潜台词；聆听时不保持死板静止，而是使用极少量真实的眼神、眨眼和呼吸反馈。事件结束后保留短暂情绪余韵，不立即恢复默认表情。整体避免过度表演、机械眨眼、机械点头、嘴部大幅开合、表情跳变和AI式重复动作。

## 二十三、摄影/灯光/剪辑联动

- **与景别联动**：特写强调眼神，近景强调眉眼嘴，中景强调上半身手势，全景强调身体空间——表演设计必须随景别改变
- **与灯光联动**：微表情越细越需要柔和可读的面部光线；脸部极端阴影会让很多微表情信息看不到
- **与景深联动**：背景非常虚→观众更关注脸；深景深→表演更多依靠身体空间行动；表现脸部表演应保证眼睛和嘴区域都在清晰范围内
- **与剪辑联动**：微表情镜头不要切太快——特写只持续0.3秒很多微表演没有意义，剪辑节奏必须给表演留空间
- **与声音联动**：声音悲伤脸完全平静，除非是刻意潜台词设计；Audio Emotion × Facial Emotion × Body Emotion 共同决定人物是否"真的在说话"
- **与摄影机运动联动**：复杂对白不要"人物讲话+摄影机疯狂移动"，一个主要变量——人物表演+摄影机缓慢推进（对白慢推：随心理信息深入逐渐拉近观众）；反应镜头用固定机位放大表演；A讲话→焦点转向B（Rack Focus）=表演关系的视觉转移
- **与焦段联动**：面部微表情适合85mm/100mm/135mm+大特写/特写（焦段最终服从整体构图和空间需求）

## 二十五、二十步工作流与评分

**二十步表演设计流程**：确定人物性格→角色表演DNA→Neutral Baseline→当前场景情绪→内心情绪→外显情绪→Trigger→Reaction Latency→设计眼神→眉眼→嘴部→下颌→呼吸→头部→身体→对白节奏→聆听反应→情绪余韵→**再设计摄影机**→最后生成AI视频。

**最终检查表**：身份（同一个吗）/ 眼睛（有注意力吗）/ 表情（是不是过大）/ 眉毛（机械同步吗）/ 嘴部（一直大幅开合吗）/ 下颌（机械运动吗）/ 呼吸（有生命感吗）/ 头部（一直点头吗）/ 身体（有重心和重量吗）/ 对白（有节奏吗）/ 停顿（有思考吗）/ 聆听（有反应吗）/ 潜台词（表面和内心有差异吗）/ 情绪（连续吗）/ 结束（有余韵吗）。

**100分评分**：身份一致性15 / 眼神真实性15 / 微表情真实性15 / 口型同步10 / 讲话节奏10 / 呼吸与身体10 / 头部动作5 / 聆听表演10 / 情绪连续性5 / 角色个性5。

## 二十六、终极模型

**五层真实感**：外观真实（像真人）→ 动作真实（动起来像）→ 语言真实（说话像）→ 心理真实（反应像）→ **角色真实（每个动作都像"这个人"会做的动作）**——第五层才是AI电影级表演。

**黄金结构**：Trigger → Attention → Processing → Micro Reaction → Speech/Action → Secondary Motion → Residual

**电影对白最终循环**：听→理解→决定→准备→说→反应→等待→对方回应。

**终极公式**：Character Performance = Identity × Intent × Attention × Emotion × Micro Expression × Speech × Body × Timing × Continuity

**最少而准原则**：1秒≈一次眼神变化；2秒≈一次眼神+一次呼吸；5秒≈聆听→思考→一句话→余韵。宁可3个准确微动作，不要15个随机动作。

**高级真实感四关键词**：克制（动作不过量）/ 延迟（反应不过快）/ 非同步（不同帧变化）/ 余韵（不立即清零）。
**讲话像真人五关键词**：呼吸 / 停顿 / 重音 / 视线 / 反应。

**最高判断标准**：当人物说"我没事"，观众看到眼神不是没事、呼吸不是没事、停顿不是没事、嘴角不是没事、身体不是没事——角色就活了。

**与skill其他库的接口**：FACS解决"脸怎么动"（本库）；表演学解决"为什么动"（本库）；摄影解决"观众什么时候看到"（02号）；声音解决"人物怎么说"（13号）；Blocking解决"身体在哪里"（15号）；连续性解决"上一镜继承什么"（11号/本库四锁）。最终接入 Character Bible → Character Acting Bible。
